## Research Problem

### English

The paper addresses fine-grained vessel traffic flow forecasting in maritime intelligent transportation systems.

Unlike road transportation, maritime traffic does not have an explicitly defined road network. Therefore, conventional graph-based traffic forecasting models cannot be directly transferred to maritime applications.

The paper focuses on two main research questions:

1. How can a maritime traffic network be automatically extracted from large-scale historical AIS trajectories?
2. How can multiple spatial and temporal relationships among maritime traffic nodes be incorporated into a neural forecasting model?

The central argument is that vessel traffic should not be treated as a collection of independent time-series variables. Instead, maritime traffic has an underlying graph structure in which traffic flows are connected through geographical proximity, historical vessel movements, and correlated temporal patterns.

### 中文

该论文研究海上智能交通系统中的细粒度船舶交通流预测问题。

与道路交通不同，海上交通没有清晰、固定的道路网络结构，因此，原本用于城市道路交通预测的图神经网络模型不能直接应用于航运场景。

论文主要回答两个问题：

1. 如何从大规模历史 AIS 船舶轨迹中自动提取海上交通网络？
2. 如何将不同航运节点之间的空间关系和时间关系纳入统一的预测模型？

论文的核心观点是：

> 船舶交通流不应被视为若干彼此独立的时间序列，而应被表示为一个具有节点、边和时间变化的海上交通图。

节点之间的联系不仅包括地理距离，还包括历史船舶流动关系以及流量时间序列的统计相关性。

## Core Method

### 1. Maritime Traffic Network Extraction  
### 1. 海上交通网络提取

#### English

The authors first transform raw AIS vessel trajectories into a maritime traffic graph.

The extraction procedure contains four main steps:

1. Extract starting points, ending points, and way points from each vessel trajectory.
2. Cluster the extracted trajectory feature points.
3. Project the feature-point clusters onto spatial grids.
4. define maritime traffic nodes and edges from the clustered trajectory structure.

The output is an original maritime traffic graph:

\[
G_O=(\mathcal{N},\mathcal{E},A_O)
\]

where:

- \(\mathcal{N}\) is the set of maritime traffic nodes;
- \(\mathcal{E}\) is the set of connections between nodes;
- \(A_O\) is the original adjacency matrix.

#### 中文

作者首先将原始 AIS 船舶轨迹转换为海上交通图。

海上交通网络的提取包括四个主要步骤：

1. 从每条船舶轨迹中识别起点、终点和转向点；
2. 对轨迹特征点进行空间聚类；
3. 将特征点聚类投影到规则空间网格；
4. 根据轨迹的连接关系定义交通节点和边。

最终形成原始海上交通图：

\[
G_O=(\mathcal{N},\mathcal{E},A_O)
\]

其中：

- \(\mathcal{N}\) 表示海上交通节点集合；
- \(\mathcal{E}\) 表示节点之间的连接关系；
- \(A_O\) 表示原始邻接矩阵。

---

### 2. Douglas–Peucker Trajectory Simplification  
### 2. Douglas–Peucker 轨迹压缩

#### English

The Douglas–Peucker algorithm is used to simplify each vessel trajectory and identify geometrically important points.

For trajectory \(T_i\):

\[
\{p_i^s,p_i^w,p_i^e\}\leftarrow DP(T_i)
\]

where:

- \(p_i^s\): starting point;
- \(p_i^w\): way point or direction-changing point;
- \(p_i^e\): ending point.

This step removes large numbers of redundant AIS observations while retaining important changes in vessel movement direction.

#### 中文

论文使用 Douglas–Peucker 算法压缩船舶轨迹，并识别具有几何意义的重要轨迹点。

对于第 \(i\) 条轨迹 \(T_i\)：

\[
\{p_i^s,p_i^w,p_i^e\}\leftarrow DP(T_i)
\]

其中：

- \(p_i^s\)：轨迹起点；
- \(p_i^w\)：转向点或航向明显变化的位置；
- \(p_i^e\)：轨迹终点。

该步骤删除大量重复或冗余 AIS 点，同时保留反映船舶运动方向变化的重要位置。

---

### 3. DBSCAN Feature-Point Clustering  
### 3. DBSCAN 特征点聚类

#### English

Because different vessels do not pass through exactly the same coordinates, the extracted starting, ending, and way points contain noise and spatial deviations.

The paper applies DBSCAN to:

- cluster nearby feature points;
- identify irregularly shaped maritime activity regions;
- remove isolated AIS outliers;
- avoid specifying the number of clusters in advance.

The clustering process can be represented as:

\[
[F^1,\ldots,F^C]+O\leftarrow DBSCAN(P)
\]

where:

- \(P\) is the complete set of extracted feature points;
- \(F^c\) is the \(c\)-th feature-point cluster;
- \(O\) is the set of detected outliers.

#### 中文

由于不同船舶不会经过完全相同的经纬度位置，提取出的起点、终点和转向点会存在空间偏移和噪声。

论文使用 DBSCAN：

- 将空间上接近的特征点聚为一类；
- 识别具有不规则空间形状的港池、航道和转向区域；
- 去除孤立的 AIS 异常点；
- 避免事先指定聚类数量。

聚类过程表示为：

\[
[F^1,\ldots,F^C]+O\leftarrow DBSCAN(P)
\]

其中：

- \(P\) 为全部轨迹特征点；
- \(F^c\) 为第 \(c\) 个特征点聚类；
- \(O\) 为被识别出的异常点。

---

### 4. Grid Projection and Node Generation  
### 4. 网格投影与节点生成

#### English

The authors argue that a maritime traffic node should represent a spatial region rather than an exact coordinate.

The study area is therefore divided into an \(L\times W\) spatial grid. Feature points belonging to the same DBSCAN cluster are projected onto the grid.

Grid cells containing sufficient numbers of feature points from the same cluster are combined into a maritime traffic node.

Edges are constructed when historical trajectories demonstrate that vessels can travel between two nodes.

The original adjacency matrix is:

\[
A_O^{ij}=
\begin{cases}
1, & \text{if node }n_i\text{ is connected to }n_j,\ i\neq j\\
0, & \text{otherwise}
\end{cases}
\]

#### 中文

作者认为，海上交通节点应当表示一个具有一定空间范围的区域，而不是一个精确坐标点。

因此，研究区域被划分为 \(L\times W\) 的规则网格，并将 DBSCAN 特征点聚类投影到网格中。

包含足够多同类特征点的网格区域被组合为一个海上交通节点。

如果历史船舶轨迹显示船舶能够从节点 \(i\) 航行至节点 \(j\)，则在两个节点之间建立一条边。

原始邻接矩阵定义为：

\[
A_O^{ij}=
\begin{cases}
1, & \text{如果节点 }n_i\text{ 与 }n_j\text{ 相连且 }i\neq j\\
0, & \text{其他情况}
\end{cases}
\]

## Multi-Graph Construction

The paper constructs three complementary spatial graphs instead of relying only on the original binary maritime network.

论文没有仅使用一张二元连接图，而是构建了三张具有互补信息的空间关系图。

---

### 1. Distance Graph \(G_D\)  
### 1. 距离图 \(G_D\)

#### English

The distance graph represents geographical proximity between maritime traffic nodes.

The edge weight is defined as the reciprocal of the Euclidean distance between two node centroids:

\[
A_D^{ij}=
\begin{cases}
\frac{1}{D_{ij}}, & i\neq j\\
0, & \text{otherwise}
\end{cases}
\]

Nearby maritime nodes therefore receive higher connection weights.

This graph reflects the assumption that spatially close maritime locations are more likely to exhibit similar traffic patterns.

#### 中文

距离图表示不同海上交通节点之间的地理邻近关系。

边权重由两个节点中心点之间欧氏距离的倒数表示：

\[
A_D^{ij}=
\begin{cases}
\frac{1}{D_{ij}}, & i\neq j\\
0, & \text{其他情况}
\end{cases}
\]

因此，距离越近的节点具有越高的连接权重。

该图反映了空间邻近节点通常具有更相似船舶活动模式的假设。

---

### 2. Interaction Graph \(G_I\)  
### 2. 交互图 \(G_I\)

#### English

The interaction graph represents the historical intensity of vessel movements between nodes.

Its adjacency matrix is:

\[
A_I^{ij}=
\begin{cases}
I_{ij}, & i\neq j\\
0, & \text{otherwise}
\end{cases}
\]

where \(I_{ij}\) is the number of historical vessel movement records between nodes \(i\) and \(j\).

Two nodes may therefore have a strong interaction edge even when they are not geographically close, provided that many vessels historically travel between them.

#### 中文

交互图表示不同节点之间历史船舶流动的强度。

其邻接矩阵为：

\[
A_I^{ij}=
\begin{cases}
I_{ij}, & i\neq j\\
0, & \text{其他情况}
\end{cases}
\]

其中，\(I_{ij}\) 表示历史上节点 \(i\) 与节点 \(j\) 之间的船舶交通记录数量。

因此，即使两个节点的地理距离较远，只要历史上存在大量船舶往来，它们仍然可以具有较强的交互关系。

---

### 3. Correlation Graph \(G_C\)  
### 3. 相关性图 \(G_C\)

#### English

The correlation graph captures statistical similarities between the historical traffic-flow time series of different nodes.

The authors calculate the Pearson correlation coefficient:

\[
C_{ij}=
\frac{\operatorname{Cov}(X_i,X_j)}
{\sigma_{X_i}\sigma_{X_j}}
\]

The adjacency matrix is:

\[
A_C^{ij}=
\begin{cases}
C_{ij}, & i\neq j\\
0, & \text{otherwise}
\end{cases}
\]

This graph allows the model to connect nodes that display synchronised traffic changes, even when they are not directly connected by a vessel route.

#### 中文

相关性图用于表示不同节点历史交通流时间序列之间的统计相似性。

作者使用 Pearson 相关系数：

\[
C_{ij}=
\frac{\operatorname{Cov}(X_i,X_j)}
{\sigma_{X_i}\sigma_{X_j}}
\]

其邻接矩阵为：

\[
A_C^{ij}=
\begin{cases}
C_{ij}, & i\neq j\\
0, & \text{其他情况}
\end{cases}
\]

该图使模型能够连接流量变化具有同步性的节点，即使这些节点之间不存在直接航线连接。

## STMGCN Architecture

### English

The proposed model is called the Spatio-Temporal Multi-Graph Convolutional Network, or STMGCN.

The prediction task is formulated as:

\[
[v_{t+1},\ldots,v_{t+H}]
=
F([v_{t-M+1},\ldots,v_t];G_D,G_I,G_C)
\]

where:

- \(v_t\in\mathbb{R}^{N}\) is the vessel traffic flow observed at all \(N\) nodes at time \(t\);
- \(M\) is the historical input-window length;
- \(H\) is the forecasting horizon;
- \(G_D\), \(G_I\), and \(G_C\) are the distance, interaction, and correlation graphs.

STMGCN contains:

- two spatio-temporal multi-graph convolutional blocks;
- one fully connected output layer.

Each STMG-Conv block follows:

\[
\text{Temporal Gated Convolution}
\rightarrow
\text{Spatial Multi-Graph Convolution}
\rightarrow
\text{Temporal Gated Convolution}
\]

Residual connections and a bottleneck strategy are also used inside the network.

### 中文

论文提出的模型称为时空多图卷积网络，即 STMGCN。

预测任务表示为：

\[
[v_{t+1},\ldots,v_{t+H}]
=
F([v_{t-M+1},\ldots,v_t];G_D,G_I,G_C)
\]

其中：

- \(v_t\in\mathbb{R}^{N}\) 表示时间 \(t\) 所有 \(N\) 个节点的船舶交通流；
- \(M\) 表示历史输入窗口长度；
- \(H\) 表示预测步数；
- \(G_D\)、\(G_I\) 和 \(G_C\) 分别表示距离图、交互图和相关性图。

STMGCN 包括：

- 两个时空多图卷积模块；
- 一个全连接输出层。

每个 STMG-Conv 模块的结构为：

\[
\text{时间门控卷积}
\rightarrow
\text{空间多图卷积}
\rightarrow
\text{时间门控卷积}
\]

模型内部还使用了残差连接和 bottleneck 压缩策略。

---

## Temporal Gated Convolution

### English

The temporal component uses one-dimensional causal convolution and gated linear units to extract temporal patterns.

The temporal operation is:

\[
\mathcal{T}
=
V_1\odot\sigma(V_2)
\]

where:

- \(V_1\) contains candidate temporal features;
- \(\sigma(V_2)\) is a sigmoid gate;
- \(\odot\) denotes element-wise multiplication.

The gate determines which historical states are important for identifying temporal dynamics and compositional structures.

Compared with recurrent models such as LSTM and GRU, temporal convolution can be more computationally parallelisable.

### 中文

时间编码部分使用一维因果卷积和门控线性单元提取时间变化模式。

时间门控运算为：

\[
\mathcal{T}
=
V_1\odot\sigma(V_2)
\]

其中：

- \(V_1\) 表示候选时间特征；
- \(\sigma(V_2)\) 表示 sigmoid 门控权重；
- \(\odot\) 表示逐元素相乘。

门控机制决定哪些历史状态对识别当前的时间动态更加重要。

与 LSTM 和 GRU 等循环网络相比，时间卷积结构通常具有更好的并行计算能力。

## Spatial Multi-Graph Convolution

### English

The temporal feature matrix is processed separately by three graph-convolution branches:

\[
S_D=\psi(\Theta *_ {G_D}\mathcal{T})
\]

\[
S_I=\psi(\Theta *_ {G_I}\mathcal{T})
\]

\[
S_C=\psi(\Theta *_ {G_C}\mathcal{T})
\]

where \(S_D\), \(S_I\), and \(S_C\) are the spatial representations learned from the distance, interaction, and correlation graphs.

The three graph representations are concatenated:

\[
\hat{V}
=
\psi\left(
W[S_D,S_I,S_C]+B
\right)
\]

The paper uses spectral graph convolution with Chebyshev polynomial approximation to reduce computational cost.

### 中文

时间特征矩阵被分别输入三条图卷积分支：

\[
S_D=\psi(\Theta *_ {G_D}\mathcal{T})
\]

\[
S_I=\psi(\Theta *_ {G_I}\mathcal{T})
\]

\[
S_C=\psi(\Theta *_ {G_C}\mathcal{T})
\]

其中，\(S_D\)、\(S_I\) 和 \(S_C\) 分别表示从距离图、交互图和相关性图中学习到的空间表示。

三种图表示随后被拼接：

\[
\hat{V}
=
\psi\left(
W[S_D,S_I,S_C]+B
\right)
\]

论文使用谱图卷积，并通过 Chebyshev 多项式近似降低图卷积的计算成本。

## Prediction Target

### English

The target is node-level vessel traffic flow.

Given vessel traffic observations during the previous \(M\) time intervals, the model predicts vessel traffic flows for the following \(H\) time intervals at all maritime traffic nodes.

The experiments evaluate:

- one-hour-ahead forecasting;
- two-hour-ahead forecasting;
- three-hour-ahead forecasting.

This is a multi-node, multi-step traffic-flow forecasting problem rather than a vessel-trajectory prediction problem.

### 中文

论文的预测目标是节点级船舶交通流。

模型根据过去 \(M\) 个时间段所有海上交通节点的船舶流量，预测未来 \(H\) 个时间段各节点的船舶通过数量。

实验分别评估：

- 未来1小时预测；
- 未来2小时预测；
- 未来3小时预测。

因此，这是一项多节点、多步交通流预测任务，而不是单条船舶轨迹预测任务。

## Evaluation

### English

The main evaluation metrics are:

- Root Mean Squared Error (RMSE);
- Mean Absolute Error (MAE);
- Coefficient of Determination (\(R^2\));
- Relative Error (RE).

Each forecasting model is run ten times to reduce the influence of random model initialisation.

The paper reports both:

- mean forecasting performance;

Additional analyses include:

- node-level error comparisons;
- residual analysis;
- perturbation and noise-robustness analysis.

主要评价指标包括：

## Main Quantitative Results

| Forecasting horizon | STMGCN RMSE | STMGCN MAE | STMGCN \(R^2\) |
|---|---:|---:|---:|
| 1 hour | \(6.46\pm0.96\) | \(3.63\pm0.43\) | \(0.66\pm0.08\) |
| 2 hours | \(7.19\pm1.47\) | \(3.86\pm0.44\) | \(0.60\pm0.09\) |
| 3 hours | \(7.59\pm2.19\) | \(4.16\pm0.72\) | \(0.56\pm0.11\) |

### Interpretation / 结果解释

- STMGCN achieves the lowest overall RMSE and MAE across the three forecasting horizons.
- It also obtains the highest \(R^2\) among the compared models.
- Forecasting performance gradually deteriorates as the horizon increases from one to three hours.
- STMGCN generally reports smaller standard deviations than the competing models, indicating greater training stability.
- The model also performs strongly across the individual nodes of the maritime traffic network.

中文解释：

- STMGCN 在1小时、2小时和3小时预测任务中均取得总体最低的 RMSE 和 MAE。
- 在对比模型中，STMGCN 的 \(R^2\) 最高。
- 随预测期限从1小时增加到3小时，预测误差逐渐增加，说明长期预测难度更高。
- STMGCN 的重复实验标准差总体较低，表明其训练结果更稳定。
- 在16个单独交通节点上的相对误差比较中，STMGCN 也表现出较好的准确性和稳健性。

## Key Findings

### English

1. **Graph representation improves vessel traffic forecasting.**  
   Representing maritime traffic as a network enables the model to use cross-node relationships that cannot be captured by independent time-series models.

2. **Spatial and temporal information are complementary.**  
   Temporal gated convolutions learn short-term traffic dynamics, while graph convolutions model interactions among maritime nodes.

3. **Multiple graphs outperform a single graph.**  
   Distance, interaction, and correlation graphs encode different types of relationships, and their fusion generally improves prediction accuracy.

4. **Correlation-related graph combinations are particularly informative.**  
   Two-graph variants involving distance plus correlation or interaction plus correlation perform better than many single-graph variants.

5. **STMGCN outperforms conventional ML, temporal neural networks, and existing graph models.**  
   The model achieves better overall performance than HA, SVR, BPNN, LSTM, GRU, T-GCN, and DCRNN.

6. **The model is comparatively robust.**  
   Repeated experiments, residual analysis, and input perturbation tests indicate relatively stable predictions and limited sensitivity to moderate input noise.

7. **Forecasting difficulty increases with the prediction horizon.**  
   RMSE and MAE increase, while \(R^2\) decreases, when forecasting changes from one hour to three hours ahead.

### 中文

1. **图结构表示能够提高船舶交通流预测效果。**  
   将海上交通表示为网络，使模型能够学习不同节点之间的联系，而不是把每个节点视为独立时间序列。

2. **时间信息和空间信息具有互补性。**  
   时间门控卷积学习短期流量动态，图卷积则学习不同海上交通节点之间的空间和流动关系。

3. **多图融合通常优于单图模型。**  
   距离图、交互图和相关性图分别编码不同类型的节点关系，多图融合能够提供更加完整的航运网络信息。

4. **包含相关性图的组合尤其具有预测价值。**  
   距离图加相关性图、交互图加相关性图等双图组合，通常优于许多单图模型。

5. **STMGCN 优于传统机器学习、时间序列神经网络和已有图模型。**  
   其整体表现优于 HA、SVR、BPNN、LSTM、GRU、T-GCN 和 DCRNN。

6. **模型具有较好的稳健性。**  
   重复实验、残差分析和输入扰动实验表明，STMGCN 的结果较为稳定，对一定程度的输入噪声不敏感。

7. **预测期限越长，任务难度越高。**  
   当预测期限从1小时增加到3小时时，RMSE 和 MAE 上升，\(R^2\) 下降。

### M3: Finance + Shipping

P066 is most directly relevant to M3.

Two versions of M3 should be distinguished:

#### M3-Flat

Use engineered PortWatch variables as ordinary tabular features:

\[
X_t^{M3}
=
[X_t^{financial},X_t^{shipping}]
\]

Examples include:

- tanker count at each chokepoint;
- tanker capacity at each chokepoint;
- weekly percentage change;
- rolling averages;
- congestion indicators;
- anomalies relative to historical averages.

#### M3-Graph

Represent shipping observations as:

\[
X_{\text{ship},t}\in\mathbb{R}^{N\times F}
\]

where:

- \(N\) is the number of ports, terminals, or chokepoints;
- \(F\) is the number of node-level shipping features.

The Shipping Encoder produces:

\[
z_{\text{ship},t}
=
f_{\text{ship}}
(X_{\text{ship},t-L:t},A)
\]

The oil-price forecast is then:

\[
\hat{r}_{t+1}
=
f(z_{\text{fin},t},z_{\text{ship},t})
\]

The comparison:

\[
M3\text{-Flat}
\quad\text{vs.}\quad
M3\text{-Graph}
\]

tests whether preserving shipping-network structure adds value beyond using the same shipping information as flat variables.

中文：

P066 与 M3 的关系最直接。

M3 可以分为两个版本。

#### M3-Flat：扁平航运特征

将 PortWatch 工程特征作为普通数值变量：

\[
X_t^{M3}
=
[X_t^{financial},X_t^{shipping}]
\]

变量可以包括：

- 各咽喉点的 tanker count；
- 各咽喉点的 tanker capacity；
- 周度变化率；
- 移动平均；
- 港口拥堵指标；
- 相对于历史均值的异常程度。

#### M3-Graph：航运图表示

将航运数据表示为：

\[
X_{\text{ship},t}\in\mathbb{R}^{N\times F}
\]

其中：

- \(N\) 为港口、终端或咽喉点数量；
- \(F\) 为每个节点的航运特征数量。

航运编码器生成：

\[
z_{\text{ship},t}
=
f_{\text{ship}}
(X_{\text{ship},t-L:t},A)
\]

然后进行油价预测：

\[
\hat{r}_{t+1}
=
f(z_{\text{fin},t},z_{\text{ship},t})
\]

比较：

\[
M3\text{-Flat}
\quad\text{vs.}\quad
M3\text{-Graph}
\]

可以检验：在使用相同航运信息的情况下，保留航运网络结构是否优于扁平变量拼接。
