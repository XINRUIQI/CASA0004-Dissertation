## Core Method / 核心方法

- **Model / 模型**: CFFormer, a Cross-Fusion Transformer framework.
  - EN: The model adopts a parallel dual-stream encoder to extract features separately from optical images and complementary modalities such as SAR or DSM.
  - CN: 模型采用平行双流编码器，分别提取 optical image 与 SAR / DSM 等辅助模态的特征。

- **Backbone / 主干网络**: BiFormer-based Transformer encoder.
  - EN: The encoder uses Transformer-based BiFormer networks to capture long-range spatial dependencies in remote-sensing images.
  - CN: 编码器基于 BiFormer Transformer，用于捕捉遥感图像中的长距离空间依赖关系。

- **Feature Correction Module (FCM) / 特征校正模块**:
  - EN: FCM corrects modality-specific features using information from the other modality in both spatial and channel dimensions.
  - CN: FCM 在 spatial-wise 和 channel-wise 两个维度上，用另一模态的信息校正当前模态特征。
  - EN: Spatial-wise correction handles local appearance and spatial inconsistencies.
  - CN: 空间校正主要处理局部外观差异与空间不一致。
  - EN: Channel-wise correction handles global semantic and channel-level differences.
  - CN: 通道校正主要处理全局语义差异与特征通道重要性差异。

- **Feature Fusion Module (FFM) / 特征融合模块**:
  - EN: FFM uses multihead cross-attention to globally interact and fuse corrected features from different modalities.
  - CN: FFM 使用 multihead cross-attention，在全局尺度上交互并融合不同模态的校正后特征。
  - EN: It is designed to avoid the limitations of simple addition or concatenation, which may cause redundancy and fail to model nonlinear cross-modal relationships.
  - CN: 它避免了简单相加或拼接带来的特征冗余问题，并能建模复杂的非线性跨模态关系。

- **Decoder / 解码器**:
  - EN: The decoder aggregates multi-scale fused features and upsamples them to generate pixel-level segmentation maps.
  - CN: 解码器汇聚多尺度融合特征，并上采样生成像素级语义分割图。

## Key Findings / 主要发现

1. **Multisource remote-sensing data are complementary but noisy.**  
   **多源遥感数据具有互补性，但也存在噪声和模态差异。**

   - EN: Optical images provide rich spectral and texture information, while SAR provides backscatter and geometric information, and DSM provides elevation information.
   - CN: 光学影像提供光谱与纹理信息，SAR 提供后向散射与几何结构信息，DSM 提供高度信息。
   - EN: However, different sensors also introduce inconsistency and interference noise, so naive fusion may not work well.
   - CN: 但不同传感器也会带来不一致性和干扰噪声，因此简单融合不一定有效。

2. **Dual-stream modality-specific encoding is more appropriate than early concatenation.**  
   **双流模态专属编码比 early concatenation 更合理。**

   - EN: CFFormer extracts optical and SAR/DSM features through separate branches before interaction.
   - CN: CFFormer 先用不同分支分别提取 optical 与 SAR/DSM 特征，再进行交互。
   - EN: This supports the idea that heterogeneous modalities should first be represented in their own feature spaces.
   - CN: 这说明异质模态应先在各自的特征空间中被编码，而不是一开始就粗暴拼接。

3. **FCM improves multimodal fusion by correcting spatial and channel-level discrepancies.**  
   **FCM 通过校正空间与通道差异提升多模态融合效果。**

   - EN: Ablation results show that adding FCM improves mIoU and OA.
   - CN: 消融实验显示，加入 FCM 能提升 mIoU 和 OA。
   - EN: The best correction order is spatial-wise correction first, followed by channel-wise correction.
   - CN: 最优校正顺序是先做 spatial-wise correction，再做 channel-wise correction。
   - EN: This suggests that local spatial differences between modalities should be reduced before global semantic/channel differences are handled.
   - CN: 这说明应先处理模态之间更直观的局部空间差异，再处理更抽象的全局语义或通道差异。

4. **Cross-attention fusion outperforms simple addition or concatenation.**  
   **Cross-attention 融合优于简单相加或拼接。**

   - EN: The ablation study compares Add, Concat, and CrossAttn variants.
   - CN: 消融实验比较了 Add、Concat 和 CrossAttn 三种融合方式。
   - EN: CrossAttn achieves the best segmentation accuracy because it models global sequence-to-sequence interactions between modalities.
   - CN: CrossAttn 效果最好，因为它能从 sequence-to-sequence 角度建模不同模态之间的全局交互关系。

5. **CFFormer achieves strong performance across three benchmark datasets.**  
   **CFFormer 在三个多源遥感数据集上取得较强表现。**

   - EN: On WHU-OPT-SAR, CFFormer achieves mIoU = 58.0% and OA = 85.35%.
   - CN: 在 WHU-OPT-SAR 上，CFFormer 达到 mIoU = 58.0%、OA = 85.35%。
   - EN: On Vaihingen, it achieves mIoU/OA = 84.31%/91.88%.
   - CN: 在 Vaihingen 上，达到 mIoU/OA = 84.31%/91.88%。
   - EN: On Potsdam, it achieves mIoU/OA = 88.62%/92.64%.
   - CN: 在 Potsdam 上，达到 mIoU/OA = 88.62%/92.64%。

## Limitations / 局限性

1. **Different task from oil-price forecasting / 任务不同**
   - EN: The paper focuses on semantic segmentation, not commodity price forecasting.
   - CN: 该文研究的是语义分割，不是大宗商品或原油价格预测。
   - EN: Therefore, it cannot directly prove that EO/SAR features improve Brent or WTI forecasting.
   - CN: 因此它不能直接证明 EO/SAR 特征能提升 Brent 或 WTI 预测。

2. **Image-level spatial task, not temporal forecasting / 图像空间任务，不是时间序列预测**
   - EN: CFFormer models spatial pixel-level relationships, while oil-price forecasting requires temporal and financial-market dynamics.
   - CN: CFFormer 建模的是像素级空间关系，而油价预测需要建模时间序列和金融市场动态。

3. **No market, macro, or geopolitical variables / 不包含市场、宏观或地缘政治变量**
   - EN: The paper only uses remote-sensing modalities such as optical, SAR, and DSM.
   - CN: 该文只使用 optical、SAR、DSM 等遥感模态。
   - EN: It does not address how to fuse remote-sensing data with macro-financial or text-based uncertainty indicators.
   - CN: 它没有处理遥感数据如何与宏观金融变量或文本不确定性指标融合。

4. **High data and computation requirements / 数据与计算需求较高**
   - EN: CFFormer is trained on benchmark segmentation datasets with pixel-level labels.
   - CN: CFFormer 在有像素级标签的遥感分割数据集上训练。
   - EN: In oil forecasting, labelled samples are usually much fewer, so fully end-to-end training may be difficult.
   - CN: 在油价预测中，可用标签样本通常更少，因此完整端到端训练可能更难。

5. **Remote-sensing contribution must be validated by project-specific ablation / 遥感贡献必须通过你的项目消融验证**
   - EN: The paper supports the architecture, but not the empirical forecasting value of EO/SAR for oil prices.
   - CN: 该文支持的是架构设计，而不是 EO/SAR 对油价预测的实证有效性。
   - EN: Your dissertation still needs ablation tests to prove whether M4 improves forecasting accuracy.
   - CN: 你的论文仍需通过消融实验验证 M4 是否真正提升预测精度。
