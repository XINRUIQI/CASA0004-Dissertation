## Core Method / 核心方法

- **Model / 模型**: ShaSpec (Shared-Specific Feature Modelling), a multi-modal learning framework designed for missing-modality scenarios.

  ShaSpec（共享-专属特征建模），用于处理多模态学习中的模态缺失问题。

- **Main idea / 核心思想**: Each modality is decomposed into two types of representations:

  1. shared features, which capture modality-robust information;
  2. specific features, which preserve modality-specific information.

  每个模态被拆分为两类表示：

  1. shared features：学习不同模态之间共同、稳健的信息；
  2. specific features：保留每个模态自身独有的信息。

- **Architecture / 架构**: One shared encoder + modality-specific encoders + projection layer + residual fusion + decoder/classifier.

  一个共享编码器 + 每个模态各自的专属编码器 + 特征投影层 + 残差融合 + 解码器/分类器。

- **Missing modality handling / 缺失模态处理**: When one modality is missing, ShaSpec does not reconstruct the raw missing input. Instead, it generates the missing modality embedding from the average of available shared features.

  当某个模态缺失时，ShaSpec 不重建原始缺失数据，而是用已有模态的 shared features 平均生成缺失模态的 latent embedding。

- **Training objectives / 训练目标**: The total loss consists of:

  1. task loss for segmentation or classification;
  2. Distribution Alignment Objective (DAO), which encourages shared features from different modalities to be aligned;
  3. Domain Classification Objective (DCO), which encourages specific features to retain modality identity.

  总损失函数包括：

  1. 主任务损失，用于分割或分类；
  2. DAO 分布对齐损失，用于让不同模态的 shared features 更接近；
  3. DCO 域分类损失，用于让 specific features 保留模态身份信息。

- **Evaluation / 评估**: The paper evaluates ShaSpec under both full-modality and missing-modality settings, including dedicated and non-dedicated training.

  论文同时评估完整模态和缺失模态场景，并区分 dedicated training 与 non-dedicated training。

## Dataset / 数据集

- **BraTS2018**: Multi-modal brain tumour MRI segmentation dataset. Modalities include Flair, T1, T1 contrast-enhanced (T1c), and T2. The target is segmentation of enhancing tumour, tumour core, and whole tumour.

  BraTS2018 是多模态脑肿瘤 MRI 分割数据集。模态包括 Flair、T1、T1c 和 T2。预测目标是 enhancing tumour、tumour core 和 whole tumour 三类肿瘤区域。

- **Audiovision-MNIST**: A multi-modal classification dataset combining digit images and spoken digit audio. The image modality comes from MNIST, while the audio modality is represented using MFCC features.

  Audiovision-MNIST 是图像 + 音频的多模态分类数据集。图像来自 MNIST，音频通过 MFCC 特征表示。

- **OpenI X-ray + clinical text**: The paper also includes an additional experiment using frontal X-ray images and clinical text reports.

  论文还额外使用 OpenI 数据集进行 X-ray 图像 + 临床文本的分类实验。

## Key Findings / 主要发现

1. **ShaSpec significantly improves performance under missing-modality settings.**

   ShaSpec 在缺失模态条件下显著提升模型表现。

   On BraTS2018, ShaSpec outperforms competing methods such as U-HeMIS, U-HVED, Robust-MSeg, and mmFormer across most missing-modality combinations.

   在 BraTS2018 上，ShaSpec 在大多数缺失模态组合下优于 U-HeMIS、U-HVED、Robust-MSeg 和 mmFormer 等方法。

2. **Shared-specific feature modelling is more effective than simple feature fusion.**

   shared-specific 特征建模比简单特征拼接更有效。

   The model explicitly separates modality-robust shared information from modality-specific information, allowing the model to use both cross-modal commonality and modality uniqueness.

   该模型显式区分跨模态共享信息和模态专属信息，因此既能利用不同模态之间的共同信号，也能保留每个模态独有的信息。

3. **The method handles missing modalities without reconstructing raw data.**

   该方法不需要重建原始缺失模态。

   Instead of generating missing MRI images, audio files, or text, ShaSpec fills the missing modality at the representation level using available shared features.

   ShaSpec 不是生成缺失的 MRI 图像、音频或文本，而是在 latent representation 层面补足缺失模态。

4. **A single non-dedicated model can handle multiple missing-modality combinations.**

   一个 non-dedicated 模型可以处理多种模态缺失组合。

   This avoids the need to train a separate model for every possible missing-modality pattern.

   这避免了为每一种缺失组合单独训练模型的麻烦。

5. **Auxiliary losses are important but should not dominate the main task.**

   辅助损失有用，但不能压过主任务。

   The paper finds that small weights for DAO and DCO improve performance, while overly large weights can disturb the optimisation of the main segmentation/classification task.

   论文发现，DAO 和 DCO 的权重较小时有助于提升表现，但权重过大时会干扰主任务优化。

6. **The framework is task-flexible.**

   该框架具有任务适配性。

   ShaSpec is tested on both segmentation and classification, suggesting that the shared-specific design is not tied to one specific task type.

   ShaSpec 同时在分割和分类任务上测试，说明 shared-specific 设计并不局限于某一种任务。

## Implications for M1–M4 Oil Price Forecasting / 对 M1–M4 石油价格预测的借鉴意义

### 1. M1–M4 can be treated as four modalities / M1–M4 可以被定义为四个模态

- **M1: Market and financial variables**

  Brent/WTI returns, futures basis, volatility, USD index, interest rates, inventories.

  **M1：市场与金融变量**

  Brent/WTI 收益率、期货基差、波动率、美元指数、利率、库存等。

- **M2: Text and geopolitical risk**

  News embeddings, GPR, OPEC statements, sanction-related narratives, conflict events.

  **M2：文本与地缘政治风险**

  新闻 embedding、GPR、OPEC 声明、制裁叙事、冲突事件等。

- **M3: Shipping and AIS/PortWatch**

  Tanker counts, tanker capacity, chokepoint activity, port congestion, vessel movement indicators.

  **M3：航运与 AIS/PortWatch**

  油轮数量、油轮载重能力、咽喉通道活动、港口拥堵、船舶活动指标等。

- **M4: Remote sensing and SAR**

  SAR-based dark vessel detection, oil storage proxies, port-level remote sensing signals.

  **M4：遥感与 SAR**

  SAR 暗船检测、储油代理变量、港口遥感信号等。

---

### 2. Missing modality should be expected rather than treated as an exception / 模态缺失应该被视为常态，而不是异常

In the oil price forecasting project, complete-case modelling may waste many observations because some modalities are naturally sparse or delayed.

在油价预测项目中，如果强行使用 complete-case，很可能会浪费大量样本，因为某些模态天然存在稀疏、延迟或缺失问题。

ShaSpec suggests a better strategy:

ShaSpec 提供了更合理的策略：

- use available modalities whenever they exist;
- randomly drop modalities during training to improve robustness;
- generate missing modality embeddings in the latent space;
- avoid reconstructing raw missing data.

- 有哪些模态就用哪些模态；
- 训练时随机 drop 一些模态，提高模型稳健性；
- 在 latent space 中生成缺失模态表示；
- 避免重建原始缺失数据。

---

### 3. The project should not try to reconstruct raw AIS, SAR, or text data / 项目不应优先尝试重建原始 AIS、SAR 或文本数据

For oil forecasting, it is unrealistic to reconstruct SAR images from financial variables, or reconstruct AIS vessel movements from news text.

在油价预测中，用金融变量重建 SAR 图像，或用新闻文本重建 AIS 船舶轨迹，并不现实。

A better approach is representation-level completion:

更合理的方法是在表示层补全：

```python
# Conceptual pseudo-code / 概念伪代码

for each available modality m:
    r_m = shared_encoder(x_m)
    s_m = specific_encoder_m(x_m)
    f_m = projection([r_m, s_m]) + r_m

for each missing modality k:
    f_k = average(available shared features)

y_hat = forecasting_head([f_M1, f_M2, f_M3, f_M4])
```

This follows the ShaSpec logic and is more suitable for heterogeneous oil-market data.

这与 ShaSpec 的逻辑一致，也更适合异构的油价预测数据。

### 4. The shared feature space can be interpreted as a latent oil shock space / shared feature space 可以解释为潜在油价冲击空间

The shared representation may capture cross-modal oil-market drivers such as:

shared representation 可以理解为捕捉跨模态共同油价驱动因素，例如：

- global demand shock / 全球需求冲击
- supply disruption / 供应中断
- geopolitical tension / 地缘政治紧张
- transport bottleneck / 运输瓶颈
- inventory pressure / 库存压力
- risk-on or risk-off sentiment / 风险偏好或避险情绪

The specific representation can capture modality-unique signals such as:

specific representation 可以捕捉每个模态独有的信号，例如：

- M1: futures basis, OVX, DXY, inventory surprises
- M2: geopolitical narratives, sanctions, OPEC tone

- M4: SAR dark vessels, storage-tank changes, port-level imagery

- M1：期货基差、OVX、DXY、库存意外

- M4：SAR 暗船、储油罐变化、港口遥感图像

## Limitations / 局限性

1. **No oil price forecasting task**

   **没有直接做油价预测**

   The paper does not test crude oil prices, Brent, WTI, commodities, or financial time-series forecasting.

   该论文没有测试原油价格、Brent、WTI、大宗商品或金融时间序列预测。

2. **No regression experiment**

   **没有回归实验**

   The experiments focus on segmentation and classification. Regression is mentioned as a possible future direction, not as an empirically validated setting.

   论文主要验证分割和分类任务。回归只是未来方向，并不是已经验证过的任务。

3. **Different data domain**

   **数据领域不同**

   The main datasets are medical imaging and digit audio-image classification, which are very different from oil-market data.

   论文主要数据集是医学影像和数字图像-音频分类，与油价市场数据存在明显差异。

4. **Simple missing feature generation**

   **缺失模态生成方式较简单**

   Missing modality embeddings are generated by averaging available shared features. This is simple and efficient, but may be too crude for complex oil-market dynamics.

   论文使用已有 shared features 的平均值生成缺失模态 embedding，这种方法简单高效，但对复杂油价动态可能略显粗糙。

5. **No temporal forecasting design**

   **没有专门的时间序列预测结构**

   The paper does not address rolling windows, forecast horizons, temporal leakage, non-stationarity, or regime shifts, all of which are important for oil price forecasting.

   论文没有讨论 rolling window、预测期、时间泄漏、非平稳性或 regime shift，而这些都是油价预测中的关键问题。

6. **No economic interpretability**

   **缺乏经济解释框架**

   The paper visualises shared and specific features using t-SNE, but it does not provide an economic interpretation framework comparable to SHAP analysis or causal reasoning.

   论文使用 t-SNE 可视化 shared/specific features，但没有提供类似 SHAP 或因果解释的经济解释框架。
