## Research Motivation / 研究动机

### English

Modern machine-learning models, such as ensemble models and deep neural networks, often achieve high predictive accuracy but are difficult to interpret. This creates a tension between predictive performance and interpretability.

Before this paper, several local explanation methods had already been proposed, including LIME, DeepLIFT, Layer-wise Relevance Propagation, Shapley regression values, Shapley sampling values, and Quantitative Input Influence. However, the relationships among these methods were unclear, and different methods could produce inconsistent feature-attribution results.

The paper therefore asks:

1. Can existing model-explanation methods be placed within a common theoretical framework?
2. What properties should a reliable feature-attribution method satisfy?
3. Is there a unique attribution method satisfying these properties?
4. Can Shapley-value explanations be computed efficiently for complex models?

### 中文

现代机器学习模型，例如集成学习模型和深度神经网络，通常能够获得较高的预测精度，但其内部决策过程难以解释，由此形成预测准确性与模型可解释性之间的矛盾。

在本文发表之前，已经存在 LIME、DeepLIFT、逐层相关性传播、Shapley regression values、Shapley sampling values 和 Quantitative Input Influence 等局部解释方法。但是，这些方法之间的关系并不清楚，而且不同方法可能对同一个预测给出不同甚至相互矛盾的变量贡献结果。

因此，本文主要回答以下问题：

1. 能否把已有的模型解释方法放入一个统一的理论框架？
2. 一个可靠的特征归因方法应当满足哪些性质？
3. 是否存在同时满足这些性质的唯一归因方法？
4. 如何高效计算复杂模型的 Shapley-value 解释？

## Core Method / 核心方法

### Model or Framework / 模型或框架

- **English**: SHAP, or SHapley Additive exPlanations, is a unified framework for assigning each input feature an attribution value for a particular model prediction.
- **中文**：SHAP，即 Shapley Additive Explanations，是一个基于 Shapley value 的统一特征归因框架，用于衡量每个输入变量对某一次具体模型预测的贡献。

SHAP is not itself a forecasting model. It is a post-hoc explanation method applied to an already trained model.

SHAP 本身不是预测模型，而是应用于已训练模型的事后解释方法。

---

## Original Model and Explanation Model / 原始模型与解释模型

The paper distinguishes between:

本文区分了两类模型：

1. **Original prediction model \(f\) / 原始预测模型 \(f\)**  
   The complex model whose prediction needs to be explained, such as an ensemble model, neural network, or other machine-learning model.  
   即需要被解释的复杂预测模型，例如集成模型、神经网络或其他机器学习模型。

2. **Explanation model \(g\) / 解释模型 \(g\)**  
   A simpler interpretable model that approximates and decomposes the prediction of \(f\).  
   即一个较简单、可以理解的模型，用于近似并分解原始模型的预测。

The additive explanation model is written as:

加性解释模型写为：

\[
g(z') = \phi_0 + \sum_{i=1}^{M}\phi_i z'_i
\]

where:

其中：

- \(z'_i\): whether feature \(i\) is present in the simplified input / 特征 \(i\) 是否存在于简化输入中；
- \(\phi_0\): baseline or expected model output / 基准预测或模型期望输出；
- \(\phi_i\): contribution of feature \(i\) to the current prediction / 特征 \(i\) 对当前预测的贡献；
- \(M\): number of input features / 输入特征数量。

For a particular observation, the prediction can be decomposed as:

对于某一个具体样本，模型预测可以分解为：

\[
f(x) = \phi_0 + \phi_1 + \phi_2 + \cdots + \phi_M
\]

Therefore:

因此：

> Prediction = baseline prediction + sum of feature contributions  
> 模型预测 = 基准预测 + 所有特征贡献之和

## Shapley-Value Interpretation / Shapley 值的解释

### English

SHAP is based on the Shapley value from cooperative game theory.

The model prediction is treated as the total payoff of a cooperative game, while individual features are treated as players. The contribution of a feature depends on how much the model prediction changes when that feature is added to a particular subset of other features.

Because the marginal contribution of a feature may depend on which other features are already present, SHAP considers all possible feature subsets or feature orderings and calculates a weighted average of the feature's marginal contributions.

### 中文

SHAP 的理论基础来自合作博弈论中的 Shapley value。

在这一框架中：

- 模型预测被视为合作博弈产生的总收益；
- 每一个输入变量被视为一个参与合作的玩家；
- 某变量的贡献等于该变量加入某个变量组合之后，模型预测值发生的变化。

一个变量的边际贡献通常取决于其他哪些变量已经进入模型。因此，SHAP 不只计算某一种变量加入顺序，而是考虑所有可能的变量组合或加入顺序，并对该变量的边际贡献进行加权平均。

The formal Shapley-value attribution is:

Shapley 特征归因可以写为：

\[
\phi_i =
\sum_{S \subseteq F \setminus \{i\}}
\frac{|S|!(|F|-|S|-1)!}{|F|!}
\left[
f_{S\cup\{i\}}(x_{S\cup\{i\}})
-
f_S(x_S)
\right]
\]

where \(S\) is a subset of features that does not contain feature \(i\).

其中，\(S\) 表示不包含特征 \(i\) 的其他特征子集。

## Three Core Properties / 三项核心性质

The most important theoretical contribution of the paper is the proof that SHAP is the unique additive feature-attribution method satisfying three desirable properties.

本文最重要的理论贡献，是证明 SHAP 是唯一同时满足以下三项性质的加性特征归因方法。

### 1. Local Accuracy / 局部准确性

\[
f(x) = g(x') = \phi_0 + \sum_{i=1}^{M}\phi_i x'_i
\]

### English

For the observation being explained, the sum of the baseline value and all feature attributions must exactly equal the original model prediction.

### 中文

对于当前被解释的样本，基准值与所有变量贡献之和必须严格等于原始模型的预测结果。

This ensures that SHAP provides a complete numerical decomposition of the prediction.

这保证了 SHAP 能够对模型预测进行完整的数值分解。

---

### 2. Missingness / 缺失性

\[
x'_i = 0 \Rightarrow \phi_i = 0
\]

### English

If a feature is absent from the simplified input, it must receive zero attribution.

### 中文

如果某个变量在简化输入中不存在，那么该变量的贡献必须为零。

---

### 3. Consistency / 一致性

### English

If a model changes so that a feature's marginal contribution increases or remains unchanged for every possible feature subset, the attribution assigned to that feature must not decrease.

### 中文

如果模型发生变化，使某个变量在所有可能变量组合中的边际贡献都增加或保持不变，那么解释方法分配给该变量的贡献不能反而下降。

The paper proves that only the Shapley-value solution satisfies local accuracy, missingness, and consistency simultaneously within the class of additive feature-attribution methods.

论文证明，在加性特征归因方法中，只有 Shapley-value 解能够同时满足局部准确性、缺失性和一致性。

---

## Methods Unified by SHAP / SHAP 统一的解释方法

The paper shows that six previously developed explanation methods belong to the same class of additive feature-attribution methods:

论文指出，以下六种已有解释方法都属于加性特征归因方法：

1. **LIME**
2. **DeepLIFT**
3. **Layer-wise Relevance Propagation**
4. **Shapley regression values**
5. **Shapley sampling values**
6. **Quantitative Input Influence**

### English

Although these methods appear different, they all explain a complex prediction through a simpler additive explanation model.

The paper argues that methods not based on the correct Shapley-value solution may violate local accuracy or consistency.

### 中文

尽管这些方法表面上具有不同的计算方式，但它们都使用一个较简单的加性解释模型来分解复杂模型预测。

本文指出，如果某种方法没有得到正确的 Shapley-value 解，就可能违反局部准确性或一致性，从而产生不符合直觉的特征归因结果。

## SHAP Estimation Methods / SHAP 估计方法

Exact Shapley-value computation is computationally expensive because it requires considering a large number of feature subsets. The paper therefore introduces or discusses several approximation methods.

精确计算 Shapley value 的成本很高，因为需要考虑大量变量组合。为此，论文提出或讨论了多种近似计算方法。

### 1. Shapley Sampling Values

- **English**: A model-agnostic sampling approximation based on permutations of features.
- **中文**：一种模型无关的抽样近似方法，通过抽取变量加入顺序估计 Shapley value。

The method avoids retraining the model for every possible feature subset but may still require many model evaluations.

该方法避免对每一个变量组合重新训练模型，但仍可能需要大量模型调用。

---

### 2. Kernel SHAP

- **English**: A model-agnostic method that recovers Shapley values through specially weighted linear regression.
- **中文**：一种模型无关方法，通过带有特殊 Shapley kernel 权重的线性回归估计 Shapley values。

Kernel SHAP modifies the LIME regression framework by selecting a theoretically derived weighting kernel rather than relying on heuristic weights.

Kernel SHAP 对 LIME 的局部线性回归框架进行了修改，使用理论推导得到的 Shapley kernel，而不是启发式选择权重。

The Shapley kernel is:

Shapley kernel 为：

\[
\pi_{x'}(z')
=
\frac{M-1}
{\binom{M}{|z'|}|z'|(M-|z'|)}
\]

Kernel SHAP jointly estimates all feature attributions through weighted least squares.

Kernel SHAP 通过加权最小二乘同时估计所有变量的贡献。

---

### 3. Linear SHAP

For a linear model:

对于线性模型：

\[
f(x) = \sum_{j=1}^{M}w_jx_j+b
\]

under the feature-independence approximation:

在特征独立近似下：

\[
\phi_i = w_i(x_i-E[x_i])
\]

### English

The SHAP contribution depends both on the model coefficient and on how far the current feature value is from its expected value.

### 中文

变量的 SHAP 贡献不仅取决于线性模型系数，还取决于当前变量取值相对于其期望值的偏离程度。

---

### 4. Low-Order SHAP

- **English**: An approximation suitable for a small number of features or low-order feature interactions.
- **中文**：适合变量数量较少或只考虑低阶变量交互的近似方法。

---

### 5. Max SHAP

- **English**: A model-specific method for efficiently computing attributions for maximum functions.
- **中文**：针对最大值函数设计的高效模型专用归因方法。

This is particularly relevant to operations such as max pooling in neural networks.

该方法主要与神经网络中的 max-pooling 等操作有关。

---

### 6. Deep SHAP

- **English**: A compositional approximation that combines DeepLIFT-style backpropagation with Shapley-value principles.
- **中文**：一种将 DeepLIFT 式反向传播与 Shapley-value 原理结合起来的组合式近似方法。

Deep SHAP calculates SHAP approximations for individual network components and propagates them backward through the network.

Deep SHAP 先计算神经网络局部组件的 SHAP 近似，再通过网络结构向后传播，从而获得整个模型的特征贡献。

实证检验主要包括三个部分：

The paper compares:

论文比较了：

使用了两种模型设定：

## Key Findings / 核心发现

### 1. Existing explanation methods can be unified

**English**: LIME, DeepLIFT, Layer-wise Relevance Propagation, and several Shapley-based methods can all be interpreted as additive feature-attribution methods.

**中文**：LIME、DeepLIFT、逐层相关性传播以及多种 Shapley-based 方法都可以统一理解为加性特征归因方法。

---

### 2. SHAP is the unique theoretically justified additive attribution

**English**: Within the additive feature-attribution class, SHAP is the unique solution satisfying local accuracy, missingness, and consistency.

**中文**：在加性特征归因方法中，SHAP 是唯一同时满足局部准确性、缺失性和一致性的归因解。

---

### 3. Kernel SHAP improves model-agnostic estimation

**English**: Kernel SHAP uses a theoretically derived weighting kernel to estimate Shapley values more efficiently than direct sampling methods and more consistently than heuristic LIME explanations.

**中文**：Kernel SHAP 使用理论推导的权重核，在模型无关条件下，比直接 Shapley 抽样更高效，也比启发式 LIME 解释更符合 Shapley 理论。

---

### 4. SHAP explanations better align with human intuition

**English**: In simple allocation experiments, SHAP attributions are more consistent with human judgments than LIME and the original DeepLIFT method.

**中文**：在简单的贡献分配实验中，SHAP 的归因结果比 LIME 和原始 DeepLIFT 更符合人类判断。

---

### 5. SHAP explains individual predictions rather than only global model behaviour

**English**: SHAP decomposes a particular model output into a baseline prediction and feature-level contributions.

**中文**：SHAP 首先解释的是某一个具体预测，将该预测分解为基准值和各个变量的贡献，而不只是提供一个全局变量排序。

---

### 6. Local explanations can be aggregated into global importance

For feature \(j\), global SHAP importance may be calculated as:

对于变量 \(j\)，可以将局部 SHAP 取绝对值后汇总为全局重要性：

\[
I_j = \frac{1}{T}\sum_{t=1}^{T}|\phi_{j,t}|
\]

However, this global summary is an application of local SHAP values rather than the main theoretical object defined by the paper.

但是，这种全局重要性是对局部 SHAP values 的进一步汇总，而不是论文理论框架中的首要解释对象。

### Step 1: Train M1–M4 under the same forecasting design  
### 第一步：在相同预测设计下训练 M1–M4

Use the same:

统一使用：

- rolling or expanding training windows;
- 滚动窗口或扩展窗口；
- forecasting horizons;
- 预测期限；
- hyperparameter-tuning procedure;
- 超参数调优流程；
- out-of-sample evaluation period.
- 样本外评价期。

---

### Step 2: Evaluate forecast accuracy  
### 第二步：评价预测精度

Use:

使用：

- RMSE;
- MAE;
- MAPE, where appropriate;
- out-of-sample \(R^2\);
- directional accuracy;
- Diebold–Mariano tests.

These metrics answer:

这些指标回答：

> Do remote-sensing and shipping variables improve out-of-sample forecasting accuracy?  
> 遥感和航运变量是否提高了样本外预测精度？

SHAP does not answer this question by itself.

SHAP 本身不能回答预测是否改善。

---

### Step 3: Compute SHAP values on out-of-sample forecasts  
### 第三步：对样本外预测计算 SHAP

For each forecast origin \(t\), calculate:

对每一个预测时点 \(t\)，计算：

\[
f(x_t) = \phi_{0,t} + \sum_{j=1}^{M}\phi_{j,t}
\]

This allows every forecast to be decomposed into contributions from individual predictors.

这样可以将每一次预测分解为各个预测变量的贡献。

---

### Step 4: Aggregate variables into modality groups  
### 第四步：按数据模态汇总变量

For example:

例如：

\[
\Phi_{\text{Market},t}
=
\sum_{j\in\text{Market}}\phi_{j,t}
\]

\[
\Phi_{\text{Macro},t}
=
\sum_{j\in\text{Macro}}\phi_{j,t}
\]

\[
\Phi_{\text{Remote Sensing},t}
=
\sum_{j\in\text{Remote Sensing}}\phi_{j,t}
\]

\[
\Phi_{\text{Shipping},t}
=
\sum_{j\in\text{Shipping}}\phi_{j,t}
\]

This directly matches the M1–M4 multimodal research design.

这种汇总方式与 M1–M4 的多模态研究设计直接对应。

---

### Step 5: Report global importance  
### 第五步：报告全局重要性

Calculate mean absolute SHAP values:

## Limitations / 局限性

### 1. SHAP explains model behaviour, not causal effects  
### 1. SHAP 解释模型行为，而不是因果效应

A positive SHAP value means that a variable pushes the model prediction upward relative to the baseline.

正 SHAP 值意味着某变量相对于基准值推动模型给出更高预测。

It does not prove that the variable causes oil prices to rise.

这不能证明该变量在现实中导致油价上涨。

---

### 2. Dependence among features complicates attribution  
### 2. 变量相关性会使归因更加复杂

The theoretical SHAP definition uses conditional expectations:

理论上的 SHAP 定义使用条件期望：

\[
E[f(z)\mid z_S]
\]

However, practical implementations may approximate this using marginal expectations or feature-independence assumptions.

但是，实际计算可能通过边际期望或变量独立假设近似条件期望。

For highly correlated predictors, such as:

对于以下高度相关变量：

- Brent and WTI prices;
- Brent 与 WTI 价格；
- VIX and OVX;
- VIX 与 OVX；
- multiple futures contracts;
- 多个期限的期货合约；
- related shipping indices;
- 相互关联的航运指数；
- spatially neighbouring remote-sensing indicators;
- 空间相邻的遥感指标；
- multiple lags of the same variable;
- 同一变量的多个滞后项；

SHAP contributions may be divided, substituted, or redistributed among correlated variables.

SHAP 贡献可能在相关变量之间被分摊、替代或重新分配。

---

### 3. SHAP does not automatically solve multicollinearity  
### 3. SHAP 不能自动解决多重共线性

SHAP can reveal that the model relies on groups of related features, but it does not remove correlation from the input data.

SHAP 可以揭示模型依赖哪些相关变量组，但不会消除输入数据中的相关性。

Possible complementary methods include:

可结合的方法包括：

- correlation clustering;
- 相关性聚类；
- group-level SHAP;
- 变量组 SHAP；
- regularisation;
- 正则化；
- ablation tests;
- 消融实验；
- PCA within conceptually coherent variable groups.
- 在概念一致的变量组内部进行 PCA。

---

### 4. SHAP importance is not equivalent to predictive value  
### 4. SHAP 重要性不等同于预测增量价值

A variable can receive high SHAP importance because the fitted model uses it strongly, even if the model is overfitted.

即使模型发生过拟合，某变量仍可能因为被模型大量使用而获得较高 SHAP importance。

The predictive value of a variable must be verified through out-of-sample retraining and ablation tests.

变量是否具有预测增量价值，必须通过样本外重新训练和消融实验检验。

---

### 5. Feature selection can cause information leakage  
### 5. 使用 SHAP 筛选变量可能造成信息泄漏

If SHAP values are computed using the complete sample or the test period and then used to select variables, future information enters the model-selection process.

如果使用完整样本或测试期计算 SHAP，再依据 SHAP 筛选变量，就会把未来信息带入模型选择过程。

Feature selection must be conducted only within each training window.

变量筛选必须仅在每一个训练窗口内部完成。

---

### 6. Exact SHAP computation can be expensive  
### 6. 精确计算 SHAP 的成本较高

The number of possible feature subsets grows exponentially with the number of features.

可能的变量组合数量会随变量数呈指数增长。

Kernel SHAP may be computationally expensive for:

Kernel SHAP 在以下情况下可能计算成本较高：

- large datasets;
- 大型数据集；
- many predictors;
- 变量数量较多；
- repeated rolling-window estimation;
- 重复的滚动窗口训练；
- deep or computationally expensive forecasting models.
- 深度模型或单次预测成本较高的模型。

---

### 7. The paper does not develop a time-series SHAP framework  
### 7. 本文没有专门建立时间序列 SHAP 框架

The study does not directly address:

本文没有直接处理：

- temporal dependence;
- 时间依赖；
- lagged predictors;
- 滞后变量；
- rolling-window forecasting;
- 滚动窗口预测；
- structural breaks;
- 结构突变；
- regime changes;
- 市场状态切换；
- leakage from future observations.
- 未来信息泄漏。

These issues must be handled separately in the dissertation's forecasting design.

这些问题必须通过本项目的时间序列预测设计单独处理。

---

### 8. TreeSHAP is not the main method of this paper  
### 8. TreeSHAP 不是本文的核心方法

The 2017 paper establishes the general SHAP framework and discusses Kernel SHAP, Linear SHAP, Low-Order SHAP, Max SHAP, and Deep SHAP.

2017 年论文建立了 SHAP 的一般理论框架，并讨论了 Kernel SHAP、Linear SHAP、Low-Order SHAP、Max SHAP 和 Deep SHAP。

The efficient TreeSHAP algorithm commonly used for XGBoost and other tree ensembles was developed in subsequent work.

今天常用于 XGBoost 和其他树集成模型的高效 TreeSHAP 算法属于后续研究。

---

### 9. The experiments are not economic or energy-market applications  
### 9. 论文实验并非经济或能源市场应用

The empirical demonstrations use simulated decision trees, human-allocation tasks, and MNIST image classification.

论文实验使用模拟决策树、人类贡献分配任务和 MNIST 图像分类。

Therefore, the paper establishes the explanation methodology but does not demonstrate its validity specifically for oil-price forecasting.

因此，该文建立了模型解释方法，但没有专门检验其在油价预测中的有效性。

---

### 10. Global aggregation can hide time variation  
### 10. 全局汇总可能掩盖时间变化

Mean absolute SHAP values summarise overall model reliance but may hide:

平均绝对 SHAP 值可以概括模型的总体依赖程度，但可能掩盖：

- changing importance across market regimes;
- 不同市场状态下的重要性变化；
- changes across forecast horizons;
- 不同预测期限上的变化；
- differences between positive and negative oil-price movements;
- 油价上涨和下跌阶段的差异；
- unstable predictor importance over time.
- 变量重要性的时间不稳定性。

## SHAP-Based Feature Selection / 基于 SHAP 的变量筛选

SHAP may be used as an auxiliary feature-selection tool, but it should not be treated as an automatic selection rule.

SHAP 可以作为辅助变量筛选工具，但不应被视为自动变量选择规则。

A valid rolling-window procedure is:

合理的滚动窗口流程为：

1. Train M4 using only the current training window.  
   仅使用当前训练窗口训练 M4。

2. Calculate SHAP values using training or internal-validation observations.  
   使用训练集或内部验证集计算 SHAP。

3. Rank variables using mean absolute SHAP.  
   根据平均绝对 SHAP 对变量排序。

4. Select candidate top-\(K\) variables inside the training window.  
   在训练窗口内部选择候选 top-\(K\) 变量。

5. Retrain the reduced model.  
   重新训练精简模型。

6. Predict the next out-of-sample observation or test block.  
   预测下一条样本外观测或测试区间。

7. Move the rolling window and repeat the procedure.  
   移动滚动窗口并重复流程。

8. Report selection frequency and out-of-sample performance.  
   报告变量入选频率与样本外预测表现。

Variable-selection stability can be measured as:

变量筛选稳定性可以表示为：

\[
\text{Selection Frequency}_j
=
\frac{\text{Number of windows in which variable }j\text{ is selected}}
{\text{Total number of rolling windows}}
\]

This is more reliable than calculating a single full-sample SHAP ranking.

这比只计算一次全样本 SHAP 排名更加可靠。

## SHAP and PCA / SHAP 与 PCA

SHAP and PCA serve different purposes.

SHAP 与 PCA 解决的是不同问题。

| SHAP | PCA |
|---|---|
| Post-hoc model explanation / 模型训练后的解释方法 | Pre-processing dimensionality reduction / 模型训练前的降维方法 |
| Explains contribution to model output / 解释变量对模型输出的贡献 | Compresses correlated variables into orthogonal components / 将相关变量压缩为正交成分 |
| Retains original variable meanings / 保留原始变量含义 | Components may be difficult to interpret / 主成分可能难以解释 |
| Does not remove multicollinearity / 不消除共线性 | Reduces linear correlation / 减少线性相关性 |
| Depends on the fitted model / 依赖已训练模型 | Changes the model's input space / 改变模型输入空间 |

A useful robustness comparison could include:

可以进行以下稳健性比较：

- **M4-All**: all original variables;  
  使用全部原始变量；

- **M4-SHAP-selected**: variables selected within each training window;  
  在每个训练窗口内部使用 SHAP 筛选变量；

- **M4-PCA**: correlated variable groups replaced by principal components;  
  使用主成分替代高相关变量组；

- **M4-Regularised**: variable complexity controlled through regularisation or model constraints.  
  通过正则化或模型约束控制变量复杂度。

All versions should use the same forecasting windows, tuning budget, and evaluation period.

所有版本都应使用相同的预测窗口、调参预算和评价期。
