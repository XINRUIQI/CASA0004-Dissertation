# Reading Note — Paper 104: Lightweight Pre-trained Transformer for Remote Sensing Timeseries / 轻量级遥感时序预训练 Transformer

## Citation / 文献信息

Tseng, G., Cartuyvels, R., Zvonkov, I., Purohit, M., Rolnick, D., & Kerner, H. (2024). *Lightweight, Pre-trained Transformers for Remote Sensing Timeseries*. arXiv preprint arXiv:2304.14065v4.

- **DOI**: N/A / 未提供 DOI
- **Published**: arXiv v4, February 2024 / arXiv 第 4 版，2024 年 2 月
- **Model name**: Presto — Pretrained Remote Sensing Transformer
- **Paper type**: Remote sensing foundation model / self-supervised learning / masked autoencoder

## Core Method / 核心方法

- **Model / 模型**: Presto, a lightweight Transformer-based masked autoencoder designed for remote sensing pixel-timeseries.
  - 中文：Presto 是一个面向遥感像素时间序列的轻量级 Transformer masked autoencoder。
  - English: Presto is a lightweight Transformer-based masked autoencoder specifically designed for multi-sensor remote sensing pixel-timeseries.

- **Input unit / 输入单位**: Pixel-timeseries rather than full images.
  - 中文：模型不直接把遥感数据当作普通图像处理，而是以单个像素在多个时间点上的多源观测序列为输入。
  - English: Instead of treating remote sensing data as a single image, Presto models each pixel as a temporal sequence of multi-sensor observations.

- **Pre-training data / 预训练数据**:
  - 21.5 million global pixel samples.
  - 10m spatial resolution.
  - 12-month contiguous timeseries sampled from 2020–2021.
  - Dynamic variables: Sentinel-1 radar, Sentinel-2 multispectral bands, ERA5 climate reanalysis, NDVI, Dynamic World land-cover classes.
  - Static variables: SRTM topography/elevation and pixel location coordinates.
  - 中文：预训练数据覆盖全球 21.5M 个 10m 像素样本，每个样本包含连续 12 个月的多源遥感观测。

- **Tokenisation / 编码方式**:
  - Inputs are divided into channel groups according to sensor/source.
  - The model adds positional encoding, month encoding, and learnable channel-group encoding.
  - 中文：Presto 会区分不同传感器来源，例如 S1、S2、ERA5、NDVI、Dynamic World、地形和位置，并为时间月份、通道组和位置添加编码。
  - English: Presto explicitly encodes temporal position, seasonal month information, and sensor/channel identity.

- **Self-supervised objective / 自监督目标**:
  - Masked autoencoding: mask part of the input and reconstruct the missing values.
  - During downstream use, the decoder is discarded and only the encoder output is used.
  - 中文：预训练时遮挡部分时间点或传感器通道，让模型重建缺失信息；下游任务中只保留 encoder 作为特征提取器或可微调模型。
  - English: During pre-training, Presto reconstructs masked timesteps or sensor channels; for downstream tasks, only the encoder is retained.

- **Structured masking / 结构化遮挡**:
  - Random masking.
  - Channel-group masking.
  - Contiguous timestep masking.
  - Full timestep masking.
  - 中文：这一设计让模型适应遥感数据中常见的缺失问题，例如云遮挡、某些传感器缺失、某些月份没有观测。
  - English: These masking strategies make the model robust to missing timesteps, missing sensors, and incomplete remote sensing observations.

- **Downstream adaptation / 下游适配方式**:
  - PrestoR: frozen Presto encoder + linear/logistic regression.
  - PrestoRF: frozen Presto encoder + random forest.
  - PrestoFT: fine-tuned Presto encoder + prediction head.
  - 中文：文章证明 Presto 既可以作为 frozen feature extractor，也可以进行 full fine-tuning。
  - English: The paper demonstrates that Presto can be used either as a frozen feature extractor or as a fine-tuned encoder.

## Key Findings / 主要发现

1. **Presto can learn useful representations from multi-sensor remote sensing timeseries.**  
   **Presto 能从多源遥感时序中学习有效表示。**

   - 中文：相比只处理单张图像或单一传感器的遥感模型，Presto 直接利用时间维度、多传感器结构和地理位置元数据，能更好地适配遥感任务。
   - English: Unlike models that treat remote sensing data as single-timestep imagery, Presto leverages temporal dynamics, multi-sensor structure, and location metadata.

2. **Lightweight architecture can still achieve competitive performance.**  
   **轻量模型也能取得有竞争力的表现。**

   - 中文：Presto 参数量远小于大型 ViT / ResNet 类遥感基础模型，但在多种任务上仍表现良好，说明遥感任务不一定都需要超大模型。
   - English: Although Presto is much smaller than many ViT- or ResNet-based remote sensing models, it remains competitive across diverse downstream tasks.

3. **Structured masking improves robustness to missing data.**  
   **结构化遮挡增强了对缺失数据的鲁棒性。**

   - 中文：文章的消融实验显示，结合 channel-group masking、random masking、timestep masking 和 contiguous timestep masking 的策略优于单纯 random masking。
   - English: The ablation results show that combining structured masking strategies outperforms random masking alone.

4. **Pre-training is crucial for strong downstream performance.**  
   **预训练对下游效果非常关键。**

   - 中文：与随机初始化模型相比，预训练后的 Presto 在多个任务上显著提升表现。例如在 S2-Agri100 数据集上，预训练带来了明显的准确率提升。
   - English: Compared with a randomly initialized model, the pretrained Presto encoder achieves substantially stronger downstream performance.

5. **Frozen feature extraction is effective and computationally efficient.**  
   **冻结 encoder + 轻量预测头是有效且高效的方案。**

   - 中文：文章中 PrestoR 和 PrestoRF 只训练线性模型或随机森林，下游适配参数很少，但仍能达到较强结果。
   - English: PrestoR and PrestoRF train only simple downstream models on top of frozen Presto embeddings, making adaptation computationally efficient.

6. **Presto handles different input shapes and temporal resolutions.**  
   **Presto 可以处理不同输入形状和时间分辨率。**

   - 中文：虽然 Presto 预训练使用 12 个月时序，但它在 24 个时间点的 S2-Agri100 任务、单时间点图像任务 EuroSAT / TreeSatAI、以及回归任务上都能适配。
   - English: Although Presto is pretrained on 12-month sequences, it generalises to tasks with different temporal resolutions, single-timestep imagery, and regression targets.

## Application to Oil Price Forecasting Project / 对石油价格预测项目的具体借鉴

### 1. Use Presto-like EO embeddings as M4 remote-sensing features  
### 1. 将 Presto 类遥感 embedding 作为 M4 特征

- 中文：你的 M4 不应只停留在 “AOI 内 Sentinel-1 后向散射均值 / NDVI 均值 / 夜光强度” 这类手工变量，也可以加入 Presto encoder 输出的遥感 embedding。
- English: M4 should not only contain engineered EO variables such as SAR backscatter, NDVI, or nightlight intensity; it can also include pretrained EO embeddings from a Presto-like encoder.

Possible design:

```text
Oil-relevant AOI
    ↓
Sentinel-1 / Sentinel-2 / NDVI / ERA5 / location
    ↓
Frozen Presto encoder
    ↓
Pixel-level embeddings
    ↓
AOI-level pooling: mean / std / quantiles
    ↓
Weekly or monthly EO representation
    ↓
Fusion with M1 + M2 + M3
```

---

### 2. Use frozen encoder because oil-price samples are limited  
### 2. 因为油价样本少，应优先冻结 encoder

- 中文：2019–2025 的周频 Brent 样本只有几百个，如果直接端到端训练大型遥感模型，很容易过拟合。Presto 证明了 frozen encoder + simple downstream model 是合理方案。
- English: Weekly Brent observations from 2019–2025 provide only a few hundred samples, so training a large EO model end-to-end would likely overfit. Presto supports using a frozen EO encoder with a lightweight downstream model.

Recommended implementation:

```text
Frozen EO encoder:
    Presto / similar remote-sensing foundation model

Downstream model:
    Ridge
    Elastic Net
    XGBoost
    Random Forest
    TCN / small temporal fusion head
```

---

### 3. Use structured masking idea for multimodal missing-data robustness  
### 3. 借鉴 structured masking 处理多模态缺失

- 中文：你的 M1–M4 数据天然异步：Brent 和金融变量是日/周频，PortWatch 是日频，GFW/EMODnet 可能是月频，遥感影像不规则且受云影响。Presto 的 structured masking 可以迁移为 modality dropout。
- English: The dissertation combines asynchronous modalities: Brent and financial variables are daily/weekly, PortWatch is daily, GFW/EMODnet may be monthly, and satellite imagery is irregular and cloud-affected. Presto’s structured masking can inspire modality dropout.

Possible adaptation:

```text
During training:
    Randomly mask selected modalities:
        - M2 uncertainty/text
        - M3 shipping
        - M4 remote sensing
    Randomly mask selected AOIs:
        - Hormuz
        - Suez
        - Malacca
    Randomly mask selected timesteps:
        - missing EO weeks
        - delayed shipping observations

Goal:
    Train the fusion model to remain robust when some modalities or timesteps are unavailable.
```

---

### 4. Use AOI pooling rather than whole-image prediction  
### 4. 应采用 AOI 聚合，而不是整图预测

- 中文：Presto 是 pixel-timeseries 模型，不是整图 CNN/ViT。因此在你的项目中，更合理的方式是对油气相关 AOI 内的像素分别编码，然后聚合成区域级 embedding。
- English: Since Presto is a pixel-timeseries model rather than a whole-image CNN/ViT, the most appropriate use in this project is to encode pixels within oil-relevant AOIs and aggregate them into AOI-level embeddings.

Example:

```text
For each AOI a and week t:

z_a,t = Pooling(
    Presto(pixel_1,t),
    Presto(pixel_2,t),
    ...,
    Presto(pixel_N,t)
)

where Pooling can be:
    mean
    standard deviation
    median
    upper quantile
    temporal change
```

Then:

```text
z_EO,t = Attention or weighted pooling over:
    z_Hormuz,t
    z_Suez,t
    z_Malacca,t
    z_Fujairah,t
    z_Rotterdam,t
    z_Singapore,t
```

## Limitations / 局限性

1. **Not an oil-price forecasting paper / 不是油价预测论文**  
   - 中文：本文证明的是 Presto 在遥感任务中的表示学习能力，并没有直接证明遥感 embedding 能预测 Brent 或 WTI 油价。
   - English: The paper demonstrates representation learning for remote sensing tasks, but it does not directly test whether EO embeddings improve Brent or WTI oil-price forecasting.

2. **Pixel-timeseries model, not full-image model / 它是像素时序模型，不是完整图像模型**  
   - 中文：Presto 主要处理单像素时序。如果任务依赖空间形状、设施边界、船舶目标检测或港口结构识别，CNN/ViT/SAR detection 模型可能更合适。
   - English: Presto primarily processes pixel-level timeseries. For tasks requiring spatial shape, object detection, vessel detection, or infrastructure boundaries, CNN/ViT/SAR-specific models may be preferable.

3. **10m resolution limitation / 10m 分辨率限制**  
   - 中文：Presto 面向 Sentinel-1 / Sentinel-2 等 10m 级公开遥感产品，不适合直接处理 <1m 的商业高分辨率影像或无人机数据。
   - English: Presto is designed around 10m-scale public EO products such as Sentinel-1 and Sentinel-2, and does not natively handle very-high-resolution commercial or drone imagery.

4. **Temporal mismatch with oil markets / 与油价预测频率存在差异**  
   - 中文：Presto 预训练采用月度 12-step 时序，而油价预测通常是日频或周频，因此需要额外设计 weekly aggregation 或 temporal alignment。
   - English: Presto is pretrained on monthly 12-step sequences, whereas oil-price forecasting is often daily or weekly. Additional temporal aggregation and alignment are required.

5. **No causal interpretation / 不能直接提供因果解释**  
   - 中文：即使 Presto embedding 提高预测表现，也不能直接说明遥感状态变化因果性地影响油价，需要结合事件分析、滞后设计和消融检验。
   - English: Even if Presto embeddings improve forecasting accuracy, this does not imply a causal relationship between EO signals and oil prices. Event studies, lag design, and ablation tests are needed.

6. **Computational and data-preprocessing burden / 数据处理成本较高**  
   - 中文：虽然 Presto 模型轻量，但要构建油气 AOI 的 Sentinel-1/Sentinel-2/NDVI/ERA5 时序仍需要较多预处理、云处理、重采样和时序对齐。
   - English: Although Presto is lightweight, constructing AOI-level Sentinel-1/Sentinel-2/NDVI/ERA5 timeseries still requires substantial preprocessing, cloud filtering, resampling, and temporal alignment.

## Suggested Dissertation Paragraph / 可直接放入论文的段落

English:

Presto (Tseng et al., 2024) provides a useful methodological foundation for incorporating remote sensing data into the proposed multimodal oil-price forecasting framework. Unlike conventional image-based remote sensing models, Presto is designed for multi-sensor pixel-timeseries and uses a masked autoencoding objective to learn robust representations from incomplete temporal and sensor observations. This is particularly relevant to oil-market forecasting, where EO observations around ports, chokepoints, refineries, and storage hubs are irregular, cloud-affected, and temporally misaligned with financial and shipping data. In this dissertation, the Presto framework motivates the use of a frozen pretrained EO encoder to extract AOI-level remote-sensing embeddings, which can then be fused with market, uncertainty, and shipping variables. However, because Presto is not itself an oil-price forecasting model, its contribution is methodological rather than evidential: the predictive value of EO embeddings must be tested through Brent-specific ablation experiments.

中文：

Tseng 等人（2024）提出的 Presto 为本文将遥感数据纳入多模态油价预测框架提供了重要方法支撑。不同于传统将遥感影像视为单张图像的模型，Presto 面向多传感器像素时间序列，并通过 masked autoencoding 学习对缺失时间点和缺失传感器具有鲁棒性的遥感表征。这一点与油价预测任务高度相关，因为港口、海峡咽喉、炼厂和储油区周边的遥感观测往往存在云遮挡、重访周期不规则和与金融/航运数据频率不一致的问题。因此，本文可借鉴 Presto 的思想，使用冻结的预训练 EO encoder 提取 oil-related AOI 的遥感 embedding，再与市场变量、不确定性变量和航运变量进行融合。不过，Presto 本身并不是油价预测模型，因此它对本文的贡献主要是方法论层面的，遥感 embedding 是否具有 Brent 预测增益仍需要通过 M1–M4 消融实验进行验证。
