## Research Question / 研究问题

### English

The paper investigates how heterogeneous financial information from textual reports and numerical time series can be integrated without treating all inputs as one homogeneous feature table.

Its central research question is:

> Can a modality-aware Transformer that separately models within-modality patterns, cross-modality interactions, and target–modality dependencies improve financial time-series forecasting?

The authors specifically address three limitations of conventional multimodal forecasting models:

1. Different modalities are often concatenated or summed and then treated as one unified input stream.
2. Conventional self-attention does not explicitly distinguish intra-modal and inter-modal relationships.
3. Financial texts and numerical time series may have different sequence lengths, publication frequencies, and temporal alignments.

### 中文

本文研究如何在不破坏不同数据模态结构的前提下，将金融文本报告与数值时间序列共同用于预测。

其核心研究问题是：

> 一个分别建模模态内部规律、模态之间交互关系以及预测目标与各模态依赖关系的模态感知 Transformer，能否提高金融时间序列预测精度？

作者主要针对传统多模态预测方法的三个问题：

1. 不同模态往往被直接拼接或相加，并被当作同一种输入数据处理。
2. 普通自注意力机制无法明确区分模态内部关系与跨模态关系。
3. 金融文本和数值时间序列可能具有不同的数据长度、发布频率和时间对齐方式。

## Core Method / 核心方法

### Model / 模型

- **Proposed model**: Modality-aware Transformer, abbreviated as **MAT**
- **基础结构**：Transformer encoder–decoder architecture
- **主要创新模块**：
  1. Feature-level Attention
  2. Intra-modal Multi-Head Attention
  3. Inter-modal Multi-Head Attention
  4. Target-modal Multi-Head Attention

The model maintains separate streams for the textual and numerical time-series modalities rather than immediately concatenating them.

模型为文本模态和数值时间序列模态保留独立的信息流，而不是在输入阶段直接将所有特征拼接成一张表。

---

### 1. Feature-level Attention / 特征级注意力

For each modality, MAT first estimates the importance of individual input features:

\[
X^{att}_{mod_i}
=
\operatorname{softmax}
\left(
\operatorname{Conv1}(X_{mod_i})
\right)
\odot X_{mod_i}
\]

where:

- \(X_{mod_i}\) is the input from modality \(i\);
- \(\operatorname{Conv1}\) generates feature-attention scores;
- \(\odot\) denotes element-wise multiplication.

#### English interpretation

The feature-level attention mechanism allows the model to assign larger weights to predictive variables and smaller weights to irrelevant or noisy variables.

For the textual modality, the selected features are topic-level sentiment scores.

For the numerical modality, the selected features include macroeconomic and financial indicators.

#### 中文解释

特征级注意力允许模型对每个模态内部的变量进行动态加权：

- 对预测有用的变量获得较高权重；
- 信息较弱或噪声较大的变量获得较低权重。

在文本模态中，被选择的是不同经济主题的情绪分数。

在数值模态中，被选择的是不同宏观经济与金融指标。

这一机制回答：

> 在当前预测任务中，每个模态内部哪些变量最重要？

---

### 2. Intra-modal Multi-Head Attention / 模态内多头注意力

Intra-modal attention uses queries, keys, and values from the same modality:

\[
Q_{mod_i},K_{mod_i},V_{mod_i}
\]

\[
Attention^{intra}_{mod_i}
=
\operatorname{softmax}
\left(
\frac{Q_{mod_i}K_{mod_i}^{T}}
{\sqrt{d_k}}
\right)V_{mod_i}
\]

#### English interpretation

This component learns temporal dependencies within each modality separately.

For example:

- which previous FED reports are most relevant;
- which historical macroeconomic observations matter most;
- whether recent or more distant observations contain stronger forecasting information.

#### 中文解释

模态内注意力分别学习各模态自身的时间依赖关系。

例如：

- 历史上哪些月份的 FED 报告更重要；
- 哪些月份的宏观经济指标更重要；
- 最近信息和较早信息对预测目标的贡献是否不同。

这一机制回答：

> 每个模态自身的历史序列中，哪些时间点最重要？

---

### 3. Inter-modal Multi-Head Attention / 模态间多头注意力

Unlike intra-modal attention, inter-modal attention exchanges queries between modalities.

For example:

\[
Attention_{text\leftarrow ts}
=
\operatorname{softmax}
\left(
\frac{Q_{text}K_{ts}^{T}}
{\sqrt{d_k}}
\right)V_{ts}
\]

and:

\[
Attention_{ts\leftarrow text}
=
\operatorname{softmax}
\left(
\frac{Q_{ts}K_{text}^{T}}
{\sqrt{d_k}}
\right)V_{text}
\]

#### English interpretation

The text modality can query the numerical time-series modality, while the numerical modality can query the text modality.

This allows MAT to learn lagged and asynchronous relationships such as:

\[
\text{FED statement at }t-2
\rightarrow
\text{macroeconomic condition at }t-1
\rightarrow
\text{interest rate at }t
\]

#### 中文解释

在模态间注意力中：

- 文本模态可以查询数值时间序列；
- 数值时间序列也可以查询文本模态。

这使模型能够识别不同模态之间的交叉关系和滞后关系，例如：

\[
t-2\text{ 时期的政策文本}
\rightarrow
t-1\text{ 时期的宏观经济状态}
\rightarrow
t\text{ 时期的利率}
\]

这一机制回答：

> 一个模态中的信息，与另一个模态中哪些历史时间点最相关？

---

### 4. Target-modal Multi-Head Attention / 目标—模态多头注意力

The decoder first applies masked self-attention to the target sequence.

It then allows the target representation to query each modality separately:

\[
Attention_{target\leftarrow text}
=
\operatorname{softmax}
\left(
\frac{Q_{target}K_{text}^{T}}
{\sqrt{d_k}}
\right)V_{text}
\]

\[
Attention_{target\leftarrow ts}
=
\operatorname{softmax}
\left(
\frac{Q_{target}K_{ts}^{T}}
{\sqrt{d_k}}
\right)V_{ts}
\]

#### English interpretation

Instead of combining the two modalities into one representation before decoding, the target series independently extracts information from each modality.

This allows the model to learn which textual and numerical observations are most relevant for producing each forecast.

#### 中文解释

在解码阶段，目标利率序列分别从文本模态和数值模态中提取信息，而不是先把两个模态简单合并。

这一机制回答：

> 在生成目标预测值时，预测目标应该分别从每个模态中读取什么信息？

---

## Text Representation Module / 文本表示模块

### English

The original FED reports are not directly fed into MAT as raw documents.

The text-processing pipeline is:

1. Split each report into sentences.
2. Encode sentences using a pretrained language model.
3. Cluster sentence embeddings into economic topics.
4. Assign sentences to the corresponding topic clusters.
5. Use a domain-adapted financial BERT model to estimate sentence-level sentiment.
6. Average sentiment scores within each topic and time period.
7. Convert each report period into a topic-level sentiment vector.

The resulting textual input is:

\[
X^{text}_t
=
[s_{1,t},s_{2,t},\ldots,s_{K,t}]
\]

where \(s_{k,t}\) is the average sentiment score for topic \(k\) at time \(t\).

Example topics reported in the paper include:

| Topic | Representative words |
|---|---|
| Real estate | estate, real, construction |
| Labour market | workers, labor, wage |
| Credit conditions | loan, lending, credit |
| Agriculture | agriculture, crop, corn |
| Energy | oil, gas, drilling |
| COVID-19 | covid19, prepandemic, cases |

### 中文

原始 FED 报告并未直接以完整文本形式输入 MAT，而是先经过文本加工流程：

1. 将每份报告拆分为句子；
2. 使用预训练语言模型生成句子嵌入；
3. 根据句子嵌入进行经济主题聚类；
4. 将句子分配到相应的主题；
5. 使用金融领域适配的 BERT 计算句子情绪；
6. 在每个主题和时间段内计算平均情绪分数；
7. 将每个时期的文本转换为主题级情绪向量。

最终文本模态表示为：

\[
X^{text}_t
=
[s_{1,t},s_{2,t},\ldots,s_{K,t}]
\]

其中，\(s_{k,t}\) 表示时间 \(t\) 中第 \(k\) 个经济主题的平均情绪分数。

需要注意：

> 该论文并不是直接使用原始文本的完全端到端多模态模型，而是先将文本转换为主题情绪时间序列，再进行多模态融合。

## Target / 预测目标

The model forecasts U.S. interest rates for four maturities:

- 2-year interest rate;
- 5-year interest rate;
- 10-year interest rate;
- 30-year interest rate.

模型分别预测四种期限的美国利率：

- 2 年期利率；
- 5 年期利率；
- 10 年期利率；
- 30 年期利率。

### Forecasting horizons / 预测期限

- 1 month ahead;
- 3 months ahead;
- 6 months ahead.

对应：

- 未来 1 个月；
- 未来 3 个月；
- 未来 6 个月。

### Input window / 输入窗口

The main experiments use a 9-month lookback window:

\[
T=9
\]

The general forecasting task is:

\[
\hat{Y}_{t+1:t+T'}
=
F
\left(
X^{text}_{t-T+1:t},
X^{ts}_{t-T+1:t},
Y_{t-T+1:t}
\right)
\]

where \(T'\) is the prediction horizon.

## Training Setup / 训练设置

- **Training–validation–test split**: 70% / 15% / 15%
- **Normalisation**: zero-mean normalisation
- **Optimizer**: Adam
- **Initial learning rate**: \(10^{-4}\)
- **Batch size**: 16
- **Early stopping**: within 10 epochs without improvement
- **Attention heads**: 8
- **Encoder layers**: 2
- **Decoder layers**: 1
- **Implementation**: PyTorch
- **Hardware**: 16GB GPU

### Loss function / 损失函数

The model is trained using mean squared error:

\[
J(\Theta_{MAT})
=
\frac{1}{m}
\sum_{k=1}^{m}
\frac{1}{T'}
\left\|
MAT_{\Theta}(X_k)-Y_k
\right\|_2^2
\]

中文：

MAT 通过最小化预测值与真实值之间的均方误差进行训练。

## Evaluation / 评价方法

The main evaluation metrics are:

### Mean Squared Error

\[
MSE
=
\frac{1}{n}
\sum_{t=1}^{n}
(y_t-\hat{y}_t)^2
\]

### Mean Absolute Error

\[
MAE
=
\frac{1}{n}
\sum_{t=1}^{n}
|y_t-\hat{y}_t|
\]

Lower MSE and MAE indicate better forecasting performance.

主要评价指标为：

- MSE；
- MAE。

两个指标均为数值越低越好。

## Key Findings / 主要发现

### 1. MAT generally outperforms conventional forecasting models

#### English

MAT substantially outperforms ElasticNet across all interest-rate maturities and prediction horizons.

This suggests that nonlinear temporal and multimodal interactions cannot be adequately represented by a simple linear forecasting pipeline.

#### 中文

MAT 在所有利率期限和预测步长上均明显优于 ElasticNet。

这表明文本、宏观经济指标与利率之间的关系具有显著的非线性和动态性，简单线性模型难以充分刻画。

---

### 2. MAT achieves the best result in most Transformer comparisons

#### English

Across four interest-rate maturities and three forecast horizons, the paper reports 12 main forecasting settings.

MAT obtains the lowest MSE in 11 of the 12 settings.

It also achieves the lowest MAE in 11 of the 12 settings.

The only clear exception is the 2-year interest rate at the 6-month forecast horizon, where Reformer performs better.

#### 中文

论文包含：

\[
4\text{ 种利率期限}
\times
3\text{ 种预测步长}
=
12\text{ 种实验设置}
\]

MAT 在其中 11 个设置中取得最低 MSE，并在 11 个设置中取得最低 MAE。

唯一明显例外是：

- 预测 2 年期利率；
- 预测期限为未来 6 个月。

在该任务中，Reformer 的表现优于 MAT。

因此，MAT 并非在所有情况下都绝对最优。

---

### 3. The gains are especially clear for longer-term interest rates

#### English

MAT shows particularly strong performance for 5-year, 10-year, and 30-year interest rates.

The authors argue that longer-term interest rates depend more strongly on macroeconomic conditions and policy communication, making multimodal information more useful.

Representative MSE results include:

| Forecasting task | MAT | Best competing model |
|---|---:|---:|
| 5-year rate, 1-month horizon | 0.494 | 0.544 |
| 5-year rate, 3-month horizon | 0.613 | 0.746 |
| 10-year rate, 1-month horizon | 0.579 | 0.674 |
| 30-year rate, 1-month horizon | 0.741 | 0.886 |
| 30-year rate, 3-month horizon | 0.901 | 1.119 |

#### 中文

MAT 在 5 年、10 年和 30 年期利率预测中表现尤其突出。

作者认为，长期利率更容易受到：

- 宏观经济环境；
- 央行政策沟通；
- 市场预期；
- 经济主题情绪

的共同影响，因此跨模态学习能够带来更明显的收益。

---

### 4. Modality separation appears more effective than simple feature mixing

#### English

The results support the idea that textual and numerical data should not be immediately treated as one homogeneous modality.

MAT first learns:

1. relevant features within each modality;
2. temporal patterns within each modality;
3. interactions between modalities;
4. target-specific information from each modality.

This hierarchical fusion structure is more expressive than simple early concatenation.

#### 中文

实验结果支持以下方法逻辑：

> 不同模态不应在输入阶段被简单压平和拼接，而应先分别学习各自的表示，再进行跨模态融合。

MAT 的融合顺序为：

1. 选择每个模态内部的重要特征；
2. 学习每个模态内部的时间模式；
3. 学习不同模态之间的交互；
4. 根据目标预测任务从各模态中提取信息。

这一分层融合结构比简单 early concatenation 更具表达能力。

---

### 5. Feature and temporal attention provide partial interpretability

#### English

Feature-level attention can indicate which topics and macroeconomic variables receive larger model weights.

Temporal attention can indicate which historical periods are more relevant to the prediction.

However, these attention weights should be interpreted as model dependence rather than causal effects.

#### 中文

特征级注意力可以展示：

- 哪些文本主题权重较高；
- 哪些宏观经济指标权重较高。

时间注意力可以展示：

- 哪些历史月份更受模型关注。

但注意力权重只能说明模型内部的信息使用方式，不能直接解释为因果影响。

\[

\[

## Limitations / 局限性

### 1. Only two relatively processed modalities / 仅包含两个经过加工的模态

#### English

The paper considers only:

- numerical time series;
- textual reports transformed into topic-level sentiment scores.

The textual modality is already converted into a structured numerical sequence before entering MAT.

Therefore, the study does not test direct fusion of raw text, images, spatial networks, or graph-structured data.

#### 中文

论文仅使用：

- 数值时间序列；
- 转换成主题情绪分数的文本序列。

文本在进入 MAT 前已经被加工成结构化数值，因此该研究没有直接处理：

- 原始文本；
- 遥感影像；
- 空间网络；
- 图结构数据。

---

### 2. Claimed asynchronous capability is not fully validated / 异步模态能力未被充分验证

#### English

The architecture theoretically allows different sequence lengths for different modalities.

However, the experiments use equal sequence lengths for the text and numerical modalities to ensure fair comparison with baseline models.

Consequently, the paper does not provide a dedicated empirical test of irregular or asynchronous observations.

#### 中文

MAT 在结构上允许不同模态具有不同序列长度。

但为了与其他模型公平比较，正式实验仍然对两个模态使用相同的输入长度。

因此，论文并未通过专门实验充分证明其处理异步、不规则观测的能力。

---

### 3. Small effective sample size / 有效样本量较小

#### English

The dataset covers approximately 24 years at monthly frequency, corresponding to only around 288 observations before window construction.

This is a limited sample for a multi-head encoder–decoder Transformer and creates potential overfitting concerns.

#### 中文

1999—2022 年的月度数据大约只有：

\[
24\times12\approx288
\]

个原始时间点。

相对于多头 encoder–decoder Transformer 而言，样本量较小，可能存在过拟合风险。

---

### 4. Limited component ablation / 组件消融不充分

#### English

The paper does not systematically report the performance effect of removing:

- feature-level attention;
- intra-modal attention;
- inter-modal attention;
- target-modal attention.

It therefore remains unclear how much of the improvement comes from each individual component.

#### 中文

论文没有系统报告分别移除以下模块后的结果：

- 特征级注意力；
- 模态内注意力；
- 模态间注意力；
- 目标—模态注意力。

因此，无法准确判断每个模块分别贡献了多少性能提升。

---

### 5. Limited statistical testing / 缺少充分统计检验

#### English

The results are mainly reported through MSE and MAE tables.

The paper does not provide detailed forecast-comparison significance tests such as:

- Diebold–Mariano tests;
- bootstrap confidence intervals;
- Model Confidence Set procedures.

Thus, lower point-estimate errors do not automatically imply statistically significant superiority.

#### 中文

论文主要通过 MSE 和 MAE 比较模型，没有系统提供：

- Diebold–Mariano 检验；
- bootstrap 置信区间；
- Model Confidence Set。

因此，误差指标较低并不自动意味着预测优势具有统计显著性。

---

### 6. Attention is not causal explanation / 注意力不等于因果解释

#### English

Feature and temporal attention weights indicate which inputs the model relies on, but they do not demonstrate causal effects.

Higher attention on an oil-related topic does not prove that the topic caused an interest-rate movement.

#### 中文

特征和时间注意力只能展示模型更依赖哪些输入，不能证明变量之间存在因果关系。

同样，在石油价格项目中，即使模型给予 Hormuz 航运信号较高权重，也不能直接得出该信号导致 Brent 价格变化。

---

### 7. The target is interest rates rather than crude oil / 预测对象不是原油价格

#### English

The empirical application focuses on U.S. interest rates.

The model’s effectiveness for highly volatile commodity prices, especially Brent crude oil returns, remains untested.

#### 中文

论文预测的是美国利率，而不是高波动性的商品价格。

因此，其结果不能直接证明 MAT 一定适用于 Brent 油价或收益率预测。

---

### 8. No random-walk benchmark / 缺少随机游走基准

#### English

The paper compares MAT with ElasticNet and several Transformer architectures, but does not emphasise a no-change or random-walk forecasting benchmark.

For oil-price forecasting, this benchmark is essential because price persistence can make naive forecasts extremely competitive.

#### 中文

论文虽然比较了 ElasticNet 和多种 Transformer，但没有重点设置不变预测或随机游走基准。

在油价预测中，这一基准非常重要，因为价格水平的高度持续性可能使简单不变预测具有很强竞争力。

## Recommended Ablation Tests for the Dissertation / 本项目建议增加的消融实验

1. **Without feature-level attention**  
   去掉特征级注意力，检验动态变量选择是否有效。

2. **Without intra-modal attention**  
   去掉模态内注意力，检验各模态自身时间建模的贡献。

3. **Without cross-modal attention**  
   去掉跨模态注意力，检验跨模态交互是否真正带来增益。

4. **Without modality gating**  
   去掉动态门控，改为固定权重或简单平均。

5. **Without target-conditioned fusion**  
   将目标查询机制替换为普通 embedding 拼接。

6. **Financial modality only**  
   只保留金融分支，对应 M1。

7. **Financial + remote sensing**  
   删除航运分支，对应 M2。

8. **Financial + shipping**  
   删除遥感分支，对应 M3。

9. **All three modalities**  
   完整 M4。

10. **Frozen versus fine-tuned EO encoder**  
    比较冻结和微调遥感编码器。

11. **Missing-modality masking**  
    随机遮蔽遥感或航运模态，检验缺失数据鲁棒性。

12. **Temporal-shift placebo**  
    将遥感或航运数据进行人为时间错位，检验预测增益是否来自真实领先关系，而不是数据泄漏。

## Overall Assessment / 总体评价

### English

This paper is one of the most directly relevant methodological references for the dissertation’s representation-level multimodal architecture.

Its main value is not that it predicts crude-oil prices, but that it provides a concrete architecture for:

- preserving modality-specific streams;
- selecting informative features;
- modelling modality-specific temporal dependencies;
- learning cross-modal interactions;
- allowing the target sequence to retrieve information separately from each modality.

However, its results should not be treated as proof that a complex three-modality model will automatically improve Brent forecasting.

The dissertation must still demonstrate that:

1. remote-sensing signals provide incremental information;
2. shipping signals provide incremental information;
3. representation-level fusion outperforms flat feature fusion;
4. improvements are robust relative to a no-change benchmark;
5. gains remain statistically significant in rolling out-of-sample evaluation.

### 中文

这篇论文是本项目“表示级多模态方法创新层”最直接的参考文献之一。

其主要价值不在于油价预测结论，而在于提供了一套清晰的模态感知架构：

- 保留模态独立信息流；
- 在各模态内部选择重要特征；
- 分别建模各模态的时间依赖；
- 显式学习跨模态交互；
- 让预测目标分别从各模态中读取信息。

但该论文不能直接证明三模态复杂模型一定能够改善 Brent 预测。

本项目仍需通过实证检验：

1. 遥感信号是否提供增量预测信息；
2. 航运信号是否提供增量预测信息；
3. 表示级融合是否优于扁平特征拼接；
4. 模型是否能够击败不变预测或随机游走；
5. 预测增益在滚动样本外评价中是否具有统计显著性。
