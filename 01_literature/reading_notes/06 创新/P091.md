## Research Problem / 研究问题

### English

This paper studies forecasting in spatial-temporal graph systems, where:

- each entity is represented as a node;
- relationships between entities are represented as edges;
- each node has dynamic features that change over time;
- a node's future state depends on both its own historical observations and the histories of related nodes.

The authors identify two major limitations in previous spatial-temporal graph models.

First, most existing models rely on a fixed, predefined adjacency matrix. However, an observed physical graph may not fully represent the genuine dependency structure:

- two connected nodes may not have a strong functional relationship;
- two unconnected nodes may nevertheless exhibit strong hidden dependencies.

Second, existing temporal modules may be ineffective for long sequences:

- RNN-based models require sequential computation and may suffer from gradient vanishing or explosion;
- standard one-dimensional CNNs need many layers because their receptive field grows only linearly with network depth.

Graph WaveNet addresses these issues by combining:

1. diffusion graph convolution;
2. a self-adaptive adjacency matrix;
3. gated dilated causal convolution;
4. residual and skip connections;
5. direct multi-horizon forecasting.

### 中文

本文研究的是时空图系统中的预测问题。在这类系统中：

- 每个实体被表示为一个节点；
- 实体之间的关系被表示为边；
- 每个节点都有随时间变化的动态特征；
- 一个节点的未来状态既取决于自身历史，也取决于相关节点的历史状态。

作者指出，以往时空图模型主要存在两个问题。

第一，大多数模型依赖固定的预定义邻接矩阵，但显式物理网络不一定能够完整反映节点之间的真实依赖关系：

- 两个存在连接的节点未必具有较强的功能性依赖；
- 两个没有直接连接的节点也可能存在重要的隐藏关系。

第二，已有时间模块不容易有效处理长序列：

- RNN 必须按时间顺序递归计算，难以充分并行，并可能出现梯度消失或梯度爆炸；
- 普通一维 CNN 的感受野随网络深度线性增长，需要堆叠很多层才能覆盖较长历史。

Graph WaveNet 通过结合以下模块解决上述问题：

1. 扩散图卷积；
2. 自适应邻接矩阵；
3. 门控扩张因果卷积；
4. 残差连接和跳跃连接；
5. 直接多步预测。

## Problem Formulation / 问题定义

### English

A graph is represented as:

\[
G=(V,E)
\]

where:

- \(V\) is the node set;
- \(E\) is the edge set;
- \(A\in\mathbb{R}^{N\times N}\) is the adjacency matrix;
- \(N\) is the number of nodes.

At time \(t\), the graph has a node-feature matrix:

\[
X^{(t)}\in\mathbb{R}^{N\times D}
\]

where \(D\) is the number of features observed at each node.

Given the previous \(S\) time steps, the model predicts the next \(T\) time steps:

\[
[X^{(t-S):t},G]
\longrightarrow
X^{(t+1):(t+T)}
\]

The input therefore has the conceptual structure:

\[
\text{nodes}\times\text{features}\times\text{historical time steps}
\]

### 中文

论文将图表示为：

\[
G=(V,E)
\]

其中：

- \(V\) 表示节点集合；
- \(E\) 表示边集合；
- \(A\in\mathbb{R}^{N\times N}\) 表示邻接矩阵；
- \(N\) 表示节点数量。

在时间点 \(t\)，所有节点具有动态特征矩阵：

\[
X^{(t)}\in\mathbb{R}^{N\times D}
\]

其中 \(D\) 表示每个节点的特征数量。

模型使用过去 \(S\) 个时间点的图信号预测未来 \(T\) 个时间点：

\[
[X^{(t-S):t},G]
\longrightarrow
X^{(t+1):(t+T)}
\]

因此，其输入可以理解为：

\[
\text{节点}\times\text{特征}\times\text{历史时间}
\]

## Core Method / 核心方法

### 1. Diffusion Graph Convolution / 扩散图卷积

#### English

Graph WaveNet uses diffusion graph convolution to model how information propagates through a directed network.

For a directed graph, the model constructs:

- a forward transition matrix \(P_f\);
- a backward transition matrix \(P_b\).

The diffusion graph convolution is:

\[
Z=
\sum_{k=0}^{K}P_f^kXW_{k1}
+
\sum_{k=0}^{K}P_b^kXW_{k2}
\]

where:

- \(K\) is the diffusion order;
- \(P_f^k\) represents \(k\)-step forward propagation;
- \(P_b^k\) represents \(k\)-step backward propagation;
- \(W_{k1}\) and \(W_{k2}\) are trainable parameters.

This allows each node to aggregate information from both direct and higher-order neighbours.

#### 中文

Graph WaveNet 使用扩散图卷积模拟信息在有向网络中的传播。

对于有向图，模型分别构建：

- 前向转移矩阵 \(P_f\)；
- 反向转移矩阵 \(P_b\)。

扩散图卷积可表示为：

\[
Z=
\sum_{k=0}^{K}P_f^kXW_{k1}
+
\sum_{k=0}^{K}P_b^kXW_{k2}
\]

其中：

- \(K\) 是扩散阶数；
- \(P_f^k\) 表示前向传播 \(k\) 步；
- \(P_b^k\) 表示反向传播 \(k\) 步；
- \(W_{k1}\) 和 \(W_{k2}\) 是可学习参数。

因此，一个节点不仅可以聚合直接邻居的信息，也可以接收二阶或更高阶邻居的信息。

---

### 2. Self-Adaptive Adjacency Matrix / 自适应邻接矩阵

#### English

The main methodological innovation is a self-adaptive adjacency matrix.

The model initialises two trainable node-embedding matrices:

\[
E_1,E_2\in\mathbb{R}^{N\times c}
\]

where \(c\) is the node-embedding dimension.

The adaptive adjacency matrix is defined as:

\[
\widetilde A_{\mathrm{adp}}
=
\operatorname{SoftMax}
\left(
\operatorname{ReLU}(E_1E_2^\top)
\right)
\]

The two embeddings have asymmetric roles:

- \(E_1\): source-node embeddings;
- \(E_2\): target-node embeddings.

Because \(E_1E_2^\top\) does not need to be symmetric:

\[
A_{ij}\neq A_{ji}
\]

The influence from node \(i\) to node \(j\) can therefore differ from the influence from node \(j\) to node \(i\).

The full graph convolution combines physical and learned graph structures:

\[
Z=
\sum_{k=0}^{K}
P_f^kXW_{k1}
+
P_b^kXW_{k2}
+
\widetilde A_{\mathrm{adp}}^kXW_{k3}
\]

If no reliable predefined graph is available, Graph WaveNet can operate using only the adaptive adjacency matrix.

#### 中文

本文最重要的方法创新是自适应邻接矩阵。

模型初始化两组可学习的节点嵌入：

\[
E_1,E_2\in\mathbb{R}^{N\times c}
\]

其中 \(c\) 是节点嵌入维度。

自适应邻接矩阵定义为：

\[
\widetilde A_{\mathrm{adp}}
=
\operatorname{SoftMax}
\left(
\operatorname{ReLU}(E_1E_2^\top)
\right)
\]

两组嵌入分别承担不同作用：

- \(E_1\)：源节点嵌入；
- \(E_2\)：目标节点嵌入。

由于 \(E_1E_2^\top\) 不要求对称，因此：

\[
A_{ij}\neq A_{ji}
\]

节点 \(i\) 对节点 \(j\) 的影响不必等于节点 \(j\) 对节点 \(i\) 的影响。

完整图卷积同时包含物理图和学习图：

\[
Z=
\sum_{k=0}^{K}
P_f^kXW_{k1}
+
P_b^kXW_{k2}
+
\widetilde A_{\mathrm{adp}}^kXW_{k3}
\]

如果无法获得可靠的预定义图结构，Graph WaveNet 也可以仅使用自适应邻接矩阵。

---

### 3. Dilated Causal Convolution / 扩张因果卷积

#### English

The temporal module uses dilated causal convolution.

For a sequence \(x\), the operation is:

\[
x*f(t)
=
\sum_{s=0}^{K-1}
f(s)x(t-ds)
\]

where \(d\) is the dilation factor.

The causal structure ensures that the prediction at time \(t\) uses only information available at or before time \(t\), thereby avoiding future-information leakage.

Dilation enlarges the temporal receptive field by skipping observations at fixed intervals.

For example:

- dilation \(=1\): adjacent observations;
- dilation \(=2\): every second observation;
- dilation \(=4\): every fourth observation.

By stacking layers with increasing dilation factors, the receptive field grows rapidly without requiring a very deep ordinary CNN.

#### 中文

Graph WaveNet 的时间模块使用扩张因果卷积。

对于序列 \(x\)，其运算形式为：

\[
x*f(t)
=
\sum_{s=0}^{K-1}
f(s)x(t-ds)
\]

其中 \(d\) 是扩张系数。

“因果”意味着时间点 \(t\) 的预测只能使用时间点 \(t\) 及其之前的信息，从而避免未来信息泄漏。

“扩张”意味着卷积核按照固定间隔读取历史观测值。

例如：

- dilation \(=1\)：读取相邻观测；
- dilation \(=2\)：每隔一个观测读取；
- dilation \(=4\)：每隔三个观测读取。

通过堆叠具有不同扩张系数的卷积层，模型能够快速扩大时间感受野。

---

### 4. Gated Temporal Convolution / 门控时间卷积

#### English

Graph WaveNet applies a gating mechanism:

\[
h=
\tanh(\Theta_1*X+b)
\odot
\sigma(\Theta_2*X+c)
\]

The first branch produces candidate temporal information, while the second branch produces a sigmoid gate between zero and one.

The element-wise product controls how much information is passed to the next layer.

This provides a function similar to the gates in LSTM or GRU while retaining the parallel computation advantages of convolutional models.

#### 中文

Graph WaveNet 在时间卷积中加入门控机制：

\[
h=
\tanh(\Theta_1*X+b)
\odot
\sigma(\Theta_2*X+c)
\]

第一条分支生成候选时间信息，第二条分支通过 sigmoid 函数产生 0 到 1 之间的门值。

两条分支逐元素相乘，从而控制多少信息可以传递到下一层。

它在功能上类似 LSTM 或 GRU 中的门控结构，但保留了卷积模型可并行计算的优势。

---

### 5. Spatial-Temporal Blocks / 时空模块

#### English

Each Graph WaveNet spatial-temporal block contains:

1. gated dilated temporal convolution;
2. graph convolution;
3. residual connection;
4. skip connection.

The temporal module is applied before graph convolution.

By stacking multiple blocks:

- lower graph layers process short-term temporal representations;
- higher graph layers process longer-term temporal representations.

Residual connections improve optimisation, while skip connections transmit information from each block directly to the output module.

#### 中文

Graph WaveNet 的每个时空模块包括：

1. 门控扩张时间卷积；
2. 图卷积；
3. 残差连接；
4. 跳跃连接。

模型首先提取时间表示，再进行节点间图传播。

通过堆叠多个时空模块：

- 底层图卷积处理较短期的时间表示；
- 高层图卷积处理较长期的时间表示。

残差连接有助于深层网络训练，跳跃连接则把各层信息直接传递至输出模块。

---

### 6. Direct Multi-Horizon Forecasting / 直接多步预测

#### English

Graph WaveNet predicts all future horizons simultaneously:

\[
\widehat X^{(t+1):(t+T)}
\]

It does not recursively feed one prediction into the next forecasting step.

This reduces:

- error accumulation;
- inconsistency between one-step training and multi-step inference.

The training loss is MAE:

\[
L=
\frac{1}{TND}
\sum_{i=1}^{T}
\sum_{j=1}^{N}
\sum_{k=1}^{D}
\left|
\widehat X_{jk}^{(t+i)}
-
X_{jk}^{(t+i)}
\right|
\]

#### 中文

Graph WaveNet 一次性输出未来所有预测期：

\[
\widehat X^{(t+1):(t+T)}
\]

它不会把前一步预测结果递归输入下一步。

这种方式可以减少：

- 多步递归预测中的误差累积；
- 单步训练与多步推理之间的不一致。

论文使用 MAE 作为训练损失：

\[
L=
\frac{1}{TND}
\sum_{i=1}^{T}
\sum_{j=1}^{N}
\sum_{k=1}^{D}
\left|
\widehat X_{jk}^{(t+i)}
-
X_{jk}^{(t+i)}
\right|
\]

### Data Processing / 数据处理

- Sensor observations are aggregated into five-minute intervals.  
  传感器观测被汇总为 5 分钟时间窗口。

- The predefined graph is constructed from road-network distance using a thresholded Gaussian kernel.  
  预定义图根据道路网络距离和截断高斯核构建。

- Inputs are standardised using Z-score normalisation.  
  输入采用 Z-score 标准化。

- Data are divided chronologically rather than randomly.  
  数据按照时间顺序而不是随机方式划分。

- **Training set / 训练集**: 70%
- **Validation set / 验证集**: 10%
- **Test set / 测试集**: 20%

## Key Findings / 主要发现

### 1. Graph WaveNet achieves the strongest overall forecasting performance

#### English

Graph WaveNet achieves the best overall MAE, RMSE and MAPE on both METR-LA and PEMS-BAY across 15-, 30- and 60-minute forecasting horizons.

Its advantage becomes particularly clear at longer horizons, indicating that the dilated temporal architecture and repeated graph propagation help capture long-range spatial-temporal dependencies.

#### 中文

Graph WaveNet 在 METR-LA 和 PEMS-BAY 两个数据集的 15、30 和 60 分钟预测中，整体取得了最优的 MAE、RMSE 和 MAPE。

其在较长预测期上的优势更加明显，说明扩张时间卷积和多层图传播有助于学习长距离时空依赖。

---

### 2. Graph structure provides additional forecasting information

#### English

WaveNet captures only temporal dependencies, while Graph WaveNet also models cross-node relationships.

Graph WaveNet substantially outperforms WaveNet, showing that network structure contains useful information beyond temporal patterns alone.

#### 中文

WaveNet 仅学习时间依赖，而 Graph WaveNet 还学习节点之间的网络关系。

Graph WaveNet 明显优于 WaveNet，说明图结构在单纯时间模式之外提供了额外预测信息。

---

### 3. Adaptive adjacency can recover meaningful hidden relationships

#### English

The adaptive-only configuration performs similarly to, and in some metrics slightly better than, the forward-only predefined graph.

This suggests that node embeddings can recover useful dependencies even when the physical graph is incomplete or unavailable.

#### 中文

仅使用自适应邻接矩阵的模型与仅使用前向预定义图的模型表现接近，部分指标甚至更好。

这说明即使物理网络不完整或不可获得，节点嵌入也能够发现具有预测价值的隐藏依赖。

---

### 4. Physical and adaptive graphs are complementary

#### English

The best adjacency configuration combines:

- forward diffusion;
- backward diffusion;
- adaptive adjacency.

On METR-LA, mean MAE decreases from 3.58 under the identity configuration to 3.04 under the forward-backward-adaptive configuration.

On PEMS-BAY, mean MAE decreases from 1.80 to 1.58.

This indicates that predefined network knowledge and data-driven latent dependencies complement each other.

#### 中文

表现最好的邻接矩阵配置同时包含：

- 前向扩散；
- 反向扩散；
- 自适应邻接矩阵。

在 METR-LA 上，平均 MAE 从无图传播时的 3.58 降至前向—反向—自适应配置下的 3.04。

在 PEMS-BAY 上，平均 MAE 从 1.80 降至 1.58。

这说明人工提供的网络知识与模型学习的隐藏依赖具有互补性。

---

### 5. Different graph layers capture different temporal scales

#### English

Each spatial-temporal block contains an independent graph-convolution layer.

Therefore:

- lower layers process short-term temporal information;
- higher layers process longer-term representations.

This may explain why Graph WaveNet performs well at longer forecasting horizons.

#### 中文

每个时空模块都包含独立的图卷积层。

因此：

- 底层图卷积处理短期时间信息；
- 高层图卷积处理更长期的时间表示。

这可能是 Graph WaveNet 在较长预测期表现较好的原因之一。

---

### 6. Direct multi-horizon forecasting improves inference efficiency

#### English

Graph WaveNet predicts all horizons in one forward pass.

Its reported inference time on METR-LA is lower than that of DCRNN and STGCN, although its training time is higher than STGCN.

#### 中文

Graph WaveNet 在一次前向传播中生成所有未来预测期。

在 METR-LA 上，其推理时间低于 DCRNN 和 STGCN，但训练时间高于 STGCN。

## Proposed Adaptation for the Oil-Price Project / 在石油价格项目中的建议改造

### 3. Predefined Shipping Graph / 预定义航运图

The predefined graph should preferably be based on actual maritime flows rather than straight-line geographic distance.

预定义航运图应优先根据实际海上流量构建，而不是简单使用经纬度直线距离。

Possible edge definitions include:

- historical origin–destination tanker flows;
- tanker DWT transported between nodes;
- route-sharing frequency;
- whether a route passes through a chokepoint;
- estimated sailing time;
- maritime-network distance.

候选边定义包括：

- 历史油轮起点—终点流量；
- 节点之间运输的 tanker DWT；
- 共同航线出现频率；
- 某条航线是否经过关键海峡；
- 预计航行时间；
- 海上航线距离。

A possible directed edge weight is:

\[

=
\frac{\text{Tanker capacity from }i\text{ to }j}

\[

=
\frac{\text{节点 }i\text{ 至节点 }j\text{ 的油轮运力}}

\]

## Limitations / 局限性

### 1. Domain Mismatch / 应用领域差异

#### English

The model is evaluated only on traffic-speed forecasting.

Traffic data have strong local persistence and direct road-network propagation. The paper does not show that Graph WaveNet improves crude-oil price forecasting.

#### 中文

该模型仅在交通速度预测任务上进行验证。

交通速度具有较强的局部连续性和明确的道路网络传播关系。本文并未证明 Graph WaveNet 能够直接提高原油价格预测精度。

---

### 2. Node-Level Output Rather Than a Global Target / 原始输出为节点级而非全球目标

#### English

The original model predicts future values for every traffic sensor.

The oil-price project predicts a single global variable, so an additional graph-level pooling or readout layer is required.

#### 中文

原始模型预测每个交通传感器的未来值。

石油价格项目预测的是单一全球变量，因此需要增加图级池化或 readout 层。

---

### 3. Much Smaller Weekly Sample / 周度样本量较小

#### English

The traffic datasets contain tens of thousands of five-minute observations.

A weekly oil-price dataset may contain only several hundred usable observations. A full eight-layer Graph WaveNet may therefore overfit.

#### 中文

交通数据集包含数万个 5 分钟观测值。

周度石油价格数据可能只有数百个有效样本，因此直接使用八层 Graph WaveNet 可能造成严重过拟合。

---

### 4. Static Adaptive Adjacency / 自适应邻接矩阵仍然是静态的

#### English

Although the adjacency matrix is learned, the original model uses one shared adaptive matrix for the full sample.

It does not explicitly model network changes caused by:

- wars;
- sanctions;
- canal disruptions;
- rerouting;
- changes in trade regimes.

#### 中文

虽然邻接矩阵由数据学习，但原始模型在整个样本期内共享同一套自适应矩阵。

它没有直接刻画以下因素造成的时变网络关系：

- 战争；
- 制裁；
- 运河中断；
- 航线绕行；
- 国际贸易格局变化。

---

### 5. Homogeneous Graph Assumption / 同质图假设

#### English

Graph WaveNet assumes that all nodes have a consistent feature structure.

If ports, refineries, terminals and chokepoints have fundamentally different variables, a heterogeneous graph model may be more appropriate.

#### 中文

Graph WaveNet 默认所有节点具有一致的特征结构。

如果港口、炼厂、终端和关键海峡的变量定义差异很大，则异构图神经网络可能更加合适。

---

### 6. No Multimodal Inputs / 未纳入多模态输入

#### English

The paper does not incorporate:

- financial variables;
- text;
- remote-sensing images;
- geopolitical events;
- macroeconomic variables.

The dissertation therefore needs an additional multimodal fusion architecture.

#### 中文

本文没有纳入：

- 金融变量；
- 文本；
- 遥感影像；
- 地缘政治事件；
- 宏观经济变量。

因此，本项目需要另外设计多模态融合架构。

### 7. No Probabilistic Forecasting / 缺少概率预测

#### English

Graph WaveNet mainly produces point forecasts and does not directly estimate:

- prediction intervals;
- probability distributions;
- tail risk.

These are important for volatile oil-price forecasting.

#### 中文

Graph WaveNet 主要输出点预测，没有直接估计：

- 预测区间；
- 概率分布；
- 尾部风险。

对于高波动的石油价格预测，这些信息较为重要。

---

### 8. Limited Benefit with Very Few Nodes / 节点过少时优势有限

#### English

If the project includes only six chokepoints and two indicators per node, the graph may be too small and simple to justify a deep Graph WaveNet.

The method becomes more convincing when the network contains a larger set of ports, terminals and chokepoints with meaningful directed flows.

#### 中文

如果项目仅包含六个关键海峡，并且每个节点只有两个指标，那么图结构可能过小、过于简单，难以支撑深层 Graph WaveNet。

当网络包含更多港口、终端和关键海峡，并具有明确有向流量时，该模型的优势会更加充分。

## Overall Assessment / 总体评价

### English

Graph WaveNet is an important methodological paper for spatial-temporal graph forecasting.

Its main contribution to this dissertation is not that it directly demonstrates improved crude-oil price forecasts. Instead, it provides a principled method for representing AIS shipping activity as a dynamic network rather than as a set of independent numerical variables.

It mainly supports the methodological innovation layer of the project by motivating the hypothesis:

\[
\text{Structured shipping representation}
>
\text{Flat shipping-feature concatenation}
\]

However, the original architecture cannot be copied without modification because this dissertation has:

- a much smaller weekly sample;
- a single global forecasting target;
- heterogeneous data modalities;
- missing and asynchronous observations;
- potentially time-varying shipping relationships.

A smaller Graph WaveNet should therefore be used as a shipping encoder, followed by graph-level pooling and multimodal fusion.

### 中文

Graph WaveNet 是时空图预测领域的重要方法论文。

它对本项目的主要价值，不是直接证明该模型能够提高原油价格预测精度，而是提供了一种有理论依据的方法，将 AIS 航运活动表示为动态网络，而不是一组相互独立的数值变量。

它主要支撑本项目的方法创新层，即检验以下研究假设：

\[
\text{结构化航运表示}
>
\text{扁平航运特征拼接}
\]

但是，原始架构不能不经修改直接复制，因为本项目具有以下不同特征：

- 周度样本量明显更小；
- 预测目标是单一全球市场变量；
- 包含多种异质数据模态；
- 存在缺失和异步观测；
- 航运关系可能随时间变化。

因此，更合理的方案是使用规模较小的 Graph WaveNet 作为航运编码器，随后加入图级池化和多模态融合模块。
