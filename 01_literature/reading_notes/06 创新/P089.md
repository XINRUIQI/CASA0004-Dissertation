# Reading Note — Paper 89: Temporal Fusion Transformers for Interpretable Multi-horizon Time Series Forecasting

## Citation｜文献信息

Lim, B., Arık, S. Ö., Loeff, N., & Pfister, T. (2021). Temporal Fusion Transformers for Interpretable Multi-horizon Time Series Forecasting. *International Journal of Forecasting*, 37(4), 1748–1764.

- **DOI**: [10.1016/j.ijforecast.2021.03.012](https://doi.org/10.1016/j.ijforecast.2021.03.012)
- **arXiv**: [1912.09363](https://arxiv.org/abs/1912.09363)
- **Preprint submitted**: September 2020
- **Journal publication**: 2021
- **Authors' affiliations**: University of Oxford and Google Cloud AI
- **Keywords**: Multi-horizon forecasting; Temporal Fusion Transformer; attention; variable selection; interpretable deep learning; quantile forecasting

## Research Problem｜研究问题

### English

The paper addresses interpretable multi-horizon time-series forecasting in settings where a model receives several heterogeneous forms of information:

1. Static covariates that do not change over time;
2. Time-varying variables that are observed only up to the forecasting origin;
3. Time-varying variables whose future values are known in advance;
4. Multiple future horizons that must be predicted simultaneously.

Existing recurrent and Transformer-based forecasting models often assume that all exogenous inputs are known in the future, ignore static covariates, or provide limited explanations of how individual variables and historical time points affect predictions.

The authors therefore develop the Temporal Fusion Transformer (TFT), which combines recurrent processing, self-attention, dynamic variable selection, gating mechanisms and quantile regression within a unified forecasting architecture.

### 中文

本文研究的是具有复杂异质输入的可解释多步时间序列预测问题。现实预测任务通常同时包含：

1. 不随时间变化的静态协变量；
2. 只能观测到预测起点之前的动态变量；
3. 在预测开始时已经知道未来取值的动态变量；
4. 需要同时预测的多个未来时点。

传统 RNN 或 Transformer 预测模型通常存在以下问题：

- 默认所有外生变量的未来值均已知；
- 忽略静态变量，或仅将其简单复制到每一个时间点；
- 无法说明模型在不同预测中使用了哪些变量；
- 难以同时学习局部时间变化和长期依赖；
- 通常属于缺乏解释能力的“黑箱”模型。

因此，作者提出 Temporal Fusion Transformer（TFT），将循环神经网络、自注意力、动态变量选择、门控机制和分位数回归整合在同一个预测框架中。

---

## Core Method｜核心方法

- **Model｜模型**: Temporal Fusion Transformer（TFT）。

- **Forecasting strategy｜预测策略**: Direct multi-horizon forecasting。模型一次性直接输出多个未来时点的预测，而不是递归地将前一期预测结果作为下一期输入。

- **Input taxonomy｜输入分类**:

  1. **Static covariates｜静态协变量**  
     不随时间改变的实体属性，例如商店编号、商品类别、地区或实体类型。

  2. **Past-observed inputs｜历史可观测变量**  
     只能观测到当前及过去、未来值未知的变量，例如历史目标值、销售量、收益率或已实现波动率。

  3. **Known future inputs｜未来已知变量**  
     在预测起点已经能够确定未来值的变量，例如星期、月份、节假日和预先确定的促销安排。

- **Local temporal processing｜局部时间建模**:  
  LSTM encoder–decoder / sequence-to-sequence layer，用于学习邻近时间点之间的短期变化、局部趋势、异常、拐点和周期模式。

- **Long-term temporal processing｜长期时间建模**:  
  Interpretable multi-head self-attention，用于识别跨越较长时间范围的依赖关系和重要历史滞后。

- **Feature selection｜特征选择**:  
  Variable Selection Networks 在每个样本和每个时间点动态计算变量权重，选择当前预测中最重要的输入，同时抑制噪声变量。

- **Gating mechanism｜门控机制**:  
  Gated Residual Networks（GRNs）和 Gated Linear Units（GLUs）控制各个变量、非线性层和模型模块对最终预测的贡献。无用模块可以被门控机制近似跳过。

- **Static information processing｜静态信息处理**:  
  Static Covariate Encoders 将静态属性转换为多个 context vectors，用于：

  - 调节动态变量选择；
  - 初始化 LSTM hidden state 和 cell state；
  - 将静态属性注入时间特征；
  - 根据不同实体调整预测过程。

- **Output｜输出**:  
  Multi-horizon quantile forecasts，同时预测多个未来时点的 P10、P50 和 P90 条件分位数。

- **Loss function｜损失函数**:  
  Quantile loss / pinball loss。

- **Evaluation｜评估指标**:  
  Normalised quantile loss，即 q-Risk，主要报告 P50 q-Risk 和 P90 q-Risk。

---

## Model Architecture｜模型架构

TFT 的整体计算流程可以概括为：

```text
Static covariates
        │
        ▼
Static Variable Selection
        │
        ▼
Static Covariate Encoders
        │
        ├─────────────► Temporal variable-selection context
        ├─────────────► LSTM hidden-state context
        ├─────────────► LSTM cell-state context
        └─────────────► Static-enrichment context

Past-observed inputs ──► Variable Selection Network ──┐
                                                       │
Known future inputs ──► Variable Selection Network ───┤
                                                       ▼
                                          LSTM Encoder–Decoder
                                                       │
                                                       ▼
                                            Static Enrichment
                                                       │
                                                       ▼
                              Interpretable Temporal Self-Attention
                                                       │
                                                       ▼
                                      Position-wise GRN Processing
                                                       │
                                                       ▼
                                      P10 / P50 / P90 Forecasts
```

## Main Components｜主要组成部分

### 1. Variable Selection Networks｜变量选择网络

#### English

Each input variable is first transformed separately into a common latent dimension. Continuous variables are processed through linear transformations, while categorical variables are represented through entity embeddings.

At each time step, the Variable Selection Network produces Softmax-normalised weights for all available variables. The selected representation is a weighted combination of the transformed variables.

This allows the model to assign different importance to the same variable in different periods and for different samples.

#### 中文

每个输入变量首先被单独转换为统一维度的隐藏表示：

- 连续变量通过线性变换；
- 类别变量通过 embedding；
- 每个变量随后经过自己的 GRN。

在每一个时间点，Variable Selection Network 会利用 Softmax 为所有变量生成动态选择权重。最终的时间输入表示是各个变量表示的加权组合：

\[
\widetilde{\xi}_t
=
\sum_{j=1}^{m}
v_t^{(j)}
\widetilde{\xi}_t^{(j)}
\]

其中：

- \(v_t^{(j)}\) 是变量 \(j\) 在时间 \(t\) 的选择权重；
- 不同时间点可以得到不同权重；
- 不同预测样本也可以得到不同权重。

因此，TFT 不假设一个变量在所有时期都具有相同的重要性。

---

### 2. Gated Residual Networks｜门控残差网络

#### English

The Gated Residual Network is the basic nonlinear processing component of TFT. It combines nonlinear transformations with a gated skip connection, allowing the model to suppress unnecessary processing when a simpler relationship is sufficient.

#### 中文

GRN 是 TFT 的基本非线性处理单元，主要包括：

- Linear transformation；
- ELU activation；
- Dropout；
- Gated Linear Unit；
- Residual connection；
- Layer normalisation。

GLU 的形式可表示为：

\[
\operatorname{GLU}(\gamma)
=
\sigma(W_1\gamma+b_1)
\odot
(W_2\gamma+b_2)
\]

其中 sigmoid 部分相当于一个门控开关：

- 当门控值接近 0 时，该模块的输出受到抑制；
- 当门控值接近 1 时，该模块的信息被保留；
- 如果复杂非线性处理没有帮助，模型可以通过残差路径近似跳过该层。

这种设计使 TFT 能够根据数据和样本动态调整网络复杂度，并减少小样本或高噪声环境中的过拟合风险。

---

### 3. Static Covariate Encoders｜静态协变量编码器

TFT 不会把静态变量简单复制到每个时间点，而是将其编码为四类 context vectors：

\[
c_s,\quad c_e,\quad c_c,\quad c_h
\]

其作用分别为：

- \(c_s\)：影响动态变量选择；
- \(c_e\)：用于 static enrichment；
- \(c_c\)：初始化 LSTM cell state；
- \(c_h\)：初始化 LSTM hidden state。

这种设计使相同的动态变化可以根据不同实体的固定属性得到不同处理。

例如，在零售数据中，不同商店、商品类别和地区可以形成不同的销售时间规律。

---

### 4. LSTM Encoder–Decoder｜LSTM 编码器—解码器

#### English

The sequence-to-sequence layer is used for local temporal processing.

- The encoder processes historical observed inputs.
- The decoder processes known future inputs.
- Static context vectors initialise the LSTM hidden and cell states.
- A gated residual connection allows the model to bypass the LSTM layer when local processing is unnecessary.

#### 中文

LSTM 在 TFT 中主要负责：

- 邻近时间点之间的依赖；
- 局部趋势；
- 短期反转；
- 变化点；
- 短期周期；
- 异常值与周围观测之间的关系。

它与后续 self-attention 形成互补：

- LSTM 负责局部和短期结构；
- Self-attention 负责长期和跨期依赖。

---

### 5. Static Enrichment｜静态信息增强

LSTM 输出之后，TFT 再次将静态 context 注入每一个时间位置：

\[
\theta(t,n)
=
\operatorname{GRN}
\left(
\widetilde{\phi}(t,n),c_e
\right)
\]

这一层使时间表示能够根据实体属性进行调整。

例如，相同的销量变化对于不同商品或商店可能具有不同含义；相同的港口活动变化对于原油出口港、炼厂和普通综合港口也可能具有不同意义。

---

### 6. Interpretable Multi-head Attention｜可解释多头注意力

#### English

Standard Transformer heads generally use different value projections, which makes attention weights difficult to interpret directly.

TFT modifies conventional multi-head attention by:

- allowing different query and key projections across heads;
- sharing the value projection across heads;
- aggregating the attention matrices from different heads.

This produces a combined attention pattern that is easier to interpret as the relative importance of historical time points.

#### 中文

普通 Transformer 的每个 attention head 通常使用独立的 value projection，因此单独观察 attention weights 并不能直接解释某一个时间点的重要性。

TFT 对标准多头注意力进行了修改：

- 不同 attention heads 使用不同的 query 和 key projections；
- 所有 heads 共享 value projection；
- 各个 heads 的 attention matrices 采用平均方式聚合。

因此，最终 attention weights 更容易解释为：

> 模型在预测某一个未来时点时，主要依赖哪些历史时间点。

模型同时使用 causal masking，保证当前预测不能访问未来信息。

---

### 7. Quantile Forecasting｜分位数预测

TFT 不只输出单一点预测，而是同时输出多个条件分位数：

\[
\hat y^{0.1}_{t+\tau},
\quad
\hat y^{0.5}_{t+\tau},
\quad
\hat y^{0.9}_{t+\tau}
\]

其中：

- P10 表示偏低情景；
- P50 表示中位数预测，可作为主要点预测；
- P90 表示偏高情景；
- P10–P90 可以构成预测区间。

模型采用 quantile loss：

\[
QL(y,\hat y,q)
=
q(y-\hat y)_+
+
(1-q)(\hat y-y)_+
\]

这种方法避免了必须假设预测误差服从正态分布。

## Key Findings｜主要发现

### 1. TFT achieves the best overall forecasting performance

#### English

Across the four datasets, TFT outperforms the competing statistical, recurrent and Transformer-based models.

Compared with the next-best model, TFT produces approximately:

- **7% lower P50 q-Risk on average**;
- **9% lower P90 q-Risk on average**.

#### 中文

在四个实验数据集上，TFT 总体上优于传统统计模型、循环神经网络和其他 Transformer 类模型。

与各数据集上的次优模型相比，TFT 平均实现：

- P50 q-Risk 降低约 7%；
- P90 q-Risk 降低约 9%。

这说明针对多步预测任务专门设计输入结构、变量选择、门控和时间建模机制，能够优于直接套用通用 RNN 或 Transformer。

---

### 2. Explicitly distinguishing input types improves forecasting

#### English

Models that assume every exogenous input is known in the future perform poorly when important predictors are observable only in the past.

TFT explicitly separates:

- historical observed inputs;
- future known inputs;
- static metadata.

This improves its ability to handle realistic forecasting tasks with incomplete future information.

#### 中文

如果一个模型假设所有外生变量的未来值均已知，那么在实际预测中往往需要对未知变量进行填补，例如使用最后一期观测值。

这种处理在 Retail 和 Volatility 等复杂数据集上会损害预测性能。

TFT 对历史可观测变量、未来已知变量和静态变量进行区分，因此更符合真实预测环境。

---

### 3. Combining local and long-term temporal processing is important

#### English

The ablation analysis shows that LSTM local processing and self-attention are among the most important TFT components.

Removing either temporal component increases P90 loss by:

- more than 6% on average;
- more than 20% for some datasets.

#### 中文

消融实验表明，负责时间建模的两个组件贡献最大：

- LSTM sequence-to-sequence 层；
- Temporal self-attention 层。

删除这些组件后，P90 损失：

- 平均上升超过 6%；
- 在部分数据集上上升超过 20%。

这说明局部变化和长期依赖不能简单互相替代，而是具有互补作用。

---

### 4. Dynamic variable selection improves both accuracy and interpretability

#### English

Removing instance-wise Variable Selection Networks increases P90 loss by approximately 4.1% on average.

The variable-selection weights also allow users to analyse:

- globally important predictors;
- predictors that are important only during particular periods;
- differences between static, historical and future-known variables.

#### 中文

删除动态变量选择网络后，P90 损失平均增加约 4.1%。

因此，Variable Selection Network 不只是解释工具，也能够：

- 抑制无用变量；
- 减少噪声影响；
- 将模型容量集中到最相关的变量；
- 改善预测性能。

---

### 5. Gating is particularly useful for small and noisy financial datasets

#### English

Removing gating layers increases P90 loss by approximately 1.9% on average.

For the Volatility dataset, removing gating increases P90 loss by approximately 4.1%.

#### 中文

门控机制对所有数据集都有一定帮助，但在规模较小、噪声较强的金融波动率数据中尤其重要。

这说明当变量关系不稳定、部分非线性模块并非始终有用时，模型需要具备自动抑制无效计算路径的能力。

---

### 6. The usefulness of model components is dataset-dependent

#### English

The complete TFT architecture is not uniformly optimal for every temporal process.

For example:

- local LSTM processing is important for Traffic, Retail and Volatility;
- in Electricity, strong daily seasonality makes direct long-range attention particularly useful;
- local processing may be unnecessary in some strongly seasonal settings.

#### 中文

不同组件的作用取决于数据本身。

这意味着不能直接假定完整 TFT 在任何任务上都是最优模型。对于具体项目，应当通过验证集和消融实验决定：

- 是否需要 LSTM；
- attention head 数量；
- 历史窗口长度；
- 是否需要静态编码；
- 门控和变量选择是否有效。

## Interpretability｜可解释性

The paper demonstrates three main interpretability use cases.

本文展示了 TFT 的三类主要解释方法。

---

### 1. Global Variable Importance｜全局变量重要性

#### English

The authors aggregate Variable Selection Network weights over the entire test set and report their:

- 10th percentile;
- 50th percentile;
- 90th percentile.

This distinguishes between:

- consistently important variables;
- consistently unimportant variables;
- variables that become important only in particular samples or periods.

#### 中文

作者对测试集中所有样本的变量选择权重进行汇总，并报告：

- 10% 分位数；
- 50% 分位数；
- 90% 分位数。

这种方法能够区分：

- 在大多数时期都很重要的变量；
- 长期没有预测价值的变量；
- 只在少数市场状态或事件中突然重要的变量。

---

### 2. Persistent Temporal Patterns｜持续性时间模式

#### English

Attention weights are aggregated across time and forecast horizons to identify recurring lag structures.

The results show:

- strong daily seasonality in Electricity;
- strong daily seasonality in Traffic;
- weaker weekly patterns and strong recent-history dependence in Retail;
- no fixed dominant lag pattern in Volatility.

For Volatility, attention is relatively evenly distributed over the historical window on average, resembling a moving-average filter that smooths high-frequency financial noise.

#### 中文

TFT 可以通过汇总 attention weights 自动发现：

- 季节性；
- 周期性；
- 重要历史滞后；
- 不同预测期所依赖的历史窗口。

在波动率数据中，没有发现固定的强周期。模型平均而言较均匀地关注整个历史窗口，类似于对高频噪声进行平滑并提取长期趋势。

---

### 3. Regime Changes and Significant Events｜市场状态变化与重大事件

#### English

The paper compares the attention pattern at each time point with the long-run average attention pattern.

Large deviations indicate that the model is changing the way it uses historical information.

In the volatility application:

- during low-volatility regimes, attention is distributed relatively evenly across the history;
- during high-volatility regimes, the model places more attention on recent sharp trend changes;
- large attention-pattern deviations correspond to major financial-market events, including the 2008 financial crisis.

#### 中文

作者计算每个时期的 attention pattern 与长期平均 attention pattern 之间的差异。

当差异明显增大时，说明模型改变了使用历史信息的方式，可能对应：

- 市场状态切换；
- 结构性变化；
- 异常冲击；
- 重大金融事件。

在低波动时期，模型较均匀地利用历史窗口；在高波动时期，模型更关注近期剧烈变化。

| **Interpretability｜可解释性** | TFT provides model-internal variable weights and lag attention, complementing post-hoc SHAP analysis used for XGBoost. / TFT 的动态变量权重和时间注意力可与 XGBoost 的 SHAP 形成互补。 |
| **Static metadata｜静态信息** | If ports, refineries, terminals or AOIs are modelled as multiple entities, their type, region, scale and function can be represented as static covariates. / 若将多个港口或遥感 AOI 建模为实体，可将站点类型、区域和功能作为静态属性。 |
| **Flat-feature baseline｜扁平特征基准** | TFT is suitable for combining engineered weekly features in a single tabular sequence, providing a strong comparison for the dissertation's representation-level multimodal model. / TFT 可作为“所有工程特征压成一张表”的强基准，与保留影像和航运网络结构的表示级融合模型比较。 |

## Target Design for the Brent Project｜Brent 项目的目标设计

A suitable internal training target is the next-week log-price change:

\[
r_{t+1}
=
\log(P_{t+1})-\log(P_t)
\]

TFT can produce quantile forecasts:

\[
\widehat{r}_{t+1}^{0.1},
\quad
\widehat{r}_{t+1}^{0.5},
\quad
\widehat{r}_{t+1}^{0.9}
\]

These can be converted back to Brent prices:

\[
\widehat{P}_{t+1}^{q}
=
P_t\exp\left(\widehat{r}_{t+1}^{q}\right)
\]

This design has several advantages:

1. It reduces the strong non-stationarity of the price-level series.
2. The final reported output remains an interpretable Brent price.
3. P50 can be used as the primary point forecast.
4. P10–P90 provides an uncertainty interval.
5. The reconstructed price forecast can be directly compared with the M0 no-change forecast.

### 中文

建议模型内部预测下一周对数价格变化，而不是直接训练非平稳的价格水平；随后再将预测结果还原为 Brent 价格。

这并不意味着论文目标从“预测价格”变成“预测收益率”，因为最终评价仍然可以基于还原后的下一周价格。

## Relationship to the Dissertation's Multimodal Model｜与真正多模态模型的关系

### TFT as Flat-feature Fusion｜TFT 作为扁平特征融合模型

Standard TFT expects all inputs to have already been converted into aligned numerical time-series variables:

\[

=
[

x_{2,t},
\dots,
x_{p,t}

Therefore, standard TFT can process:

- satellite-derived numerical indices;
- weekly tanker counts;

However, it does not directly preserve:

- raw satellite-image spatial structure;
- relationships among pixels and AOIs;
- port-network topology;

- modality-specific asynchronous sampling;

## Limitations｜局限性

1. **No oil-price application｜没有直接预测石油价格**  
   The paper evaluates electricity, traffic, retail sales and stock-market volatility, but not crude-oil prices. Its results therefore do not prove that TFT will outperform oil-price benchmarks.

2. **No Brent or WTI benchmark｜未检验 Brent 或 WTI**  
   The model's performance under oil-specific supply, demand, futures and geopolitical dynamics remains unknown.

3. **Much larger sample sizes｜实验样本明显更大**  
   Most experiments contain approximately 100,000–500,000 samples. A 2006–2026 weekly Brent dataset contains only about 1,000 time observations, creating a much greater overfitting risk.

4. **Flat numerical inputs｜主要处理扁平数值输入**  
   TFT does not directly process raw satellite imagery, spatial raster structure, vessel trajectories or dynamic shipping graphs.

5. **Interpretability is not causality｜可解释权重不代表因果效应**  
   Variable-selection weights and attention weights indicate how the trained model uses information. They do not prove that a predictor causally changes oil prices.

6. **Attention weights require cautious interpretation｜注意力解释需要谨慎**  
   High attention on a historical period indicates model reliance, but does not necessarily provide a complete explanation of the prediction.

7. **Static covariates may have limited value for a single Brent series｜单一 Brent 序列中的静态变量有限**  
   Static covariate encoders are most valuable when forecasting multiple entities. Their usefulness is smaller when the dataset contains only one global Brent target series.

8. **No oil-specific no-change test｜没有石油价格特有的不变预测检验**  
   The paper does not establish that TFT can beat the highly competitive oil-price persistence benchmark.

9. **No remote-sensing or shipping modality｜没有遥感和航运模态**  
   The paper demonstrates heterogeneous numerical input fusion, but not multimodal fusion involving images, spatial data or transport networks.

10. **Computational complexity｜计算复杂度较高**  
    The full TFT architecture contains multiple GRNs, LSTMs, attention blocks and variable-selection networks, making it more difficult to train and tune than linear models, XGBoost or a small TCN.

## Suggested Literature-review Statement｜建议的文献综述表述

### English

Lim et al. (2021) introduced the Temporal Fusion Transformer, an interpretable deep-learning architecture for multi-horizon forecasting that explicitly distinguishes static covariates, past-observed variables and known-future inputs. The model combines LSTM-based local processing, interpretable self-attention, dynamic variable selection and gated residual networks, thereby capturing temporal relationships at different scales while providing insights into variable relevance, lag structures and regime changes. Although TFT achieved strong results across electricity, traffic, retail and financial-volatility datasets, it operates primarily on aligned numerical features and does not preserve the original spatial or network structures of remote-sensing and shipping data. In this dissertation, TFT is therefore used as a strong flat-feature fusion benchmark against which the proposed modality-specific representation-level model is evaluated.

### 中文

Lim 等（2021）提出了 Temporal Fusion Transformer，这是一种面向多步时间序列预测的可解释深度学习架构。该模型明确区分静态协变量、历史可观测变量和未来已知变量，并结合基于 LSTM 的局部时间处理、可解释自注意力、动态变量选择和门控残差网络，从而同时学习不同时间尺度上的依赖关系，并解释变量重要性、历史滞后结构和市场状态变化。尽管 TFT 在电力、交通、零售和金融波动率数据集上取得了较强预测结果，但其主要处理已经完成时间对齐的数值特征，不能保留遥感影像和航运网络的原始空间结构。因此，本论文将 TFT 定位为扁平特征融合的强基准模型，并将其与保留模态结构的表示级多模态模型进行比较。
