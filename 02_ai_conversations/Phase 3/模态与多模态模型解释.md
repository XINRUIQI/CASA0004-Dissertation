# 一、什么是“模态”（Modality）

**模态 = 一种类型或来源的数据，它具有自己独特的结构和表达形式。**

“模态”这个词来自人类感知。例如，视觉、听觉和触觉属于不同的感知通道。在机器学习中，“模态”被引申为具有不同数据形态和结构的数据类型。

| 模态 | 典型形式 | 数据结构 |
|---|---|---|
| 文本 | 文章、新闻、评论 | 词序列（离散符号） |
| 图像 | 照片、卫星影像 | 像素网格（2D / 3D 张量） |
| 音频 | 语音、声音 | 波形（1D 时序信号） |
| 视频 | 影片 | 图像序列（时空张量） |
| 表格 / 结构化数据 | 价格、财务指标 | 行列数值表 |
| 时序 | 股价、传感器读数 | 按时间排列的数值序列 |
| 图（Graph） | 社交网络、贸易网络 | 节点 + 边 |

判断两类数据是否属于“不同模态”的关键是：

> 它们的底层数据结构和统计特性是否存在本质差异。

例如：

- “油价时序”和“黄金价格时序”都属于数值时序，因此通常被视为**同一模态中的不同变量**；
- “卫星影像”和“新闻文本”的底层结构完全不同，因此属于**两个不同模态**。

# 二、什么是“多模态模型”（Multimodal Model）

**多模态模型 = 能够同时接收并融合两种或两种以上模态数据，用于预测或决策的模型。**

多模态建模的核心难点是：

> 不同模态的数据结构不同，因此通常不能直接放入同一种网络中处理，也不能简单地把原始数据直接拼接在一起。

一个典型的多模态模型通常包含三个部分。

## 1. 模态专属编码器（Modality-Specific Encoder）

每一种模态使用与其数据结构相匹配的编码器，将原始数据转换为向量表示或 embedding。

常见对应关系如下：

- 图像 → CNN / Vision Transformer（ViT）
- 文本 → BERT / Transformer
- 时序 → LSTM / TCN / TFT / Temporal Transformer
- 图结构 → GNN / GAT / ST-GNN

编码器的作用可以表示为：

```text
原始模态数据
    ↓
模态专属编码器
    ↓
模态表示向量 / embedding
```

例如：

```text
卫星影像
    ↓
CNN / ViT / Prithvi / SatMAE
    ↓
遥感表示 z_rs
```

```text
金融时间序列
    ↓
TCN / LSTM / TFT
    ↓
金融表示 z_fin
```

```text
航运网络
    ↓
GNN / GAT
    ↓
航运表示 z_ship
```

## 2. 融合层（Fusion Layer）

融合层负责把不同模态的表示整合起来。

根据融合发生的阶段，通常可以分为三种方式。

| 融合方式 | 做法 | 特点 |
|---|---|---|
| 早期融合 / 特征级融合 | 一开始就把不同来源的特征拼成一个大向量或一张表 | 实现简单，但模态界限容易被抹平 |
| 中期融合 / 表示级融合 | 各模态先独立编码，再通过 attention、gating 等机制交互 | 能保留模态结构，属于典型的跨模态融合 |
| 晚期融合 / 决策级融合 | 每个模态独立预测，最后对预测结果进行投票或加权 | 模态独立性强，但跨模态交互较弱 |

### 早期融合

```text
金融特征 ─┐
遥感特征 ─┼── 拼接成一张表 ── 模型 ── 预测
航运特征 ─┘
```

这种做法也常被称为：

- flat fusion；
- feature concatenation；
- tabular early fusion；
- 扁平特征融合。

如果把遥感、航运和金融数据都加工成数值列，再统一输入 Ridge、XGBoost、LSTM 或 TCN，那么本质上仍然属于**早期融合**。

### 中期融合

```text
金融数据 ── 金融编码器 ── z_fin ─┐
遥感数据 ── 遥感编码器 ── z_rs  ├── Attention / Gating ── 融合表示
航运图   ── 图编码器   ── z_ship ┘
```

中期融合先保留每种模态自己的数据结构，再在表示空间中进行交互，因此更接近严格意义上的“模态感知多模态模型”。

### 晚期融合

```text
金融模型 ── 预测结果 y_fin  ─┐
遥感模型 ── 预测结果 y_rs   ├── 加权 / 投票 ── 最终预测
航运模型 ── 预测结果 y_ship ─┘
```

这种方法容易解释各模态的独立贡献，但不同模态之间的深层交互通常较弱。

## 3. 预测头（Prediction Head）

预测头接收融合后的表示，并完成最终任务。

常见任务包括：

- 回归：预测价格、收益率、需求量；
- 分类：预测上涨或下跌、疾病类别；
- 排序：对风险或相关性进行排序；
- 生成：生成文本、图像或其他内容。

在回归任务中，预测头通常可以是：

```text
融合表示
    ↓
全连接层 / MLP
    ↓
预测值
```

例如：

```text
[z_fin, z_rs, z_ship]
          ↓
门控或交叉注意力融合
          ↓
融合表示 z_fused
          ↓
MLP 回归头
          ↓
下一周 Brent 对数收益率或价格
```

# 三、经典多模态模型示例

## 1. CLIP：图像 + 文本

CLIP 同时处理图像和文本，用于判断一张图片与一句话在语义上是否匹配。

```text
图像 ── 图像编码器 ── 图像向量
                           ↓ 相似度比较
文本 ── 文本编码器 ── 文本向量
```

## 2. GPT-4V / Gemini：图像 + 文本 + 音频

这类模型能够同时处理图片、文字和语音等多种输入，因此属于通用多模态模型。

## 3. 医疗诊断：影像 + 文本 + 数值

医疗多模态模型可能同时使用：

- CT 或 MRI 影像；
- 病历文本；
- 化验指标；
- 患者生命体征。

不同数据分别编码后，再共同用于疾病判断或风险预测。

# 四、与你的原油价格预测项目的对应关系

你的项目可以被划分为三种主要模态：

| 项目数据 | 模态类型 | 推荐编码器 |
|---|---|---|
| Brent、WTI、库存、VIX、DXY 等 | 金融数值时序 | TCN / LSTM / TFT / Temporal Transformer |
| Sentinel-2、Landsat、VIIRS 等 | 遥感图像或遥感时空序列 | CNN / ViT / Prithvi / SatMAE |
| 港口、咽喉、船舶流量与拥堵网络 | 图结构或动态图 | GNN / GAT / ST-GNN |

严格的模态感知模型结构可以表示为：

```text
金融时序
    ↓
Finance Temporal Encoder
    ↓
z_fin
    │
    ├──────────────┐
    │              │
卫星影像           │
    ↓              │
EO Encoder         │
    ↓              │
z_rs               ├── Gated Cross-Attention ── z_fused ── Prediction Head
    │              │
    │              │
航运动态图         │
    ↓              │
Graph Encoder      │
    ↓              │
z_ship             │
    └──────────────┘
```

因此，你的研究中可以区分两类模型：

## 扁平融合基线

将所有金融、遥感和航运变量都处理为数值列，再统一输入同一个模型。

例如：

```text
所有工程特征
    ↓
统一表格
    ↓
Ridge / XGBoost / LSTM / TCN
    ↓
预测
```

这种方法使用了多来源数据，但不一定保留各模态原始结构。

## 模态感知表示级融合模型

每种模态使用独立编码器，再通过门控、注意力或交叉注意力进行融合。

例如：

```text
金融编码器 → z_fin
遥感编码器 → z_rs
图编码器   → z_ship
                ↓
门控交叉注意力
                ↓
预测 Brent
```

这正是你的 RQ2 所要比较的核心：

> 保留模态结构的表示级融合，是否优于把所有变量压缩为一张表的扁平融合？
