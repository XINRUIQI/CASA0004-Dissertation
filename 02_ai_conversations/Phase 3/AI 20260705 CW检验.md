# Clark-West Test（CW 检验）解释

## 一、Clark-West test 是什么？

Clark-West test（简称 CW 检验）是一种用于比较两个预测模型样本外预测精度的统计检验。

它尤其适合比较：

```text
嵌套模型 nested models
```

最经典的来源是：

```text
Clark, T. E., & West, K. D. (2007).
Approximately normal tests for equal predictive accuracy in nested models.
Journal of Econometrics.
```

简单来说，CW 检验想回答的问题是：

> 一个加入了更多变量的大模型，相比一个更简单的基准模型，是否真的具有额外预测能力？

---

## 二、在原油价格预测项目里的直观理解

你的项目目标是：

```text
预测下一周 Brent 原油价格
```

你有一组逐步加变量的模型：


| 模型  | 含义                                        |
| --- | ----------------------------------------- |
| M0  | 随机游走 / no-change benchmark，即“下周价格 = 本周价格” |
| M1  | 历史 Brent + 金融 / 宏观变量                      |
| M2  | M1 + 遥感变量                                 |
| M3  | M1 + 航运变量                                 |
| M4  | M1 + 遥感变量 + 航运变量                          |


普通问题是：

> M1 / M2 / M3 / M4 加了更多变量之后，预测结果的变化到底是真的，还是只是随机波动？

Clark-West 要回答的问题是：

> 如果大模型包含了小模型的信息，那么大模型是否在统计意义上比小模型具有更强的预测能力？

例如：

```text
M1 = 金融基线
M2 = M1 + 遥感变量
M3 = M1 + 航运变量
M4 = M1 + 遥感变量 + 航运变量
```

那么可以用 CW 检验来判断：

```text
M2 相对 M1 是否有额外预测力？
M3 相对 M1 是否有额外预测力？
M4 相对 M1 是否有额外预测力？
```

---



## 三、为什么不用普通 DM test 就够了？

Diebold-Mariano test，也就是 DM 检验，适合比较两个非嵌套模型的预测精度。

例如：

```text
XGBoost vs LSTM
Ridge vs XGBoost
TCN vs Random Forest
```

这些模型之间通常不是一个包含另一个的关系，因此可以用 DM 检验比较它们的预测误差序列。

但是，如果两个模型是嵌套的，普通 DM 检验会有问题。

例如：

```text
小模型：M1 = 金融变量
大模型：M2 = 金融变量 + 遥感变量
```

M2 包含了 M1 的所有信息，只是多加了一些变量。

在这种情况下，大模型因为估计了更多参数，即使新增变量在真实世界中没有预测力，也可能因为估计噪声导致样本外 MSPE 被“惩罚”。

也就是说：

> 大模型天然更容易因为参数更多而吃亏。

Clark-West 的核心贡献就是：

> 对嵌套模型中大模型的估计噪声偏差进行调整，从而更公平地判断新增变量是否真的有预测价值。

---



## 四、Clark-West 的基本公式

设：

```text
e1_t = y_t - ŷ1_t
```

表示小模型 / 基准模型的预测误差。

```text
e2_t = y_t - ŷ2_t
```

表示大模型 / 扩展模型的预测误差。

普通的 MSPE 差异是：

```text
e1_t² - e2_t²
```

如果这个值大于 0，说明大模型的平方误差更小。

但是 Clark-West 会加入一个调整项：

```text
(ŷ1_t - ŷ2_t)²
```

因此，Clark-West 的调整后损失差异为：

```text
f_t = e1_t² - e2_t² + (ŷ1_t - ŷ2_t)²
```

然后检验：

```text
mean(f_t) > 0 ?
```

如果 `mean(f_t)` 显著大于 0，说明：

> 大模型在调整嵌套模型的估计噪声后，具有显著更强的预测能力。

也就是说，大模型中的新增变量确实提供了额外预测信息。

## 五、怎么解读 CW 检验结果？

假设你比较：

```text
M1 = 金融基线
M3 = M1 + 航运咽喉变量
```

结果为：

```text
CW statistic = 1.92
p-value = 0.027
```

可以解释为：

> M3 的样本外预测表现显著优于 M1，说明加入航运咽喉变量后，模型获得了额外预测信息。

如果结果为：

```text
CW statistic = 0.65
p-value = 0.260
```

则说明：

> 即使 M3 的 RMSE 看起来略有改善，也不能证明这种改善在统计上显著。

换句话说：

```text
p-value < 0.05  →  新增变量有统计显著的预测增量
p-value ≥ 0.05  →  不能证明新增变量有显著预测增量
```

## 六、和你的项目怎么对应？

在你的项目里，CW 检验可以这样理解：


| 比较       | 问题                          |
| -------- | --------------------------- |
| M0 vs M1 | 金融变量是否相对随机游走提供额外预测力？        |
| M1 vs M2 | 遥感变量是否在金融基线之外提供额外预测力？       |
| M1 vs M3 | 航运变量是否在金融基线之外提供额外预测力？       |
| M1 vs M4 | 遥感 + 航运是否在金融基线之外提供额外预测力？    |
| M3 vs M4 | 遥感变量是否在金融 + 航运基础上继续提供额外预测力？ |


其中，你当前最关键的比较是：

```text
M1 vs M2
M1 vs M3
M1 vs M4
```

因为你的研究重点不是单纯证明模型能不能打赢 M0，而是要看：

> 在一个强金融基线之上，遥感和航运模态是否还能提供额外预测信息。

## 七、结合当前结果的解释

你当前的主结果中：


| 比较               | CW_p  | 解释           |
| ---------------- | ----- | ------------ |
| M2 XGB vs M1 XGB | 0.085 | 遥感模态边缘不显著    |
| M3 XGB vs M1 XGB | 0.096 | 航运模态边缘不显著    |
| M4 XGB vs M1 XGB | 0.020 | 遥感 + 航运全模态显著 |


这说明：

1. 单独加入遥感模态，不能稳定证明相对 M1 有显著增量；
2. 单独加入航运模态，也不能稳定证明相对 M1 有显著增量；
3. 但同时加入遥感和航运后，M4 相对 M1 达到统计显著。

因此，比较合理的解释是：

> 遥感和航运都带有一定弱信号，但单独加入时信号不够强；两个模态合并后，信号叠加才达到统计显著。

## 八、为什么 CW 显著，但 RMSE 可能更差？

这是 CW 检验最容易让人误解的地方。

RMSE 和 CW 检验问的是两件不同的事。

RMSE 问的是：

> 最终预测误差有没有变小？

Clark-West 问的是：

> 在调整大模型因为多估参数而带来的噪声惩罚之后，新增变量本身是否包含预测信号？

所以可能出现这种情况：

```text
M4 的 RMSE 比 M1 更差
但 M4 的 CW_p 却显著
```

这并不矛盾。

它说明：

> 新增模态中可能确实有方向性信号，但简单 flat fusion 没有把这些信号有效转化成更低的整体 RMSE。

换句话说：

```text
有信号，但噪声也很大；
Clark-West 看到了信号；
RMSE 看到了最终净效果。
```

这正好支持你的 RQ2：

> 遥感和航运模态不是完全无效，而是简单扁平拼接无法有效利用它们，因此需要更聪明的模态感知融合方法。

## 九、使用 CW 检验时需要注意什么？

Clark-West 最适合用于：

```text
线性嵌套预测模型
```

例如：

```text
AR 模型 vs ARX 模型
历史价格模型 vs 历史价格 + 外生变量模型
M1 Ridge vs M2 Ridge
M1 Ridge vs M3 Ridge
```

因为这些模型之间有明确的嵌套关系。

但是，如果比较的是：

```text
Random Walk vs XGBoost
Random Walk vs TCN
XGBoost vs LSTM
XGBoost vs TCN
```

这些模型通常不是严格嵌套模型。

在这种情况下，更常规的做法是使用：

```text
Diebold-Mariano test
```

因此，在论文里要注意措辞：

> 对于线性或特征嵌套设定，使用 Clark-West 检验评估新增变量的预测增量；对于非嵌套模型或不同算法之间的比较，使用 Diebold-Mariano 检验作为补充。

---



## 十、一句话总结

Clark-West test 可以概括为：

> 专门用于“基准模型 vs 加了更多变量的大模型”的样本外预测精度检验。

它想证明的不是简单的：

```text
大模型 RMSE 是否更低
```

而是：

```text
新增变量是否提供了统计显著的额外预测信息
```

在你的项目里，CW 检验的作用就是判断：

> 遥感和航运模态是否真的在金融基线之外提供了额外预测价值。
