## TFT 的优势


| 特性                         | 对你项目的价值                                        |
| -------------------------- | ---------------------------------------------- |
| 原生支持多类型输入                  | 静态变量（AOI 类型）、已知未来变量（日历特征）、未知变量（价格、NTL 等）可以分别编码 |
| 可解释注意力权重                   | 自动输出“哪些时间步”和“哪些变量”对预测贡献最大，天然支持模态贡献分析           |
| Variable Selection Network | 内置变量选择机制，可以自动筛选有用特征——你有 237 个特征，这很有用           |
| 多步预测                       | 原生支持多步时间序列预测                                   |


## TFT 的风险


| 风险    | 说明                                                                  |
| ----- | ------------------------------------------------------------------- |
| 样本量   | 约 1,043 个周度样本对 Transformer 来说偏少，可能过拟合                               |
| 调参复杂  | 比 XGBoost/LSTM 多很多超参数，如 `attention heads`、`hidden size`、`dropout` 等 |
| 实现工作量 | 比 LSTM 多 2–3 天，但可以使用 `pytorch-forecasting` 库                        |
