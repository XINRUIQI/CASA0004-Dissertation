## 已完成脚本说明

### `01_baselines.py`

实现以下四类基线模型：

- `LogisticRegression`
- `Ridge`
- `RandomForest`
- `SVM` / `SVR`

实验覆盖：

- M1–M4 四个模态层级；
- `direction`、`volatility` 和 `price` 三个预测目标；
- 完整的模态消融实验。

训练时将 train 和 validation 数据合并，并在 test 集上进行最终评估。

### `02_xgboost_model.py`

实现 XGBoost 分类和回归模型，主要功能包括：

- 使用 validation 集进行 early stopping；
- 运行 M1–M4 四层消融实验；
- 对 M4 模型自动生成 SHAP summary plot；
- 将实验结果保存至 `results/` 目录。

`01_baselines.py` 和 `02_xgboost_model.py` 均通过 `config.py`、`data_loader.py` 和 `evaluation.py` 接入统一数据与评估管线。

### `03_lstm_model.py`

包含完整的 LSTM 实现：

- LSTM 模型定义；
- 训练循环；
- Early stopping；
- Epoch-level 训练日志；
- 预测函数；
- M1–M4 × 3 targets 的消融实验主函数 `run_lstm()`。

对于方向分类任务，脚本会自动将标签：

```text
{-1, 0, 1}
```

映射为：

```text
{0, 1, 2}
```

以适配 `CrossEntropyLoss`，预测完成后再映射回原始标签。

### `04_tft_model.py`

包含完整的简化版 Temporal Fusion Transformer 实现，核心组件包括：

- `GatedResidualNetwork`
- `VariableSelectionNetwork`
- `SimplifiedTFT`
  - Variable Selection Network
  - GRU 时序编码
  - Multi-head Attention
  - Gated Output

实验支持：

- M1–M4 四个模态层级；
- `direction`、`volatility` 和 `price` 三个预测目标；
- M4 模型自动保存 attention heatmap；
- M4 模型自动保存 variable importance 可视化图。

该实现仅依赖 PyTorch，不需要安装 `pytorch-forecasting`。

### `05_stgnn_model.py`

包含完整的纯 PyTorch 时空图神经网络实现。

核心结构为：

```text
GraphConvLayer → GRU → Fully Connected Output Head
```

其中：

- `GraphConvLayer` 使用 `D⁻¹AHW` 进行图消息传递；
- GCN 负责建模 AOI 节点之间的空间关系；
- GRU 负责建模时间依赖；
- Fully Connected Head 输出分类或回归结果。

图数据构建方式如下：

- M1 和 M3：将 9 维金融特征广播至 11 个 AOI 节点；
- M2 和 M4：在金融特征基础上，增加 1 维逐节点 NTL 特征；
- M3 和 M4：使用航运活动构建加权邻接矩阵。

脚本还包括：

- Early stopping 训练循环；
- M1–M4 × 3 targets 的消融实验；
- 结果保存至 `stgnn_results.csv`。

### `run_all.py`

用于统一顺序运行全部模型，并完成结果汇总与可视化。

主要功能包括：

- 顺序运行 Baselines；
- 运行 XGBoost；
- 运行 LSTM；
- 运行 TFT；
- 运行 ST-GNN；
- 聚合所有模型结果；
- 生成模型比较热力图；
- 生成 M1 与 M4 的对比柱状图。
