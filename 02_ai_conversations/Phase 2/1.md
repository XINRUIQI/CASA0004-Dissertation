
# 多模态 Brent 原油价格方向预测实验设计

## 1. 数据集概况

当前数据集包含 **33 列基础特征**，主要包括以下几类。

### 1.1 价格、收益率与波动率特征

- `brent_price`
- `wti_price`
- `brent_return_pct`
- `brent_vol_4w`
- `brent_vol_12w`
- `brent_direction`

### 1.2 EIA 周度能源市场特征

包含 EIA 周报中的：

- 10 个原始序列
- 3 个衍生指标：
  - 库存变动
  - 净进口
  - 净贸易

EIA 周报数据覆盖率为 **100%**。

### 1.3 FRED 宏观经济特征

包含 5 个指标：

- VIX
- U.S. Dollar Index
- 10-Year Treasury Yield
- Federal Funds Rate
- S&P 500

其中：

- VIX：100% 覆盖
- Dollar Index：100% 覆盖
- 10-Year Treasury Yield：100% 覆盖
- Federal Funds Rate：100% 覆盖
- S&P 500：约 48% 覆盖，仍需补充下载

### 1.4 EIA STEO 月度产量特征

- 数据频率：月度
- 当前覆盖率：约 20%
- 可用时间：仅 2022 年以后

### 1.5 模态可用性标记

数据集中包含 4 个 modality availability flags，用于表示不同模态在对应周是否可用。

# 2. 消融实验架构

## 2.1 预测任务

- **目标变量**：`target_brent_direction_next_1w`
- **预测含义**：预测下一周 Brent 原油价格方向
- **标签定义**：
  - `1` = 下一周价格上涨
  - `0` = 下一周价格下跌
- **任务类型**：二分类

---

## 2.2 时间切分

采用严格的时间序列切分，确保训练、验证和测试过程中不存在未来信息泄漏。

| 数据集 | 时间范围 | 周数 |
|---|---|---:|
| Train | 2006-01-06 ~ 2022-12-30 | 887 |
| Validation | 2023-01-13 ~ 2024-06-28 | 77 |
| Test | 2024-07-12 ~ 2025-12-26 | 77 |

---

## 2.3 四层递进特征集

整体消融实验按照 `M1 → M2 → M3 → M4` 的顺序逐步增加不同模态。

| 实验 | 特征组成 | 特征数 | 实验逻辑 |
|---|---|---:|---|
| M1 | 市场 + 宏观 | 27 | Brent/WTI 价格与收益率、EIA 周报 10 个序列，以及 FRED 5 个宏观指标 |
| M2 | M1 + 文本 | 27 + 0 = 27 | 文本特征暂为空，GDELT/OPEC NLP 特征待构建 |
| M3 | M1 + M2 + 遥感 | 27 + 112 = 139 | 加入 8 个 AOI 的光学遥感、夜光、传感器状态及观测数量特征 |
| M4 | M1 + M2 + M3 + 航运 | 27 + 112 + 100 = 239 | 加入 GFW 和 IMF PortWatch 的航运与咽喉通行特征 |

---

## 2.4 M1：市场与宏观特征

M1 包含 27 个市场、能源基本面和宏观经济特征，具体包括：

### Brent/WTI 市场特征

- Brent 价格
- WTI 价格
- Brent 收益率
- WTI 收益率
- Brent 波动率
- Brent 价格方向

### EIA 周报特征

包含 10 个周度序列，例如：

- 原油库存
- 原油产量
- 原油进口
- 原油出口
- 炼厂投入
- 炼厂利用率
- 汽油库存
- 馏分油库存
- 成品油供应
- 其他石油基本面指标

同时包含库存变化、净进口或净贸易等衍生指标。

### FRED 宏观特征

- S&P 500
- VIX
- U.S. Dollar Index
- 10-Year Treasury Yield
- Federal Funds Rate

## 2.5 M2：文本模态

M2 的定义为：

```text
M2 = M1 + 文本特征
````

当前文本特征尚未完成构建，因此：

```text
M2 = 27 + 0 = 27
```

计划构建的文本数据源包括：

* GDELT 新闻数据
* OPEC 月报、新闻稿或公告
* 地缘政治事件文本
* 石油市场情绪指标
* 新闻主题与文本嵌入
* 文本情绪分数
* 事件数量与事件强度

因此，当前 M2 与 M1 在特征数量和实际输入上相同，暂不构成有效的新增模态实验。

---

## 2.6 M3：遥感模态

M3 在 M1 和 M2 的基础上加入遥感特征：

```text
M3 = M1 + M2 + 遥感
```

当前特征数为：

```text
27 + 112 = 139
```

遥感特征来自 8 个 AOI。

### 光学遥感指标

每个 AOI 包含以下指数：

* NDVI
* NDWI
* NDBI
* BSI

每个指数分别计算：

* `mean`
* `std`

### VIIRS 夜光指标

每个 AOI 可包含：

* 夜光均值 `mean`
* 夜光最大值 `max`
* 夜光标准差 `std`
* 无云观测比例或 cloud-free 指标

### 遥感数据质量与可用性指标

* `sensor_flag`
* `obs_count`

这些指标用于区分：

* 真实的低遥感数值
* 遥感观测缺失
* 云覆盖或传感器不可用
* 一周内有效观测数量不足

## 2.7 M4：航运模态

M4 在 M3 的基础上继续加入航运特征：

```text
M4 = M1 + M2 + M3 + 航运
```

当前特征数为：

```text
27 + 112 + 100 = 239
```

航运特征主要来自：

* Global Fishing Watch Vessel Presence

# 3. 候选模型

每一层特征实验均运行以下 4 个模型。

| 模型                  | 是否需要标准化 | 是否原生支持 NaN |
| ------------------- | ------: | ---------: |
| Logistic Regression |       是 |     否，需要填补 |
| Random Forest       |       否 |     否，需要填补 |
| XGBoost             |       否 |          是 |
| LightGBM            |       否 |          是 |

## 3.1 缺失值处理

### Logistic Regression

* 不支持 NaN
* 需要先进行缺失值填补
* 当前计划将缺失值填为 0
* 建议同时保留 modality availability flags，以区分“真实值为 0”和“模态缺失”

### Random Forest

* 当前实验实现中不直接支持 NaN
* 需要将缺失值填为 0
* 同样需要结合 availability flags 使用

### XGBoost

* 原生支持 NaN
* 可以在树分裂过程中学习缺失值默认方向
* 不需要提前将航运缺失值统一填为 0

### LightGBM

* 原生支持 NaN
* 可以自动学习缺失值的分裂方式
* 适合处理不同模态覆盖时间不一致的问题

# 5. SHAP 可解释性分析

在表现最佳的多模态实验层中进行 SHAP 分析。

优先候选实验层为：

* M3
* M4

分析步骤如下：

1. 使用 LightGBM 在最佳实验层上重新训练模型。
2. 使用测试集作为解释样本。
3. 计算 TreeSHAP values。
4. 按平均绝对 SHAP 值计算全局特征重要性。
5. 输出 Top 25 特征。
6. 绘制 SHAP summary plot。
7. 分析市场、宏观、遥感和航运特征对预测结果的相对贡献。

建议输出：

* Top 25 特征重要性表
* SHAP beeswarm plot
* SHAP bar plot
* 关键特征 dependence plot
* 不同模态的 SHAP 重要性汇总

# 7. 图神经网络多模态建模方案

除传统表格型机器学习模型外，可以进一步将遥感 AOI 与航运咽喉组织为供应链图，用于构建图神经网络模型。

## 7.1 图结构定义

### 节点

图中共有 17 个节点：

```text
11 个 AOI + 6 个航运咽喉 = 17 个节点
```

节点类型包括：

* 石油生产地
* 石油出口港
* 炼化或工业区域
* 石油消费或进口节点
* 国际航运咽喉

---

## 7.2 节点特征

每个节点在每一周具有对应的遥感或航运指标。

### AOI 节点特征示例

以 `P001` 为例：

* NDVI mean
* NDVI std
* NDWI mean
* NDWI std
* NDBI mean
* NDBI std
* BSI mean
* BSI std
* VIIRS nightlight mean
* VIIRS nightlight max
* VIIRS nightlight std
* cloud-free observation
* sensor flag
* observation count

### 航运咽喉节点特征示例

以 Hormuz 为例：

* transit hours
* vessel count
* tanker count
* total vessel count
* tanker capacity
* total capacity
* tanker share
* week-on-week change
* 4-week moving average
* modality availability flag

由于 AOI 节点和航运节点的原始特征维度不同，可以采用以下方式之一统一维度：

1. 将所有节点映射到统一的特征空间，不适用的字段填为 NaN 或 0。
2. 为不同节点类型设置独立的编码器。
3. 使用 heterogeneous graph neural network。
4. 添加 node-type embedding，区分遥感节点与航运节点。

---

## 7.3 边

边表示石油供应链中的连接关系。

示例路径包括：

```text
P003 Ras Tanura → Hormuz → P004 Singapore
```

```text
P011 Yanbu → Bab el-Mandeb → Suez → P001 Rotterdam
```

边可以表示：

* 原油出口关系
* 航运通行关系
* 港口与咽喉之间的物流连接
* 上游生产节点与下游消费节点之间的供应链联系
* 潜在的石油流向

边可以设计为：

* 有向边
* 静态边
* 带权边
* 随时间变化的动态边

边权重可以根据以下信息构建：

* 历史原油流量
* 航线距离
* 航运时间
* 油轮通行数量
* 油轮运力
* 节点之间的供应链重要性

---

## 7.4 全局特征

M1 中的市场与宏观变量可作为全局特征使用。

主要包括：

* Brent/WTI 价格与收益率
* EIA 周度石油市场指标
* VIX
* Dollar Index
* 10-Year Treasury Yield
* Federal Funds Rate
* S&P 500

全局特征可以通过以下方式加入模型：

### 方法一：Graph-level features

先通过 GNN 获得图嵌入，再与 M1 特征拼接：

```text
Graph Embedding + M1 Global Features → Classification Head
```

### 方法二：复制到每个节点

将同一周的 M1 特征附加到每个节点：

```text
Node Remote-Sensing/Shipping Features + M1 Features
```

### 方法三：构建全局虚拟节点

增加一个 global node：

```text
Global Market Node
```

该节点包含 M1 市场和宏观特征，并与所有 AOI 和航运节点连接。

---

## 7.5 预测目标

图模型执行图级别预测，而不是节点级别预测。

预测目标为：

```text
target_brent_direction_next_1w
```

即：

* 输入：第 `t` 周的供应链图、节点特征和全局特征
* 输出：第 `t+1` 周 Brent 原油价格方向
* `1` = 涨
* `0` = 跌

因此，任务可以表示为：

```text
Weekly Supply-Chain Graph at Week t
        ↓
Temporal/Graph Encoder
        ↓
Graph-Level Embedding
        ↓
Binary Classification
        ↓
Brent Direction at Week t+1
```

# 8. 图模型的候选架构

## 8.1 静态 GNN

每一周构建一个独立图，使用：

* GCN
* GraphSAGE
* GAT

模型流程：

```text
Node Features
    ↓
GNN Layers
    ↓
Global Mean/Attention Pooling
    ↓
Concatenate M1 Global Features
    ↓
MLP Classification Head
    ↓
Brent Direction
```

---

## 8.2 时空图神经网络

由于数据为周度时间序列，可以进一步构建时空图模型。

候选架构包括：

* GCN + LSTM
* GCN + GRU
* GAT + GRU
* Temporal Graph Network
* Temporal Graph Attention Network
* Spatio-Temporal Graph Convolutional Network

模型流程示例：

```text
Weekly Graph Sequence:
G(t-L+1), ..., G(t-1), G(t)
        ↓
Spatial GNN Encoder
        ↓
Temporal GRU/LSTM/TCN Encoder
        ↓
Graph-Level Representation
        ↓
M1 Global Features
        ↓
Binary Classification
        ↓
Brent Direction at t+1
```

# 9. 整体实验逻辑

完整实验可以分为两个阶段。

## 第一阶段：表格型多模态消融实验

```text
M1：市场 + 宏观
M2：M1 + 文本
M3：M2 + 遥感
M4：M3 + 航运
```

每层运行：

* Logistic Regression
* Random Forest
* XGBoost
* LightGBM

主要研究问题：

```text
加入新的数据模态是否能够提高下一周 Brent 价格方向预测性能？
```

---

## 第二阶段：供应链图模型实验

将：

* AOI 遥感节点
* 航运咽喉节点
* 供应链连接关系
* M1 市场与宏观全局特征

共同构建为图模型。

主要研究问题：

```text
显式建模石油生产、航运与消费节点之间的供应链关系，是否比简单地将所有特征拼接为表格更有效？
```

# 10. 核心对比关系

最终可以形成以下模型比较框架：

```text
M1 Tabular Baseline
        ↓
M3 Tabular Multimodal
        ↓
M4 Tabular Multimodal
        ↓
Static GNN
        ↓
Temporal GNN
```

重点比较：

1. M3 是否优于 M1。
2. M4 是否优于 M3。
3. 航运数据缺失是否影响 M4 的早期训练。
4. 原生缺失值处理是否优于统一填 0。
5. 图结构是否优于简单特征拼接。
6. 时空图模型是否优于静态图模型。
7. 遥感和航运模态是否提供独立于市场与宏观变量的增量预测信息。
8. 不同模态在不同市场阶段中的重要性是否发生变化。

```
```
