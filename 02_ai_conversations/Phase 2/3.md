
# 1. 文献设计、概念变量与实际特征列数

## 1.1 文献设计与概念变量

文献设计主要依据：

- `external_sources.md`
- 文献矩阵

在文献层面，各模态推荐保留的是具有明确经济机制和文献依据的核心概念变量，而不是主数据表中经过 AOI、咽喉和指标维度展开后的全部列。

| 模态 | 推荐变量数 | 说明 |
|---|---:|---|
| M1 | 10 个 | 对应文献矩阵中的变量 #1–#10；其中 #1 包含 `brent_price` 滞后项和 `brent_log_return`，#6 包含 `ovx` / `vix` |
| M2 | 5–7 个 | 核心包括 4 个 NTL 异常指标和 1 个 NTL 数据质量指标；Sentinel-2 光学指标可选 1–2 个；`aoi_capacity_weight` 为可选静态变量，在 Dataset Overview 中可以不单独成行 |
| M3 | 约 7–10 个 | 采用文献矩阵 §③ 中推荐的核心航运变量，包括咽喉船舶数量、运力、全球汇总指标、方向性不对称和拥堵代理等 |

## 1.2 主表中的实际特征列数

主表实际列数由以下文件确定：

```text
feature_groups.json
        ↓

```

| 模态 | 实际列数 | 构成 |
|---|---:|---|
| M1 | 10 列 | `brent_price`、`crude_stocks_change`、`global_econ_activity`、`nonoil_industrial_commodity`、`futures_spread`、`ovx`、`gpr`、`dgs10_change`、`gold_return`、`commodity_fx` |

- GDELT 文本或事件变量；

- 其他辅助变量。

# 2. 文献概念变量与主表实际列数的差异

## 2.1 M1：文献设计与配置文件的差异

文献中 M1 设计为 10 个核心概念变量。

但需要注意：

- `vix` 已经存在于 `weekly_time_index.csv`；
- `brent_log_return` 也已经存在于 `weekly_time_index.csv`；
- 二者没有被单独列入 `feature_groups["M1_market_macro"]`；
- 当前 M1 特征组中只有 `ovx`，没有 `vix`。

因此，文献矩阵中的一个概念变量可能对应：

- 一个主表特征列；
- 多个相关特征列；
- 一个已有于时间索引表、但未重复列入 feature group 的变量。

例如，文献变量 #1 实际上包含：

```text
brent_price 的滞后项
+
brent_log_return
```

文献变量 #6 则表示：

```text
OVX（优先）
/
VIX（替代或稳健性变量）
```

---

## 2.2 M2：概念变量较少，但按 AOI 全量展开

文献设计中的 M2 核心变量约为 5–7 个。

这些变量主要是：

- NTL 异常；
- NTL 数据质量；
- Sentinel-2 光学观测或活动代理；
- 可选的 AOI 静态权重。

但在实际 pipeline 中，每一类变量都会按照 11 个 AOI 分别展开。

例如：

```text
1 个 ntl_anomaly 概念变量
        ↓
11 个 AOI
        ↓
11 个实际特征列
```

因此，M2 实际包含：

```text
ntl_anomaly：11 列
ntl_valid_obs_count：11 列
s2_clear_obs_count：11 列
s2_cloud_fraction：11 列
```

总计：

```text
11 + 11 + 11 + 11 = 44 列
```

所以：

```text
文献层面：约 5–7 个概念变量
主表层面：44 个展开后的特征列
```

---

## 2.3 M3：核心航运机制较少，但候选列较多

文献矩阵建议 M3 保留约 7–10 个核心航运概念变量，例如：

- 咽喉船舶数量；
- 油轮数量；
- 油轮运力；
- 总运输能力；
- 油轮占比；
- 环比变化；
- 移动平均；
- 港口进口和出口方向性；
- 全球航运活动汇总；
- 港口或锚地拥堵代理。

但在实际 pipeline 中，这些指标会按照：

- 6 个航运咽喉；
- 多种船舶指标；
- GFW 与 PortWatch 两个数据源；
- 港口方向；
- 全球汇总；
- 变化率和移动平均；

进行展开。

因此，当前 M3 共保留：

```text
PortWatch：64 列
GFW：55 列
合计：119 列
```

这些 119 列应理解为候选特征池，而不是最终模型必须全部使用的变量。

后续建模时还需要进行：

- 特征筛选；
- 共线性诊断；
- 滞后扩展；
- 缺失率筛选；
- 稳定性筛选；
- 变量重要性分析；
- 消融实验。

# 3. Dataset Overview 应该报告哪一种变量数量

需要区分以下两种问题。

## 3.1 Dataset Overview 表格

如果表格的目的是介绍研究设计、数据模态和经济机制，应写概念变量数：

| 模态 | Dataset Overview 推荐写法 |
|---|---:|
| M1 | 10 个核心市场与宏观变量 |
| M2 | 5–7 个核心遥感概念变量 |
| M3 | 7–10 个核心航运概念变量 |

这种写法更加适合：

- 项目概述；
- 方法论章节；
- 文献综述；
- Dataset Overview；
- 研究设计示意图；
- 答辩展示。

因为它反映的是变量的概念类别，而不是空间展开后的机器学习输入维度。

---

## 3.2 主表或模型输入维度

如果表格的目的是描述数据工程结果或模型输入，应写实际列数：

| 模态 | 主表实际列数 |
|---|---:|
| M1 | 10 列 |
| M2 | 44 列 |
| M3 | 119 列 |
| 合计 | 173 列 |

这种写法更加适合：

- Data Processing；
- Feature Engineering；
- Model Input；
- 特征组配置说明；
- pipeline 技术文档；
- 模型维度与计算复杂度说明。

为了避免读者误解，可以同时报告概念变量数和展开后列数：

| 模态 | 核心概念变量 | 展开后候选特征列 | 说明 |

# 4. OVX 与 VIX 的变量选择

## 4.1 最终选择

M1 核心变量集优先使用：

```text
OVX
```

VIX 不进入 M1 核心特征集，仅作为：

- 稳健性检验变量；
- 敏感性分析变量；
- OVX 的替代变量；
- 样本覆盖差异的对照变量。

因此，当前变量 #6 的定义为：

```text
石油市场不确定性：
OVX 为核心代理变量；
VIX 为替代性稳健性变量。
```

---

## 4.2 理由一：OVX 的经济机制更加直接

根据 P052 Kilian 的石油价格形成机制，原油价格波动可以从以下机制理解：

- 石油供给冲击；
- 全球总需求冲击；
- 石油特定需求或预防性需求冲击。

OVX 是原油市场专属的隐含波动率指标，其信息直接来自原油相关期权市场，因此更接近：

```text
石油特定不确定性
        ↓
预防性需求变化
        ↓
原油价格变化
```

相比之下，VIX 衡量的是美国股票市场整体隐含波动率，更多反映：

- 股票市场风险；
- 宏观金融不确定性；
- 投资者整体避险情绪；
- 广义风险偏好变化。

VIX 与原油价格存在关联，但这种关联比 OVX 更加间接。

因此，在解释石油特定不确定性时：

```text
OVX > VIX
```

文献矩阵 P052 的核心结论可以概括为：

```text
当 OVX 与 VIX 高度相关时，应优先使用具有石油市场针对性的 OVX。
```

---

## 4.3 理由二：避免高相关变量造成解释稀释

P059 的 SHAP 解释边界指出，VIX 和 OVX 是典型的高相关变量。

如果同时将二者加入同一个模型：

```text
VIX + OVX
```

可能出现以下问题：

- 两个变量表达相似的风险信息；
- 模型可能在两者之间随机选择分裂；
- SHAP 贡献会在相关变量之间分摊；
- 单个变量的重要性被压低；
- 特征排序不稳定；
- 难以判断真正起作用的是广义市场风险还是石油特定风险。

例如，模型可能得到：

```text
OVX SHAP importance = 较低
VIX SHAP importance = 较低
```

但这并不代表“不确定性变量不重要”，而可能只是总贡献被两个高度相关变量分散。

因此，核心模型中应只保留一个变量：

```text
核心模型：OVX
稳健性模型：使用 VIX 替换 OVX
```

而不建议：

```text
核心模型：OVX + VIX 同时进入
```

---

## 4.4 理由三：OVX 的样本期代价较小

OVX 的主要缺点是开始时间较晚。

```text
OVX：约从 2007 年 5 月开始
VIX：约从 1990 年开始
```

当前 M1 和 M2 的总体研究期从 2006 年开始。

因此，使用 OVX 作为核心变量会导致模型有效样本起点从：

```text
2006 年初
```

调整至：

```text
2007 年 5 月左右
```

大约损失一年多的数据。

与整个研究期相比，这一损失相对有限，因此是可以接受的。

其优势是：

- 经济解释更加准确；
- 与原油市场机制更加直接；
- 避免 VIX 和 OVX 的重复信息；
- SHAP 解释更加清晰。

---

## 4.5 不建议将 VIX 用于直接回填 OVX

如果需要保留 2006 年至 2007 年的样本，不应简单构造：

```text
2006–2007：使用 VIX
2007 以后：使用 OVX
```

并将其视为同一个连续变量。

原因是：

- VIX 和 OVX 的定义不同；
- 二者对应的基础资产不同；
- 数值尺度和分布不同；
- 经济含义并不完全相同；
- 拼接后会形成结构断点；
- 模型可能学习到数据源切换而不是真实市场变化。

因此，不建议：

```text
OVX column =
    VIX before 2007-05
    OVX after 2007-05
```

如果确实需要进行这种扩展，应：

- 对两个指标进行标准化；
- 保留 `source_flag`；
- 明确将其命名为复合风险指标；
- 单独进行稳健性检验；
- 不将其直接解释为原始 OVX。

# 5. OVX 与 VIX 的具体实验设计

## 5.1 核心实验

M1 核心变量集只使用：

```text
OVX
```

变量组可以写为：

```text
M1_market_macro = [
    brent_price,
    crude_stocks_change,
    global_econ_activity,
    nonoil_industrial_commodity,
    futures_spread,
    ovx,
    gpr,
    dgs10_change,
    gold_return,
    commodity_fx
]
```

---

## 5.2 稳健性实验

单独构建一版替代模型：

```text
M1_OVX：使用 OVX
M1_VIX：使用 VIX 替换 OVX
```

除风险指标外，其他变量、样本划分和模型设置保持一致。

具体对比：

| 实验 | 不确定性变量 | 其他变量 |
|---|---|---|
| M1-OVX | OVX | 完全相同 |
| M1-VIX | VIX | 完全相同 |

需要比较：

- Accuracy；
- F1；
- AUC-ROC；
- RMSE，如果存在连续预测任务；
- 方向预测准确率；
- Diebold-Mariano 检验；
- 特征重要性；
- SHAP 排序；
- 不同市场时期的稳定性。

---

## 5.3 公平比较时的样本处理

由于 VIX 的样本比 OVX 更长，直接比较可能受到样本期不同的影响。

因此建议进行两组比较。

### 比较 A：共同样本期

将两个模型都限制在 OVX 可用期：

```text
2007-05 至研究期结束
```

这样可以确保：

- 两个模型使用完全相同的样本；
- 差异来自变量本身；
- 不受额外一年训练数据影响。

### 比较 B：各自最大样本期

```text
OVX 模型：2007-05 开始
VIX 模型：2006-01 开始
```

该比较反映实际数据覆盖条件下，两种变量设计的总体预测表现。

最终应优先依据共同样本期比较判断：

```text
OVX 是否真正优于 VIX
```

---

## 5.4 相关性与共线性诊断

在共同样本期计算：

- Pearson correlation；
- Spearman correlation；
- VIF；
- 滚动相关系数；
- 危机期与正常期相关系数。

例如：

```text
corr(OVX, VIX)
```

还可以使用滚动窗口：

```text
52-week rolling correlation
104-week rolling correlation
```

这可以检验二者之间的关系是否随市场状态变化。

如果二者高度相关，则进一步支持：

```text
核心模型不同时放入 OVX 和 VIX
```

# 6. 推荐的最终落地方案

| 阶段 | 做法 |
|---|---|
| M1 核心集 | 只放 OVX，作为石油特定不确定性代理 |
| VIX 处理 | 不进入核心特征集，保留在原始或辅助时间索引数据中 |
| 稳健性检验 | 单独运行一版 `OVX → VIX` 替换实验 |
| 样本公平性 | 首先在 OVX 和 VIX 的共同样本期进行比较 |
| 相关性分析 | 报告 OVX 与 VIX 的 Pearson、Spearman 和滚动相关系数 |
| 模型比较 | 对比验证集和测试集表现，并视任务使用 DM 检验 |
| SHAP 分析 | 核心模型解释 OVX；替代模型解释 VIX，不在同一模型中同时解释 |
| 文献依据 | 使用 P052 论证 OVX 的石油针对性，使用 P059 论证避免相关变量导致 SHAP 归因稀释 |

# 7. 论文中的推荐写法

## 7.1 中文版本

```text
在市场不确定性变量的选择上，本研究优先采用 OVX，而非同时纳入 OVX 与 VIX。OVX 是基于原油相关期权构建的隐含波动率指标，与石油市场特定不确定性及预防性需求机制的联系更加直接。相比之下，VIX 主要反映股票市场整体风险和广义金融不确定性。

此外，OVX 与 VIX 通常具有较高相关性。如果将二者同时纳入模型，模型解释贡献可能在相关变量之间被分摊，从而降低 SHAP 特征归因的清晰度和稳定性。因此，OVX 被纳入核心 M1 特征集，而 VIX 仅用于替代性稳健性检验。稳健性分析将使用 VIX 替换 OVX，并在共同样本期内比较两种设定的预测性能。
```

---

## 7.2 英文版本

```text
OVX is selected as the primary uncertainty proxy in the core M1 feature set,
rather than including both OVX and VIX. As an implied volatility index derived
from crude-oil-related options, OVX provides a more direct proxy for
oil-specific uncertainty and precautionary demand. In contrast, VIX primarily
captures broad equity-market uncertainty and general financial risk.

OVX and VIX are also likely to contain highly correlated information. Including
both variables may distribute or substitute their contributions in tree-based
models, reducing the clarity and stability of SHAP-based attribution.
Accordingly, OVX is retained in the core specification, while VIX is used in a
separate robustness exercise in which it replaces OVX. Their predictive
performance is compared over a common sample period to ensure a fair
comparison.
```
