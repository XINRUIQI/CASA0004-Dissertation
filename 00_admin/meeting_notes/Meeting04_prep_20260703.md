**表注：**

## B. 关键发现（可直接讲的 6 点）

1. **无一模型击败 M0。** 周频 Brent 随机游走极强，所有 12 个学习模型 skill 均为负——这本身是稳健且诚实的核心结论（与油价预测文献一致：复杂模型难超随机游走）。
2. **深度 LSTM 最贴近 M0**（M1/M4 skill 仅 −0.6% / −0.7%），明显优于 Ridge（−4~10%）和 XGB（−8~15%）——深度早融合在"逼近 RW"上更稳，且未出现历史上的负 R² 崩溃（强正则 + 目标标准化 + early stopping 生效）。
3. **遥感 M2 的嵌套增量在两类模型上都显著**：XGB CW_p = 0.006、LSTM CW_p = 0.012——**跨模型交叉印证**遥感 anom 相对纯金融带来信息增量（尽管整体仍不及 M0）。
4. **航运 M3 是"模型架构敏感"的关键对照**：XGB CW_p = 2.5e-5（极显著），但深度 early-fusion LSTM CW_p = 0.46（不显著）、RMSE 反而变差。→ **把 119 维高维异构航运"一股脑堆进一个 RNN"处理不好**，这正是 **RQ2「需要模态感知融合、而非扁平早融合」的直接经验证据**。
5. **M4 全模态**：XGB 相对 M1 显著（CW_p = 1.7e-4），LSTM 边缘（0.059）。
6. **必须讲清的 nuance：CW 显著 ≠ 击败 M0。** 遥感/航运相对纯金融有**统计显著的嵌套信息增量**，但绝对精度仍未超随机游走——这两者不矛盾，是本研究要如实表述的结论。

## D. 稳健性

- **水体掩膜（M2）**：对水面主导的出口码头做 MNDWI 水体掩膜、仅陆地像素算光学指标后，M2 XGB 嵌套增量**更强**（CW_p 0.006 → **8.5e-5**）——支持"码头水面噪声确实干扰光学指标"，掩膜是有效的方法学加固（McFeeters 1996 / Xu 2006）。
- **Leave-one-AOI-out（M2, XGB）**：去掉多数单站后 RMSE 反而下降（如去 Basra −0.28、去 Jurong −0.32）——说明遥感增量是**弥散的、非单站驱动**，且提醒需防单站过拟合。
- 深度基线四类模型全程数值稳定（无发散），说明公平协议对不同模型族都成立。

## E. 一页：贡献定位 = 集成 + 实证检验（非方法学创新）

> **本研究不提出新的融合算子 / 网络层 / 损失函数**，而是把既有方法（冻结 EO 基础模型 Prithvi/SatMAE + 模态专属编码器 + 门控 / 交叉注意力 + 缺失模态 / 不规则时间建模）**集成**为一个连贯系统，并**首次**在原油周频价格预测中、于统一无泄漏协议 + DM/Clark–West 下，系统检验「保留模态结构的表示级融合 vs 把所有列压成一张表的扁平/早融合」。贡献类型 = **application + integration + 系统实证比较**——与导师一贯强调的「公平、可复现比较」一致。

- **RQ1（增量价值）**：加遥感 / 航运是否在金融基线之上带来样本外增量？→ 已答：CW 检验显示 XGB 下 M2/M3/M4 相对 M1 均有**显著嵌套增量**，但均未击败 M0。
- **RQ2（方法集成 / 实证比较）**：模态感知表示级融合是否优于扁平特征融合？→ **核心对照层已就位**（扁平 = Ridge/XGB/LSTM early-fusion；表示级 = 待建创新层）。M3 的"XGB 显著、LSTM 早融合不显著"已提供支持 RQ2 的初步经验证据。
- **RQ3（可解释性）**：门控 / SHAP 揭示不同时期依赖哪种模态。→ SHAP 已给出模态贡献（航运 56%）；门控权重待创新层。
