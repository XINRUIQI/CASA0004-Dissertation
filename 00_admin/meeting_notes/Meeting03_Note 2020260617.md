### 1.5 Use a 4-week lag first, then test alternatives 首先使用 4 周滞后，再测试其他窗口

- The current design uses a **4-week lag**, mainly because some variables are released with delays and four weeks provides a consistently available information set.
  当前设计采用 **4 周滞后**，主要原因是部分变量存在发布延迟，而四周能够保证各变量在预测时点具有较一致的可用性。
- The literature often uses daily data and does not provide one universally accepted weekly lag length. Different studies use substantially different windows.
  现有文献通常使用日度数据，并没有统一公认的周度滞后长度；不同研究使用的窗口差异较大。
- Beatrice agreed that **4 weeks is a reasonable initial choice** because it is supported by the project's data availability.
  Beatrice 认为，基于本项目的数据可用性，**4 周可作为合理的初始选择**。
- Recommended order:
  建议顺序：
  1. Run all models using the same **4-week lag**.
     所有模型先统一使用 **4 周滞后**。
  2. Establish the main model comparison.
     完成主要模型比较。
  3. Then test alternative lags, such as **1 week**, and potentially 8 or 12 weeks if justified.
     之后再测试 **1 周**，并在有依据时测试 8 周或 12 周。

### 1.6 Simplify remote-sensing features and justify the four AOIs 简化遥感特征并论证四个 AOI

- The remote-sensing feature set initially contained both a **Sentinel-2 cloud fraction** variable and a **valid-observation fraction / count** variable.
  遥感特征最初同时包含 **Sentinel-2 云量比例**和**有效观测比例 / 次数**变量。
- Beatrice noted that cloud fraction mainly describes **image quality or data availability**, rather than the oil-related activity visible in the imagery.
  Beatrice 指出，云量比例主要反映的是**影像质量或数据可用性**，而不是影像中与石油活动有关的实际信息。
- One quality-control variable should be sufficient. The valid-observation measure can already show whether an apparent lack of activity may be caused by missing or cloud-obscured observations.
  一个质量控制变量通常已经足够。有效观测指标可以说明，某段时期未发现活动是否可能只是由于缺失观测或云层遮挡造成。
- The current decision is therefore to **remove Sentinel-2 cloud fraction** and retain the valid-observation measure.
  因此，当前决定是**删除 Sentinel-2 云量比例**，保留有效观测指标。
- This decision should be documented in the dissertation: the variable was considered but excluded because it was redundant and less directly related to the research mechanism.
  论文中应记录这一过程：曾考虑使用该变量，但因其重复且与研究机制关联较弱而删除。
- Four AOIs were selected because they provide sufficiently complete temporal coverage, whereas other candidate sites contain more missing data.
  当前选择四个 AOI，是因为这些区域具有较完整的时间覆盖，而其他候选区域存在更多缺失数据。
- Beatrice considered four AOIs likely sufficient, particularly if related studies generally use around three sites. The choice should be justified using:
  Beatrice 认为四个 AOI 基本足够，尤其是在相关研究通常只选择约三个区域的情况下。论文中应从以下方面论证：
  - **Data completeness and missingness**  
    **数据完整性和缺失情况**
  - **Comparability with related literature**  
    **与相关文献的可比性**

### 1.7 Mechanistic validation is optional exploratory analysis 机制验证属于可选的探索性分析

- A question was raised about whether remote-sensing and shipping variables must be separately validated before being added to the forecasting models.
  会议讨论了在将遥感和航运变量加入预测模型前，是否必须单独进行机制验证。
- Possible relationships include:
  可能的机制关系包括：
  - Night-time lights / thermal anomalies → oil-field, refinery, storage, or industrial activity  
    夜间灯光 / 热异常 → 油田、炼油、储油或工业活动
  - Tanker counts, capacity, imports and exports → oil supply or trade flows  
    油轮数量、运力、进口和出口 → 石油供应或贸易流动
- Beatrice's view was that separate validation is **helpful but not essential**:
  Beatrice 认为，单独验证**有帮助，但不是必须的**：
  - It can be included as **exploratory data analysis**, using time-series comparisons or correlations.
    可以将其作为**探索性数据分析**，例如时间序列对比或相关性分析。
  - The mechanism can also be explained theoretically and supported by literature.
    机制也可以通过理论文字说明，并由文献支持。
  - The most important evidence is whether adding the new data improves out-of-sample prediction.
    最重要的证据是加入新数据后，样本外预测是否得到改善。
- If adding remote sensing improves Model 1, this suggests that it provides additional predictive information. If it does not improve the model, that is also a valid result.
  如果加入遥感后模型优于模型 1，说明遥感提供了额外预测信息；如果没有改善，同样也是有效结果。
- Therefore, mechanism checks may be included, but they should not replace the main M1–M4 performance comparison.
  因此，可以开展机制检验，但不能用其取代 M1–M4 的核心性能比较。
