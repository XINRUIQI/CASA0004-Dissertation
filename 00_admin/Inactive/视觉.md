# 全部 CV 可选方案

## 1. 储油罐液位估算（Floating Roof Tank Shadow Analysis）— 最推荐

**原理：**  
浮顶储油罐（FRT）的顶盖直接浮在油面上，油越少顶盖越低，罐壁内侧产生的月牙形阴影越大。通过卫星影像测量阴影面积，可以反推储油量。

```text
油满 → 顶盖高 → 内阴影小        油空 → 顶盖低 → 内阴影大

 ┌──────┐                      ┌──────┐
 │▓▓▓▓▓▓│ ← 顶盖               │      │
 │▓▓▓▓▓▓│                      │      │
 │▓▓▓▓▓▓│ ← 石油               │░░░░░░│ ← 阴影（空的部分）
 └──────┘                      │▓▓▓▓▓▓│ ← 石油
                               └──────┘
```

**为什么极度相关：**  
这就是对冲基金（Orbital Insight、Kayrros）花几百万美元做的事情——卫星估库存。EIA 只公布美国库存，但你的 11 个 AOI 包含鹿特丹、富查伊拉、宁波等没有公开库存数据的站点。如果能估算这些站点的库存变化，就提供了市场上不存在的独家信息。

**技术路线：**  
YOLOv8 检测储油罐 → HSV/LAB 色彩空间阴影提取 → 阴影面积比 → 液位估算

**可行性问题：**  
Sentinel-2（10m）分辨率对大型罐（直径 >60m，如库欣、富查伊拉）勉强可用，小型罐不行。最佳方案需要商业高分影像（0.5–3m），但免费数据也能做概念验证。

**工作量：** 5–7 天  
**独特价值：** 极高

## 3. 港口船舶密度 / 拥堵估算（Port Congestion）

**原理：**  
在 AOI 港口区域的卫星影像中检测停泊/锚泊船舶数量，估算港口拥堵程度。拥堵高 → 供应链瓶颈 → 可能影响油价。

**技术路线：**  
用 Sentinel-1 SAR（全天候）检测港口 AOI 内的船舶亮点，统计月度锚泊船舶数。

**可行性：**  
中等。GFW SAR 数据可以间接实现：按 AOI 空间过滤 SAR 检测结果，作为港口拥堵代理。

**工作量：** 2–3 天  
**独特价值：** 中

---

## 4. 天然气火炬检测（Gas Flare Detection）

**原理：**  
炼厂和油田的天然气火炬（flaring）在夜间卫星影像中可见。火炬强度和数量反映生产活动水平。

**数据：**  
VIIRS Nightfire 数据集（Elvidge et al. 2023）已公开，自动检测全球约 2 万个红外点源。

**可行性：**  
高。不需要自己训练模型，VIIRS Nightfire 是处理好的数据集。但你已经用了 VIIRS 夜灯（平均辐射亮度），火炬检测是更精细的信号。

**工作量：** 2–3 天  
**独特价值：** 中低（和现有 VIIRS 夜灯部分重叠）

---

## 5. 漏油检测（Oil Spill Detection from SAR）

**原理：**  
漏油在 SAR 影像上表现为暗斑，因为油膜会抑制海面微波散射。CNN / Transformer 模型可用于检测。

**与油价关系：**  
间接。大型漏油事件会导致供应中断和价格波动，但属于低频事件。

**工作量：** 5–7 天  
**独特价值：** 低（事件太稀少，难以形成周频特征）

---

## 6. 基础设施变化检测（Change Detection）

**原理：**  
对比不同时期的卫星影像，检测储罐区扩建、炼厂改造、新建管道等。

**与油价关系：**  
长期指标，主要反映产能扩张，对短期周频预测帮助有限。

**工作量：** 7–10 天  
**独特价值：** 低（更适合年度/季度分析）

---

# 综合建议

如果你想在项目中加入 CV，推荐优先级如下：

| 优先级 | 方案 | 为什么 |
|---|---|---|
| 1 | 储油罐液位估算 | 这是卫星 + 油价领域最经典的 CV 应用，学术和产业界都认可。即使只做 2–3 个站点的概念验证，也是强有力的 contribution。 |
| 2 | GFW SAR 暗船计数 | 最省力，约 1 天即可完成，并且有独特信号，可以覆盖 AIS 盲区。 |
| 3 | 港口拥堵估算 | 可以和方案 2 一起做，使用同源数据，作为航运活动补充变量。 |

## 最推荐的组合

**储油罐液位估算 + GFW SAR 暗船计数**

这个组合最适合写进论文：

- 储油罐液位估算可以作为 CV 模块的亮点；
- GFW SAR 暗船计数可以作为航运模态的补充；
- 一个基于光学影像目标检测；
- 一个基于 SAR 影像船舶检测；
- 可以覆盖 Chapter 2.3 中的 “Ship detection from satellite imagery” 和 “Port activity monitoring” 两个空白章节。

这样你的论文就有了比较完整的 CV 故事：既有光学影像中的储油罐分析，也有 SAR 影像中的船舶活动监测。
