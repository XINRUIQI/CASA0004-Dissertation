# 扁平模型（Flat Baseline, M0–M4）完整流程详解

> 它把金融、遥感、航运三类数据「拍平（flatten）」拼成一张大宽表，喂给两个机器学习模型（Ridge、XGBoost），逐层加数据（消融阶梯 M0→M4），检验「每一类新数据对预测下周油价到底有没有用」。

## 1. 项目要解决什么问题

**预测目标**：下一周的 Brent 原油现货价 P_{t+1}（单位：美元/桶）。

**训练方式**：模型不直接预测价格，而是预测**对数收益** r_{t+1}=\ln(P_{t+1}/P_t)，再还原成价格 \hat P_{t+1}=P_t \cdot e^{\hat r}。这样做是因为价格本身非平稳（有趋势），对数收益更平稳、更适合建模。

**核心科学问题**：

- **RQ1**：卫星遥感、航运数据能不能超过纯金融模型、能不能超过「随机游走」这个强基准？
- **RQ2**：把多种数据简单「拍平拼接」够不够？还是需要更聪明的「模态感知融合」？

**消融阶梯（逐层加数据，看每类数据的增量价值）**：


| 模型     | 用了什么数据         | 通俗理解                         |
| ------ | -------------- | ---------------------------- |
| **M0** | 什么都不学          | 「下周价 = 本周价」，随机游走，最朴素但极强的基准   |
| **M1** | 金融/宏观（31 列）    | 价格、库存、VIX、黄金、汇率、地缘风险等        |
| **M2** | M1 + 遥感（55 列）  | 加卫星特征：11 个油站的植被/水体/建成区/裸土/夜光 |
| **M3** | M1 + 航运（113 列） | 加船运特征：6 个咽喉道的油轮流量、AIS 船舶存在   |
| **M4** | M1 + M2 + M3   | 金融+遥感+航运全部一起                 |


**每个模型用两种算法**：

- **Ridge**：带 L2 正则的线性回归，稳健但怕高维噪声
- **XGBoost**：梯度提升树，能抓非线性，对高维冗余更鲁棒

## 5. 建模数据组装



### 5.1 lag 展平（lookback=4）

每个特征展平成过去 4 周：`{变量}_lag0`（本周）、`_lag1`、`_lag2`、`_lag3`（3 周前）。入模维度 = 原始列数 × 4。


| 模型  | 原始特征列         | ×4 lag | 入模维度    |
| --- | ------------- | ------ | ------- |
| M0  | 0（规则基准）       | —      | —       |
| M1  | 31            | ×4     | **124** |
| M2  | 31+55=86      | ×4     | **344** |
| M3  | 31+113=144    | ×4     | **576** |
| M4  | 31+55+113=199 | ×4     | **796** |




### 5.2 目标构造

- 训练标签：`r_next = ln(P.shift(-1)/P)`，索引在 t，代表 r_{t+1}
- 预测还原：\hat P_{t+1}=P_t \cdot e^{\hat r}

## 6. 回测协议

用 **expanding rolling-origin（扩展窗口滚动起点）walk-forward** 回测。

### 6.1 关键参数


| 参数            | 值     | 含义                           |
| ------------- | ----- | ---------------------------- |
| 总周数           | 365   | 2019-01-04 ~ 2025-12-26      |
| lookback      | 4 周   | 每特征展平成本周+前3周                 |
| min_train     | 104 周 | 前 104 周只攒数据不预测（≈2 年 warm-up） |
| retrain_every | 13 周  | 每季度重训一次                      |
| val_weeks     | 52 周  | 训练集尾部 52 周做内层验证              |
| 测试周           | 257 周 | 约 2021–2025                  |
| seed          | 42    | 随机种子                         |




### 6.2 精确回答「训练了几个/训练周/验证周」


| 问题      | 答案                                                       |
| ------- | -------------------------------------------------------- |
| 训练了几个模型 | 每个 fold 训 2 个（Ridge+XGB）；约 20 个 fold × 2 ≈ 40 次拟合；M0 不训练 |
| 训练的周数   | 扩展式：首次 104 周 → 末次 ~360 周                                 |
| 验证的周数   | 每次训练集**尾部 52 周**（选超参后再用全训练集重训）                           |
| 测试的周数   | **257 周**（2021–2025），M0–M4 共用                            |

## 7. 主结果

**主基线（L4_tuned，257 测试周，M0 RMSE=4.152）**：


| 模型       | RMSE ($/桶) | skill vs M0 | CW_p vs M1（加模态是否显著） | 结论              |
| -------- | ---------- | ----------- | ------------------- | --------------- |
| M0_RW    | 4.152      | —           | —                   | 随机游走基准          |
| M1_Ridge | 4.256      | −2.5%       | —                   | 金融基线            |
| M1_XGB   | 4.368      | −5.2%       | —                   | 最强 RMSE 之一      |
| M2_Ridge | 4.414      | −6.3%       | 0.474               | 加遥感，线性不显著       |
| M2_XGB   | 4.440      | −6.9%       | **0.085** ❌         | 加遥感，边缘不显著       |
| M3_Ridge | 4.430      | −6.7%       | 0.264               | 加航运             |
| M3_XGB   | 4.429      | −6.7%       | **0.0002** ✅        | 加航运，高度显著        |
| M4_Ridge | 4.525      | −9.0%       | 0.314               | 全模态，线性不显著       |
| M4_XGB   | 4.507      | −8.6%       | **0.009** ✅         | 全模态，显著但 RMSE 最差 |


**三个核心结论**：

1. **没有任何模型赢过 M0**（skill 全负）——周度油价极接近随机游走，这是预期内的强基准。
2. **单加遥感 M2 不显著**（0.085）；**单加航运 M3 显著**（0.0002）；**全模态 M4 显著**（0.009）。
3. **反直觉点**：M4 显著但 RMSE（4.507）反而比 M1（4.368）差——因为 RMSE 问「最终误差大不大」，Clark-West 问「扣掉大模型多估参数的噪声惩罚后，新特征本身有没有方向性信号」，是两件事。有信号，但扁平拼接吃不动。

## 8. 怎么分析结果



### 8.1 三层证据链

```
第一层（精度）：RMSE / MAE / skill vs M0  →「误差多大？赢过 M0 吗？」
第二层（显著性）：DM / Clark-West           →「改善是显著还是偶然？」
第三层（解释）：SHAP / LOAO / LOMO          →「靠什么变量？去掉谁影响大？」
```



### 8.2 指标与检验分工


| 工具                  | 用途               | 类型                |
| ------------------- | ---------------- | ----------------- |
| RMSE / MAE          | 平均预测误差           | 精度指标              |
| skill vs M0         | 1 − RMSE/RMSE_M0 | 相对随机游走            |
| DirAcc              | 涨跌方向命中率          | 精度指标              |
| **Diebold–Mariano** | vs M0（非嵌套）       | 计量经济学检验           |
| **Clark–West**      | vs M1（嵌套）        | 嵌套模型正确检验          |
| **SHAP**            | 哪些变量/模态被用        | ML 可解释性（≠因果、≠显著性） |




### 8.3 「显著但 RMSE 更差」怎么解读（M4）

- **RMSE**：最终误差 → M4(4.507) > M1(4.368)，加特征反而更差
- **Clark-West**：扣掉噪声惩罚后，新增模态有无方向性信号 → p=0.009 显著

## 9. 一句话总结

> 扁平模型证明：在强金融基线 M1 之上，简单地把遥感/航运特征**拍平拼接**，边际增量被稀释、甚至 RMSE 变差；只有精选子集（literature 4 列、M3 full/tanker、水体掩膜版）或全模态 CW 才勉强显著。这直接支撑 **RQ2**：需要模态感知的表示级融合（编码器 → 低维 embedding → 门控融合），而不是继续堆 flat 列。
