## 0. 一句话定位

**拟定标题**：A Modality-Aware Spatio-Temporal Fusion Framework for Brent Crude Oil Forecasting Using Financial Time Series, Satellite Imagery and Maritime Networks
（融合金融时序、卫星影像与海运网络的**模态感知时空**布伦特原油价格预测框架）

不是把遥感和航运加工成更多数值列再拼成一张表，而是用**模态专属编码器**分别学习「金融状态 / 遥感活动 / 航运网络」表示，再通过**门控交叉注意力**学习三者在不同市场时期的动态贡献，端到端预测**下一周 Brent 价格**。

**贡献定位**：不提出新的融合算子 / 网络层 / 损失函数，而是把既有方法（冻结 EO 基础模型 + 模态专属编码器 + 门控/交叉注意力 + 缺失模态建模）**集成**为一个连贯系统，并**首次**在原油周频价格预测中、于统一无泄漏协议 + DM/Clark–West 下，系统检验「保留模态结构的表示级融合 vs 把所有列压成一张表的扁平融合」。贡献类型 = **application + integration + 系统实证比较**。

## 1. 研究框架



### 1.1 两层结构


| 层                              | 内容                                 | 模型                                           | 状态                     |
| ------------------------------ | ---------------------------------- | -------------------------------------------- | ---------------------- |
| **核心实证层**（baseline / ablation） | 工程特征拼成宽表，做稳健、可复现的 M0–M4 消融         | M0 随机游走 + Ridge + XGB + 深度 LSTM early-fusion | ✅ 已完成                  |
| **方法集成与实证检验层**（contribution）   | 模态专属编码器 + 表示级融合（门控 / 交叉注意力），对照扁平融合 | 三编码器 + Gated Fusion / Cross-Attention        | 🔨 部分启动（z_ship 编码器已就绪） |




### 1.2 三个研究问题（RQ）

- **RQ1（增量价值）**：在金融/宏观基线（M1）之上，加入遥感、航运是否提升样本外预测？是否优于不变基准 M0？
- **RQ2（方法集成 / 实证比较）**：相同数据下，**模态感知表示级融合** 是否优于 **扁平特征融合**（所有列拼一张表喂 XGB / 线性 / RNN）？
- **RQ3（可解释性）**：融合门控权重能否揭示「不同市场时期更依赖哪种模态、关注哪个港口/航道」，并与已知供给冲击、地缘事件在时间上吻合？



### 1.3 预测目标（唯一核心目标 = 价格）


| 层面           | 定义                                    |
| ------------ | ------------------------------------- |
| 研究目标         | 准确预测下一周 Brent 现货价格 P_{t+1}（美元/桶，周五截止） |
| 模型训练目标（内部表达） | 下一周对数价格变化 r_{t+1}=\log(P_{t+1}/P_t)   |
| 模型最终输出       | 还原价格 \hat P_{t+1}=P_te^{\hat r_{t+1}} |


方向 / 收益率仅由预测价格派生为**辅助评估指标**，不进入损失；**不做**独立波动率预测。

### 1.4 三个模态（统一比较窗 2019.1–2025.12）


| 模态        | 内容                                                                      | 合并矩阵列数                     | 频率 / 发布滞后                              |
| --------- | ----------------------------------------------------------------------- | -------------------------- | -------------------------------------- |
| **M1 金融** | Brent/WTI、EIA 周度库存·产量·进出口·炼厂、VIX、DXY、利率、S&P500、期货基差、GPR 等               | 31                         | 周频；EIA +1w、月频变量 1–5w                   |
| **M2 遥感** | 11 AOI × 月度 Sentinel-2 的 `{NDVI,NDWI,NDBI,BSI,NTL}_anom`（站点扩展窗 z-score） | 55 (anom)                  | 月频 as-of +15d；双通道另含冻结 EO embedding（待做） |
| **M3 航运** | 6 咽喉 PortWatch 过境 + GFW 存在 + 港口方向性进出口                                   | 113 (full) / **38 (core)** | 周频；GFW +4w、PortWatch +1w               |


合并矩阵 `weekly_feature_matrix.csv`：**365 周 × 212 列**（31 M1 + 55 M2 + 113 M3 + 11 mask + 2 target），无泄漏自检全通过。

### 1.5 模型架构（方法集成层）

```text
金融序列  ── Finance Encoder (TCN/GRU) ───────────► z_fin (32维)
卫星影像  ── 冻结 EO Encoder (Prithvi/SatMAE) → embedding
             └ 时间注意力 + AOI-site 注意力 ──────► z_rs  (32维)
航运动态图 ── GAT(空间) → TCN(时间) ──────────────► z_ship(32维)  ← ✅ 已实现
       z_fin, z_rs, z_ship
         └► Gated Cross-Modal Fusion ──► z_fused (64维)
               └ log-return head ─► r̂_{t+1} ─► 还原价格 P̂_{t+1}=P_t·e^(r̂)
```

融合方案递进对照：① Encoder-Concat（基础）② **Gated Fusion（推荐主模型）** ③ Cross-Attention（进阶，金融做 Query）。

### 1.6 实验设计（两维度交叉）

**模态维度 × 架构维度**：


| 模态  | 编码器                     |     | 架构                | 融合方法           |
| --- | ----------------------- | --- | ----------------- | -------------- |
| M0  | 随机游走基准                  |     | XGBoost / Ridge   | 扁平特征拼接         |
| M1  | Finance                 |     | LSTM early-fusion | 深度扁平早融合        |
| M2  | Finance + RS            |     | Encoder-Concat    | embedding 拼接   |
| M3  | Finance + Shipping      |     | **Gated Fusion**  | 动态门控（主模型）      |
| M4  | Finance + RS + Shipping |     | Cross-Attention   | 模态 token 交叉注意力 |


**核心对照**：Flat feature fusion vs Modality-aware representation fusion。

### 1.7 公平比较协议（锁定）

统一窗口 **2019.1–2025.12** · lookback = **4 周**（导师设定）· rolling-origin（expanding，min_train=104，retrain_every=13）· 单任务回归 r_{t+1} 还原价格 · 指标在**还原价格**上计算 · 测试期 **257 周（2021–2025）** · 主对照锁定 `L4_tuned`。
检验：**DM(HLN) vs M0**（非嵌套）+ **Clark–West vs M1**（嵌套增量，加模态是否显著的正确检验）。

### 2.2 关键结果（2026-07-03 精简 M1 后最新重跑）


| 模态            | 模型          | RMSE          | skill vs M0   | CW_p vs M1（嵌套增量）    |
| ------------- | ----------- | ------------- | ------------- | ------------------- |
| **M0**        | 随机游走        | **4.152**     | 0.0%          | —                   |
| M1 金融         | Ridge / XGB | 4.256 / 4.368 | −2.5% / −5.2% | —                   |
| M2 +遥感        | Ridge / XGB | 4.414 / 4.440 | −6.3% / −6.9% | 0.474 / 0.085       |
| M3 +航运 (core) | Ridge / XGB | 4.351 / 4.476 | −4.8% / −7.8% | 0.289 / 0.096       |
| M4 全模态        | Ridge / XGB | 4.466 / 4.492 | −7.6% / −8.2% | 0.375 / **0.020** ✅ |


**六点核心发现**：

1. **无一模型击败 M0**——周频 Brent 随机游走极强（诚实、稳健的核心结论，与油价预测文献一致）。
2. **精简 M1 变强后，单模态 XGB 嵌套增量退化为不显著**（M2 anom 0.085、M3 core 0.096）；**仅 M4 全模态（0.020）、M2 literature（0.022）、M2 水体掩膜（0.028）、M3 full/portwatch/tanker 臂仍显著**——两个弱增量在全融合下方向一致叠加成显著。
3. **M3 是「模型敏感」关键对照**：XGB 下 full/tanker 臂显著，但线性 Ridge 几乎全不显著——高维异构航运在扁平线性模型下无法有效利用。
4. **M3 core tier 对 XGB 反而不是最优**（full/portwatch/tanker 更优）——「最优子集因模型而异」，是扁平融合局限的直接证据。
5. **SHAP 模态占比反转为 M1(51%) > M2(25%) > M3(23%)**（M3 改 core tier + M1 变强后）；机制上苏伊士/好望角 tanker 信号对应红海绕行叙事。
6. **以上均强化 RQ2**：把 RS/航运扁平拼到已很强的金融基线上，边际增量被稀释 → **需要模态感知的表示级融合**。
