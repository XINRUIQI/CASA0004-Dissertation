## 1. 项目要解决什么问题

**预测目标**：下一周的 Brent 原油现货价 P_{t+1}（单位：美元/桶）。

**训练方式**：模型不直接预测价格，而是预测**对数收益** r_{t+1}=\ln(P_{t+1}/P_t)，再还原成价格 \hat P_{t+1}=P_t \cdot e^{\hat r}。这样做是因为价格本身非平稳（有趋势），对数收益更平稳、更适合建模。

**核心科学问题**：

- **RQ1**：卫星遥感、航运数据能不能超过纯金融模型、能不能超过「随机游走」这个强基准？
- **RQ2**：把多种数据简单「拍平拼接」够不够？还是需要更聪明的「模态感知融合」？

**消融阶梯（逐层加数据，看每类数据的增量价值）**：


| 模型     | 用了什么数据         | 通俗理解                         |
| ------ | -------------- | ---------------------------- |
| **M0** | 什么都不学          | 「下周价 = 本周价」，随机游走，最朴素但极强的基准   |
| **M1** | 金融/宏观（31 列）    | 价格、库存、VIX、黄金、汇率、地缘风险等        |
| **M2** | M1 + 遥感（55 列）  | 加卫星特征：11 个油站的植被/水体/建成区/裸土/夜光 |
| **M3** | M1 + 航运（113 列） | 加船运特征：6 个咽喉道的油轮流量、AIS 船舶存在   |
| **M4** | M1 + M2 + M3   | 金融+遥感+航运全部一起                 |


**每个模型用两种算法**：

- **Ridge**：带 L2 正则的线性回归，稳健但怕高维噪声
- **XGBoost**：梯度提升树，能抓非线性，对高维冗余更鲁棒

## 3. 第 1 步：遥感去云与月度合成（仅 M2）

去云是遥感特有的处理，全部在 **GEE 导出阶段**完成（构建脚本读到的已是去云后的月度指数）。

### 3.1 Sentinel-2 光学（NDVI/NDWI/NDBI/BSI）去云三步

1. **场景预筛**：整景云量 `CLOUDY_PIXEL_PERCENTAGE ≤ 60`（参数 `CLOUD_FILTER`），先扔掉大面积云的影像。
2. **双重云掩膜（逐像元）**：
  - s2cloudless 云概率 `< 40`（参数 `CLD_PRB_THRESH`）判为晴空
  - 再叠加 SCL 场景分类掩膜，剔除 SCL ∈ {3 云影, 8 中概率云, 9 高概率云, 10 卷云, 11 雪/冰}
3. **月度中值合成**：把当月所有晴空像元取 **median（中值）合成**（中值对残云最鲁棒）→ 在 5 km AOI 内做 `reduceRegions(mean)` 求均值，尺度 `scale=20m`。

**质量记录（不入模，仅诊断）**：`valid_obs_count`（当月进合成的有效场景数）、`cloud_probability`。这两个是「云多不多」的诊断量，**不作为预测特征**（避免把「云量」误学成价格信号）。

### 3.2 VIIRS 夜光（NTL）处理

1. **质量掩膜**：剔除 `avg_rad < 0`（杂散光/数据伪影）。
2. **区域统计**：5 km AOI 内 `reduceRegions(mean/max/stdDev)`，尺度 `scale=500m`，取 `avg_rad` 均值作为夜光水平。

VIIRS 连续性好（自 2014 起），几乎无云缺问题；Sentinel-2 受云影响，早期部分站点有月缺。

### 3.3 波段与公式


| 指数   | 公式（GEE 波段）                            | 含义        |
| ---- | ------------------------------------- | --------- |
| NDVI | (B8−B4)/(B8+B4)                       | 植被绿度      |
| NDWI | (B3−B8)/(B3+B8)                       | 水面/湿度     |
| NDBI | (B11−B8)/(B11+B8)                     | 建成区/不透水面  |
| BSI  | ((B11+B4)−(B8+B2))/((B11+B4)+(B8+B2)) | 裸土/堆场     |
| NTL  | VIIRS DNB `avg_rad` 均值                | 夜间灯光/活动强度 |




### 3.4 B4 水体掩膜稳健性版（可选）

针对 Basra/Kharg 等离岸码头 NDWI 被水面主导的问题，重跑 GEE 加水体掩膜：逐影像先算 MNDWI=(B3−B11)/(B3+B11)，`MNDWI>0` 判为水体，从 NDVI/NDBI/BSI 中掩除水面像元（只留陆地），输出 `s2_land_px`（陆地像素占比）。

## 4. 第 2 步：数据清洗与特征工程

三个模态各有一个构建脚本，把原始数据洗成**无泄漏的周频表**，统一以**每周五（W-FRI）**为时间轴。

### 4.1 M1 金融：`build_m1_weekly.py`

**输出**：`m1_weekly_features.csv`（1043 周 × 35 列，2006–2025；建模裁到 2019–2025）

**处理流程**：

1. 生成 2006–2025 每周五骨架
2. **日频→周频**：`resample("W-FRI").last()` 取每周五最后值
3. **EIA 周报**：对齐到报告周五 → 整体 `shift(+1 周)`（周报周三才发布，防泄漏）
4. **月频宏观**：月末对齐 + 前向填充到周频 → `shift(+1 或 +5 周)`
5. **派生变量**：对数收益、价差、库存变化、换月哑变量等

**发布滞后（防泄漏，关键）**：


| 来源                        | 周频化      | 滞后        |
| ------------------------- | -------- | --------- |
| 日频价格/宏观                   | 周五最后值    | 0（周五收盘可得） |
| EIA 周报（WPSR）              | 报告周五对齐   | **+1 周**  |
| GPR 地缘风险（月频）              | 月末+ffill | +1 周      |
| Kilian REA / IMF 工业原料（月频） | 月末+ffill | +5 周      |


**入模 31 列**（2026-07 精简后）：


| 分组             | 变量                                                                                                                                                                                                                                       |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 价格/派生（5）       | brent_price, wti_price, brent_log_return, wti_log_return, brent_wti_spread                                                                                                                                                               |
| EIA 周报（12，+1w） | crude_stocks_excl_spr, cushing_stocks, crude_production, crude_imports, crude_exports, refinery_crude_input, refinery_utilisation, gasoline_supplied, distillate_supplied, jet_fuel_supplied, crude_stocks_change, cushing_stocks_change |
| 宏观金融（5）        | vix, dollar_index, treasury_10y, fed_funds_rate, sp500_log_return                                                                                                                                                                        |
| 衍生市场/宏观（9）     | ovx, gpr, gold_return, global_econ_activity, nonoil_industrial_commodity, brent_f1_spot_log_basis, brent_roll_week, cadusd_log_return, dgs10_change                                                                                      |




### 4.2 M2 遥感：`build_m2_weekly.py`

**输出**：`m2_weekly_features.csv`（365 周 × 155 列，2019–2025）

**核心洗数据 = 把原始 level 转成「站点内去季节标准化距平 anom」**（这是 M2 入模的主力形态）。分两步，全部用 expanding 窗口、只用过去（无泄漏）：

1. **去季节**：对每个 (站点, 指标)，按「月份」取历史同月气候态 `clim`（如所有 1 月的平均），残差 `resid = level − clim`。正 = 比往年同月更绿/更亮。
2. **站点内 z-score 标准化**：`anom = (resid − μ)/σ`，其中 μ、σ 用 `expanding(min_periods=12)`（至少 12 个月历史）。得到「偏离了几个标准差」。

> 因为需要 ≥12 个月历史，每个序列**前 12 个月的 anom 是 NaN**，加上早期云缺，部分站点（Jurong/Ningbo/Ulsan）前段缺失更多。

**三种形态对比**：


| 形态      | 含义                | 是否入模               |
| ------- | ----------------- | ------------------ |
| `level` | 原始月度值             | ❌ 主分析不用（尺度不可比、含季节） |
| `anom`  | 站点内去季节 z-score 距平 | ✅ **入模主力（55 列）**   |
| `mom`   | 月环比差分             | ❌ 仅 EDA 表          |


**月→周对齐（as-of join，不用假 ffill）**：


| 参数                 | 值                      | 含义                      |
| ------------------ | ---------------------- | ----------------------- |
| `OBS_DAY=15`       | 15                     | 代表观测日 = 月初+14 天         |
| `PUB_LAG_DAYS=15`  | 15                     | 保守可得日 = 月末+15 天（模拟发布延迟） |
| 对齐                 | `merge_asof(backward)` | 每周五取「已发布」的最近月度观测        |
| `MAX_AGE_DAYS=100` | 100                    | 超 100 天视为模态不可用          |


每周同时携带 `age`（陈旧天数）和 `mask`（是否可用），让缺失/陈旧显式可见，而不是把月值复制成多个相同的假周值。

**入模 55 列**：5 指数 × 11 AOI，命名 `{指数}_anom_{站点}`（如 `NTL_anom_Fujairah`）。
**不入模**：55 个 level、22 个 age、22 个 avail（时效非信号或窗内近零方差）。

### 4.3 M3 航运：`aggregate_shipping_to_weekly.py`

**输出**：`m3_weekly_features.csv`（750 周 × 123 列；建模裁 2019–2025）

1. **PortWatch 日频** → `resample("W-FRI").sum()` 周求和 → `shift(+1 周)`

3. 三源用 **union 索引**拼接（修复旧版 inner-join 掉样本 bug：727→362）
4. **派生变量**：`tanker_share`（油轮占比）、`n_tanker_wow_pct`（周环比）、`avg_tanker_size`（平均吨位）、跨咽喉汇总等

**发布滞后（扁平臂；与深度图勿混写）**：


| 来源            | 周频化      | 滞后       | 说明 |
| ------------- | -------- | -------- | --- |
| PortWatch（日频） | 日→周五求和   | **+1 周** | 扁平 M3 与深度图咽喉节点共用 PW |
| GFW（**月频 presence**） | 月末+ffill | **+4 周** | **仅扁平 113 列**中的 `gfw_*` |

> 旧文档若笼统写「GFW +2 周」，那是深度图 **event/航次** 流，**不适用于**扁平 GFW presence。


**入模 113 列（full tier，主模型）**：


| 来源           | 列数  | 内容                                                                                                                                                     |
| ------------ | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| GFW          | 49  | 6 咽喉 × (total_hours, total_vessels, cargo_hours, mom_pct, bunker_hours, other_hours, other_share, mean_presence) + 1 汇总                                |

## 5. 第 3 步：合并成统一矩阵

| 模块          | 列数  | 说明                                                            |

## 6. 第 4 步：缺失值与异常值处理

### 6.1 缺失值总览


| 指标      | 数值                 |
| ------- | ------------------ |
| 总 NaN   | **553 个（占 0.71%）** |
| 无穷值 inf | **0**              |
| 完全无缺失的列 | 134 / 212          |




### 6.2 缺失按模态分组


| 模态        | 列数  | 总 NaN   | 占比   | 缺在哪             |
| --------- | --- | ------- | ---- | --------------- |
| M1 金融     | 31  | 0       | 0%   | 无缺失             |
| **M2 遥感** | 55  | **480** | 2.4% | 早期云缺 + 12 月历史要求 |
| M3 航运     | 113 | 71      | 0.2% | 周环比首周无法算        |
| mask      | 11  | 0       | 0%   | 无缺失             |
| target    | 2   | 2       | —    | 最后一周无「下周价」      |


M2 缺失集中在 3 个站点早期：Jurong（各指数 59 周）、NingboZhoushan（37 周）、Ulsan（24 周）。根因是 anom 需 ≥12 月历史 + Sentinel-2 早期云缺。

### 6.3 缺失怎么处理

在建模数据组装层（`data.py` 的 `fill_features`）：

```python
X.ffill().fillna(0.0)
```


| 步骤              | 做法         | 理由                        |
| --------------- | ---------- | ------------------------- |
| ① `ffill()`     | 用历史值前向填充   | 无泄漏（只用过去）                 |
| ② `fillna(0.0)` | 残留 NaN 填 0 | 中性值（对 z-score 距平，0 = 无异常） |


**关键**：填充后的残留 NaN 只落在 warm-up（前 104 周），不落在测试期 → 所有 M0–M4 落在**完全相同的 257 个测试周**，RMSE 差异只来自特征内容。

### 6.4 异常值怎么处理

**没有做显式的删除/截断（winsorize）**，而是靠「变换 + 模型正则化」间接控制。实测极端值：


| 类型            | 范围                | 处理                                         |
| ------------- | ----------------- | ------------------------------------------ |
| RS 距平 z-score | −5.96 ~ 9.21（43 个 | z                                          |
| 周环比 wow_pct   | 最大 ±158%          | **保留**（真实流量剧变）                             |
| inf           | 0                 | 源头拦截：距平 ±inf→NaN；n_tanker=0 时 avg_size→NaN |


**间接抗异常的三层机制**：

1. **变换**：遥感用站点内 z-score 距平（去季节去尺度）、金融用对数收益（而非价格水平）
2. **Ridge**：StandardScaler 标准化 + 强 L2 正则（α 最高 1000）压极端值
3. **XGBoost**：树模型按分裂点切分，对离群点/量级天然鲁棒

保留真实极端值是刻意的——它们对应疫情、红海/Houthi 等真实事件，删掉反而丢信号。

## 7. 第 5 步：建模数据组装（`data.py`）



### 7.1 选列（按模态）

按字典的 `modality` 字段选列，永不选 `target_*` 和 `avail_*`（mask）。

### 7.2 lag 展平（lookback=4）

每个特征展平成过去 4 周：`{变量}_lag0`（本周）、`_lag1`、`_lag2`、`_lag3`（3 周前）。入模维度 = 原始列数 × 4。


| 模型  | 原始特征列         | ×4 lag | 入模维度    |
| --- | ------------- | ------ | ------- |
| M0  | 0（规则基准）       | —      | —       |
| M1  | 31            | ×4     | **124** |
| M2  | 31+55=86      | ×4     | **344** |
| M3  | 31+113=144    | ×4     | **576** |
| M4  | 31+55+113=199 | ×4     | **796** |




### 7.3 目标构造

- 训练标签：`r_next = ln(P.shift(-1)/P)`，索引在 t，代表 r_{t+1}
- 预测还原：\hat P_{t+1}=P_t \cdot e^{\hat r}
- 特征中**永不含** target 和 mask

## 8. 第 6 步：模型与参数选择



### 8.1 M0 随机游走（内嵌规则，不是训练出来的模型）

```
r_hat = 0  →  P_hat = P_t   （「下周价 = 本周价」）
```

每周自动输出，作为所有模型的基准。M0 RMSE ≈ **4.152**。

### 8.2 Ridge（线性 + 强正则）

**Pipeline**（只在训练折内 fit，防泄漏）：

```
VarianceThreshold(0.0)  →  StandardScaler()  →  Ridge(alpha)
```

- 默认 `alpha=10.0`
- 调参网格：`alpha ∈ {0.1, 1.0, 10.0, 100.0, 1000.0}`
- 选择逻辑：维度越高越需要大 α；L4 不调参 RMSE 5.91，调参后降到 4.26



### 8.3 XGBoost（梯度提升树）

**Pipeline**：`VarianceThreshold(0.0) → XGBRegressor`（树模型不需要标准化）

**默认参数**：`n_estimators=300, max_depth=3, learning_rate=0.05, subsample=0.8, colsample_bytree=0.8, reg_lambda=1.0`

**调参网格（2×2×2=8 组）**：


| 参数               | 候选         |
| ---------------- | ---------- |
| max_depth        | 2, 3       |
| learning_rate    | 0.03, 0.05 |
| n_estimators     | 200, 400   |
| subsample        | 0.8（固定）    |
| colsample_bytree | 0.8（固定）    |
| reg_lambda       | 1.0（固定）    |


**防过拟合设计**（小样本高维尤其重要）：浅树（depth 2–3）、行/列子采样 80%、L2 正则。

### 8.4 参数怎么选（内层验证）

每个重训折内：

```
训练折（如 200 周）
  ├── 前段 → fit
  └── 尾部 52 周 → 验证，选 RMSE 最低的超参
若训练折 < 82 周（52+30）→ 用默认参数
```

选出最优超参后，用**全部训练折**重训，再预测。调参**绝不看测试集**。

## 9. 第 7 步：回测协议（具体怎么训练的）

用 **expanding rolling-origin（扩展窗口滚动起点）walk-forward** 回测。代码：`04_code/src/backtest/rolling.py`。

### 9.1 关键参数


| 参数            | 值     | 含义                           |
| ------------- | ----- | ---------------------------- |
| 总周数           | 365   | 2019-01-04 ~ 2025-12-26      |
| lookback      | 4 周   | 每特征展平成本周+前3周                 |
| min_train     | 104 周 | 前 104 周只攒数据不预测（≈2 年 warm-up） |
| retrain_every | 13 周  | 每季度重训一次                      |
| val_weeks     | 52 周  | 训练集尾部 52 周做内层验证              |
| 测试周           | 257 周 | 约 2021–2025                  |
| seed          | 42    | 随机种子                         |




### 9.2 核心思想（打比方）

想象你是 2021 年初的分析师，每周五预测下周油价：只能用「今天之前」的数据训练；随时间推进历史越来越多（窗口扩展）；不是每周重训，而是每季度（13 周）更新一次模型。

### 9.3 分步走一遍

**阶段一（第 1–104 周，warm-up）**：只积累数据，不预测。

**阶段二（第 105 周，第一次预测）**：

1. 取训练数据 = 第 1~104 周（104 个样本）
2. 内层调参：训练集分「前段 fit + 尾部 52 周验证」，Ridge 试 5 个 α、XGB 试 8 组参数，各选验证 RMSE 最低的
3. 用最优参数在全部 104 周上正式训练 Ridge 和 XGB
4. 预测第 105 周的下周油价
5. 记录 M0 基准

**阶段三（第 106–117 周）**：沿用第 105 周的模型逐周预测，不重训。

**阶段四（第 118 周，第二次重训）**：`(118−104)%13==0` 触发重训，训练数据 = 第 1~117 周（更多了），重新调参重训。

**循环到底**：

```
第105周 训练(104样本) → 预测105~117
第118周 训练(117样本) → 预测118~130
...
最后一次 训练(~360样本) → 预测最后几周
```



### 9.4 精确回答「训练了几个/训练周/验证周」


| 问题      | 答案                                                       |
| ------- | -------------------------------------------------------- |
| 训练了几个模型 | 每个 fold 训 2 个（Ridge+XGB）；约 20 个 fold × 2 ≈ 40 次拟合；M0 不训练 |
| 训练的周数   | 扩展式：首次 104 周 → 末次 ~360 周                                 |
| 验证的周数   | 每次训练集**尾部 52 周**（选超参后再用全训练集重训）                           |
| 测试的周数   | **257 周**（2021–2025），M0–M4 共用                            |




### 9.5 为什么这样设计


| 设计               | 目的                                         |
| ---------------- | ------------------------------------------ |
| 只用过去训练           | 严格无泄漏（walk-forward）                        |
| 扩展窗口             | 模拟真实：越往后历史越多                               |
| min_train=104    | 首次预测就有 2 年数据 + 够跑 52 周验证 + 对齐 M2 距平 12 月历史 |
| retrain_every=13 | 每季度更新，平衡时效与算力                              |
| M0–M4 同协议        | 差异只来自数据/模型，公平                              |




### 9.6 文献支撑（这是石油预测标准范式）


| 文献                                      | 用的回测方法                         |
| --------------------------------------- | ------------------------------ |
| P053 Alquist, Kilian & Vigfusson (2013) | 实时对齐 + 递归/扩展窗 + DM 检验；随机游走为强基准 |
| P054 Baumeister & Kilian (2015)         | 实时递归预测组合                       |
| P072 Costa et al. (2021)                | 扩展窗口伪样本外                       |
| P076 Yılmaz & Zehir (2026)              | 滚动样本外 + 多步长 + DM               |
| P025 Hao & Wang (2023，遥感→油价)            | 递归实时样本外 + Clark–West           |

## 10. 第 8 步：主结果

**主基线（L4_tuned，257 测试周，M0 RMSE=4.152）**：


| 模型       | RMSE ($/桶) | skill vs M0 | CW_p vs M1（加模态是否显著） | 结论              |
| -------- | ---------- | ----------- | ------------------- | --------------- |
| M0_RW    | 4.152      | —           | —                   | 随机游走基准          |
| M1_Flat_Ridge | 4.256      | −2.5%       | —                   | 金融基线            |
| M1_Flat_XGB   | 4.368      | −5.2%       | —                   | 最强 RMSE 之一      |
| M2_Flat_Ridge | 4.414      | −6.3%       | 0.474               | 加遥感，线性不显著       |
| M2_Flat_XGB   | 4.440      | −6.9%       | **0.085** ❌         | 加遥感，边缘不显著       |
| M3_Flat_Ridge | 4.430      | −6.7%       | 0.264               | 加航运             |
| M3_Flat_XGB   | 4.429      | −6.7%       | **0.0002** ✅        | 加航运，高度显著        |
| M4_Flat_Ridge | 4.525      | −9.0%       | 0.314               | 全模态，线性不显著       |
| M4_Flat_XGB   | 4.507      | −8.6%       | **0.009** ✅         | 全模态，显著但 RMSE 最差 |


**三个核心结论**：

1. **没有任何模型赢过 M0**（skill 全负）——周度油价极接近随机游走，这是预期内的强基准。
2. **单加遥感 M2 不显著**（0.085）；**单加航运 M3 显著**（0.0002）；**全模态 M4 显著**（0.009）。
3. **反直觉点**：M4 显著但 RMSE（4.507）反而比 M1（4.368）差——因为 RMSE 问「最终误差大不大」，Clark-West 问「扣掉大模型多估参数的噪声惩罚后，新特征本身有没有方向性信号」，是两件事。有信号，但扁平拼接吃不动。

## 11. 第 9 步：怎么分析结果



### 11.1 三层证据链

```
第一层（精度）：RMSE / MAE / skill vs M0  →「误差多大？赢过 M0 吗？」
第二层（显著性）：DM / Clark-West           →「改善是显著还是偶然？」
第三层（解释）：SHAP / LOAO / LOMO          →「靠什么变量？去掉谁影响大？」
```



### 11.2 指标与检验分工


| 工具                  | 用途               | 类型                |
| ------------------- | ---------------- | ----------------- |
| RMSE / MAE          | 平均预测误差           | 精度指标              |
| skill vs M0         | 1 − RMSE/RMSE_M0 | 相对随机游走            |
| DirAcc              | 涨跌方向命中率          | 精度指标              |
| **Diebold–Mariano** | vs M0（非嵌套）       | 计量经济学检验           |
| **Clark–West**      | vs M1（嵌套）        | 嵌套模型正确检验          |
| **SHAP**            | 哪些变量/模态被用        | ML 可解释性（≠因果、≠显著性） |


**为什么 M0 用 DM、M1 用 CW**：M2/M3/M4 是 M1 加特征的「嵌套扩展」，嵌套时标准 DM 有偏（大模型多估了真值为 0 的参数），Clark-West 专门校正这个偏差。M0 与模型非嵌套，用 DM。

### 11.3 「显著但 RMSE 更差」怎么解读（M4）

- **RMSE**：最终误差 → M4(4.507) > M1(4.368)，加特征反而更差
- **Clark-West**：扣掉噪声惩罚后，新增模态有无方向性信号 → p=0.009 显著

比喻：新增模态像一个啰嗦的分析师，有一点真信号（CW 显著），但夹带太多废话（RMSE 变差）。→ 扁平拼接吃不动，需要模态感知融合（RQ2 动机）。

## 13. RQ1 回答

**RQ1**：卫星遥感、航运数据能不能超过纯金融模型（M1）、能不能超过「随机游走」（M0）？

### 13.1 能否超过随机游走 M0？

**不能。** 所有 M1–M4 配置的 skill vs M0 均为负（RMSE 均高于 M0 的 4.152）；最强模型 M1_Flat_XGB（4.368）仍比 M0 差 5.2%。周度 Brent 极接近随机游走，与 P053 文献结论一致——这不是模型失败，而是说明 M0 本身就是极强的比较基准。

### 13.2 能否超过金融基线 M1？

**分模态，结论不同：**


| 模态         | vs M1（XGB，主规格）           | RMSE vs M1_Flat_XGB（4.368） | RQ1 判断                |
| ---------- | ------------------------ | --------------------- | --------------------- |
| **M2 遥感**  | CW_p = **0.085** ❌ 不显著   | 4.440（更差）             | **不能超过 M1**           |
| **M3 航运**  | CW_p = **0.0002** ✅ 高度显著 | 4.429（略差）             | **CW 显著，但 RMSE 未改善**  |
| **M4 全模态** | CW_p = **0.009** ✅ 显著    | 4.507（最差）             | **CW 显著，但 RMSE 明显更差** |


- **遥感（M2）**：扁平拼接全量 55 列不能提供相对 M1 的显著嵌套增量；Ridge 亦不显著（CW_p = 0.474）。稳健性显示信号存在但被稀释——literature 4 列夜光（CW_p = 0.022 ✅）、水体掩膜版 anom-55（CW_p = 0.028 ✅）、稀疏性实验（砍站/砍指标）可跨入显著，说明**有微弱信息，但全量扁平吃不动**。
- **航运（M3）**：full 113 列 XGB 对 M1 高度显著（CW_p = 0.0002），SHAP 指向霍尔木兹 tanker 占比、苏伊士周环比（红海机制）；但 RMSE 仍略高于 M1_Flat_XGB，**有信号、未转化为精度优势**。
- **全模态（M4）**：XGB 嵌套增量显著（CW_p = 0.009），主要来自 M3 full；加 M2 到 M1+M3 反而使 XGB 变差（LOMO：M1-only RMSE 全局最优）。**多模态扁平拼接不能同时改善精度与显著性。**



### 13.3 综合结论

扁平模型下，**没有任何配置在 RMSE 上同时战胜 M0 和 M1**；航运与全模态在 Clark–West 意义下相对 M1 有显著增量信号，但高维拍平把信号淹没在噪声里，无法转化为样本外精度改善。RQ1 的答案是**有条件的否定**——替代数据不是没用，而是**简单扁平拼接不足以释放其价值**（→ RQ2 动机）。

## 14. 主分析 vs 稳健性 + 通向 RQ2

### 14.1 主分析口径（正式答案；不挑最优）

| 层 | 主分析口径 | 为什么是它 |
| --- | --- | --- |
| M0 | 随机游走 \(\hat P=P_t\) | 理论基准 |
| M1 | 金融 31 列，**L4_tuned** | 导师设定 4 周 + 全量金融 |
| M2 | 遥感全 11 站 **anom-55** | 最朴素「全塞」，不人工精选 |
| M3 | 航运 **full 113** 列 | 全量航运（core 精选对 XGB 反而次优） |
| M4 | M1+M2+M3 全量 | 全模态扁平拼接 |

**稳健性臂**（literature / aoi4 / 水体掩膜 / LOAO / LOCHO / LOMO / lookback sweep 等）只用来回答「换子集或去噪后结论还在不在」——**加固**主结论，**不升级**为主分析（否则 = p-hacking，且会自拆「扁平吃不动 → 需要融合」的 RQ2 主线）。

### 14.2 通向 RQ2（深度表示级融合）

扁平层的诚实负结果（无一击败 M0；M2 全量不显著；M3/M4 有 CW 信号但 RMSE 不改善）正是方法集成层的动机。下一层见：

- **流程详解**：`deep_model_full_walkthrough_CN.md`
