## 0. 一句话定位

**拟定标题**：A Modality-Aware Spatio-Temporal Fusion Framework for Brent Crude Oil Forecasting Using Financial Time Series, Satellite Imagery and Maritime Networks
（融合金融时序、卫星影像与海运网络的**模态感知时空**布伦特原油价格预测框架）

不是把遥感和航运加工成更多数值列再拼成一张表，而是用**模态专属编码器**分别学习「金融状态 / 遥感活动 / 航运网络」表示，再通过**门控交叉注意力**学习三者在不同市场时期的动态贡献，端到端预测**下一周 Brent 价格**。

**贡献定位**：不提出新的融合算子 / 网络层 / 损失函数，而是把既有方法（冻结 EO 基础模型 + 模态专属编码器 + 门控/交叉注意力 + 缺失模态建模）**集成**为一个连贯系统，并**首次**在原油周频价格预测中、于统一无泄漏协议 + DM/Clark–West 下，系统检验「保留模态结构的表示级融合 vs 把所有列压成一张表的扁平融合」。贡献类型 = **application + integration + 系统实证比较**。

### 1.2 三个研究问题（RQ）

- **RQ1（增量价值）**：在金融/宏观基线（M1）之上，加入遥感、航运是否提升样本外预测？是否优于不变基准 M0？
- **RQ2（方法集成 / 实证比较）**：相同数据下，**模态感知表示级融合** 是否优于 **扁平特征融合**（所有列拼一张表喂 XGB / 线性 / RNN）？
- **RQ3（可解释性）**：融合门控权重能否揭示「不同市场时期更依赖哪种模态、关注哪个港口/航道」，并与已知供给冲击、地缘事件在时间上吻合？



### 1.3 预测目标（唯一核心目标 = 价格）


| 层面           | 定义                                    |
| ------------ | ------------------------------------- |
| 研究目标         | 准确预测下一周 Brent 现货价格 P_{t+1}（美元/桶，周五截止） |
| 模型训练目标（内部表达） | 下一周对数价格变化 r_{t+1}=\log(P_{t+1}/P_t)   |
| 模型最终输出       | 还原价格 \hat P_{t+1}=P_te^{\hat r_{t+1}} |


方向 / 收益率仅由预测价格派生为**辅助评估指标**，不进入损失；**不做**独立波动率预测。

### 1.5 模型架构（方法集成层）

```text
金融序列  ── Finance Encoder (TCN) ───────────────► z_fin (32维)  ← ✅ 已实现
卫星影像  ── 冻结 EO Encoder (Prithvi-EO-2.0) → embedding
             └ 时间注意力 + AOI-site 注意力 ──────► z_rs  (32维)  ← ✅ 已实现
航运动态图 ── GAT(空间) → TCN(时间) ──────────────► z_ship(32维)  ← ✅ 已实现
       z_fin, z_rs, z_ship
         └► Gated Cross-Modal Fusion ──► z_fused ─► head  ← ✅ 已实现
               └ log-return head ─► r̂_{t+1} ─► 还原价格 P̂_{t+1}=P_t·e^(r̂)
```

融合方案递进对照：① Encoder-Concat（基础）② **Gated Fusion（推荐主模型）** ③ Cross-Attention（进阶，金融做 Query）。

### 1.7 公平比较协议（锁定）

统一窗口 **2019.1–2025.12** · lookback = **4 周**（导师设定）· rolling-origin（expanding，min_train=104，retrain_every=13）· 单任务回归 r_{t+1} 还原价格 · 指标在**还原价格**上计算 · 测试期 **257 周（2021–2025）** · 主对照锁定 `L4_tuned`。
检验（**扁平层**）：**DM(HLN) vs M0**（非嵌套）+ **Clark–West vs M1**（M2/3/4 嵌套 M1，用 CW 检验加模态增量）。
> **深度层口径（§2.4，2026-07-07 修订）**：深度模型与扁平 M1 **非嵌套**（模型类 + 特征集不同）→ 对照扁平用 **DM vs M1**；「击败随机游走」用 **CW vs M0**（嵌套）；深度内部模态增量（如 fusion vs fin）嵌套 → 用 **CW**。

### 1.8 主分析 vs 稳健性臂：每个实验在项目逻辑里的角色

> 常被问「为什么每层都有一堆 sweep / LOAO / LOMO / 水体掩膜」——这里一页说清每个实验干嘛用。

**三条原则**：

1. **主分析 = 每层唯一的「正式答案」**，用**最朴素 / 先验**的口径锚定（**不挑表现最好的那个**，否则就是 p-hacking）。
2. **稳健性臂 = 换各种方式再验一遍「主结论不是碰巧」**，可以有很多个；它们**加固**主结论，**不替代**主结论。
3. 所有臂共用同一无泄漏协议（2019–2025 · L4 · rolling-origin · CW vs M1 · DM vs M0），差异只在「用哪些特征 / 怎么预处理 / 去掉什么」。

**表 A — 每层主分析口径（正式答案，靠朴素/先验锚定，非挑最优）**

| 层 | 主分析口径 | 为什么是它 |
| --- | --- | --- |
| M0 | 随机游走 P̂=P_t | 理论基准，所有模型要打的靶 |
| M1 | 金融 31 列，L4_tuned | 导师设定 4 周 + 全量金融 |
| M2 | 遥感全 11 站 anom-55 | 最朴素「全塞」，不人工精选 |
| M3 | 航运 full 113 列 | 全量航运（core 精选对 XGB 反而次优） |
| M4 | M1+M2+M3 全量 | 全模态扁平拼接 |

**表 B — 稳健性臂：各自回答什么质疑、在逻辑里起什么作用**

| 稳健性臂 | 层 | 改了什么 | 回答的质疑 | 项目逻辑作用 |
| --- | --- | --- | --- | --- |
| lookback sweep (L1/8/12) | 各层 | 滞后周数 | 换个滞后就不成立？ | 结论对时间窗稳健 |
| **LOAO** (leave-one-AOI-out) | M2 | 去掉一个**站点** | 靠某一个站撑着的？ | 遥感增量弥散、非单站驱动 |
| **LOCHO** (leave-one-channel-out) | M3 | 去掉一个**数据源** | PortWatch 还是 GFW 在起作用？ | 定位信号来源（tanker/PW 最强） |
| **LOMO** (leave-one-modality-out) | M4 | 去掉一个**模态** | 哪个模态真贡献？ | 定位模态贡献；最优子集因模型而异 → RQ2 |
| 2×2 稀疏 (aoi4 / ntlall / literature) | M2 | 精选站点/指标 | 全塞不显著=信号太稀？ | 证「站点+指标双重稀疏」→ 扁平吃不动 → RQ2 |
| 水体掩膜 (B4) | M2 | 去水面像素 | 不显著是水面噪声害的？ | 去噪也才勉强显著 → 遥感价值有限 → RQ2 |
| C2 降维 (PCA/ElasticNet) | M2 | 换降维法 | 共线性？SHAP≠PCA？ | 回应 P058；增量非纯过拟合 |
| feature-mode=returns | 各层 | 平稳化趋势列 | 非平稳外推的锅？ | 数值稳健性 |

**为什么「表现更好」的臂不能升级成主分析（关键）**

- 主线卖点（RQ2）= **「遥感/航运直接扁平拼接吃不动 → 需要模态感知融合」**。主分析必须是「最朴素的全塞版」（M2 anom-55 不显著、M3/M4 全量），这个**负结果**正是「需要融合」的证据。
- 若把 `aoi4`（4 站，CW 0.0055）或水体掩膜（0.028）升为主分析 = 等于宣称「扁平其实有用」，**自拆主线**，且会被质疑「挑显著的报」（p-hacking）。
- 所以它们留在稳健性层：`aoi4`/`literature` 证「信号稀疏」、水体掩膜证「去噪也才勉强显著」——都反过来**加固**「扁平不够、需要融合」。

| 模态            | 模型          | RMSE          | skill vs M0   | CW_p vs M1（嵌套增量）    |
| ------------- | ----------- | ------------- | ------------- | ------------------- |
| **M0**        | 随机游走        | **4.152**     | 0.0%          | —                   |

**六点核心发现**：

1. **无一模型击败 M0**——周频 Brent 随机游走极强（诚实、稳健的核心结论，与油价预测文献一致）。
2. **精简 M1 变强后，M2 anom 单模态 XGB 增量退化为不显著（0.085）**；但 **M3 改用 full 113 列后 XGB 显著（CW_p 0.0002）**、**M4 全模态显著（0.009）**，另 M2 literature（0.022）、M2 水体掩膜（0.028）也显著——弱增量在全融合下方向一致叠加。
3. **M3 是「模型敏感」关键对照**：主模型（full 113 列）XGB 显著（CW_p 0.0002），但线性 Ridge 不显著（0.264）——高维异构航运在扁平线性模型下无法有效利用，需树模型才能吃到。
4. **core tier 对 XGB 反而最弱且不显著**（RMSE 4.476、CW_p 0.096；full/portwatch/tanker 更优）——「最优子集因模型而异」，故 **2026-07-05 主模型由 core 改为 full 113 列**、core 降为稳健性臂；这是扁平融合局限的直接证据。
5. **SHAP 模态占比（full tier）重回航运主导：M3(52%) > M1(34%) > M2(15%)**（core tier 版曾为 M1 51%>M2 26%>M3 23%——full 恢复了 core 砍掉的 `tanker_share`/`n_tanker_wow_pct` 等高 SHAP 派生列）；M4 Top-10 中 6 航运 / 3 金融 / 1 遥感；机制上霍尔木兹 / 苏伊士 tanker 信号对应红海绕行叙事。
6. **以上均强化 RQ2**：把 RS/航运扁平拼到已很强的金融基线上，边际增量被稀释 → **需要模态感知的表示级融合**。

**核心发现（新口径，诚实）**：

1. **仅 Mfusion（金融+航运）skill 转正（+0.11%）**，为唯一 skill>0 的深度模型；但 CWvsM0=0.166 仍不显著——**无一显著击败 M0**（全项目诚实结论保持，现直接用 CW vs M0）。
2. **航运表示是最干净的正向证据**：在金融表示上加航运表示，嵌套 CW **0.00057** 显著降 MSE，方法学上是 RQ2「表示级融合有用」最正确的证据（深度内部嵌套）；GAT 引入 O-D 流量先验后该增量进一步走强。
3. **vs 扁平 M1 改用严格 DM(non-nested) 后不再显著**：各深度模型 DMvsM1 均 >0.05（Mship 0.106 最接近）。此前「CW vs M1 显著」是把非嵌套当嵌套的偏乐观口径；改 DM 后，「表示级显著优于扁平」由强结论**下调为方向一致、未达显著**（多 seed 层面 fusion 仅 1/3 seed DMvsM1<0.05）。
4. **门控 > 朴素拼接（架构消融）**：门控（Mfusion / M4rep）优于 encoder-concat（Mconcat −4.06%，全场最差）；DM(gating vs concat) 0.22（方向一致、未显著）。
5. **遥感表示内在弱**：Mrs −2.3%、DirAcc 0.459（<0.5）；cls embedding 更差（−11%）；加到 fin+ship 无增量——冻结 Prithvi 单模态对**周频**油价帮助有限（与扁平 M2 一致）。

**稳健性（多 seed × 超参 × RS × 正则 sweep，`04_code/scripts/deep/run_deep_sweep.py`，lookback=4）**：

- **多 seed（各 3 seed）**：fusion −0.47% ± **0.86（方差最小/最稳）**、m4rep −0.89% ± 0.60、m4xattn −1.83% ± **2.76（最不稳，seed2 崩至 −4.98%）**；CWvsM0 基本 0/3（xattn 1/3）、DMvsM1 fusion 1/3、其余 0/3——**稳的是 gated，不稳的是 xattn**。
- **超参（fusion seed42）**：lb=8 d=32 最优（+0.34%，DMvsM1 0.041）> lb=4（+0.11%）> lb=12（负）；d=64 一律变差（小样本佐证「编码器维度要小」）。**主模型仍锁 lb=4** 以对齐扁平基线做公平对比。
- **RS 正则网格（P1-5）**：meanpool 全负（最佳 lr1e-3/wd1e-3/dp0.3 −0.90%）、cls −11%——**RS 弱是内在的，非调参可救**。
- **主 fusion 正则网格（P1-6）**：整片网格 skill≈0，dp=0.3 略好（+0.29%，DMvsM1 0.038）——**主模型对正则稳健**。

**可解释性（RQ3，`run_deep_interpret.py` + `run_deep_xattn_viz.py`，lookback=4）**：

- **模态门控均值（gated 主模型）**：金融 **0.44** > 遥感 **0.348** > 航运 **0.212**。
- **节点注意力**：航运图最关注 **霍尔木兹咽喉** + P003 / P009 / P001 / P005；遥感最关注 P004 / P008 / P009 / P001 / P006（出口终端 AOI）。
- **交叉注意力（金融 Query 对 28 个 token）**：→ 航运 **0.575** / → 遥感 **0.425**；Top token 均为遥感站但权重高度均匀（~0.04），注意力「很平」→ 呼应遥感信息弱 / 冗余。
- **一个 RQ3 讨论点**：两种融合机制对「遥感 vs 航运」相对倚重相反（门控 RS>航运；xattn 航运>RS）。
- 产物：`deep_gate_weekly.csv` / `deep_interpret.png` / `deep_xattn_weekly.csv` / `deep_xattn_viz.png`。

**进阶消融（Cross-Attention / modality dropout / 子期，`run_deep_advanced.py`，lookback=4, seed=42）**：

| arm | skill vs M0 | DirAcc | CWvsM0 | DMvsM1 |
| --- | --: | --: | --: | --: |
| M4concat（encoder-concat） | −4.06% | 0.494 | 0.637 | 0.650 |
| M4rep 门控（gated） | −1.28% | 0.502 | 0.894 | 0.239 |
| **M4 Cross-Attention（金融 Query）** | **+0.12%** | 0.564 | **0.018** | 0.088 |
| M4rep + modality dropout 0.3 | −0.19% | 0.498 | 0.316 | 0.096 |
| **M4-xattn + dropout 0.3** | **+0.62%** | 0.560 | **0.008** | **0.050** |

- **Cross-Attention 单 seed 可达最佳**：seed42+lb=4 下 skill 转正、且是**唯一 CWvsM0 显著击败随机游走**的配置（0.018，加 dropout 后 0.008 且 DMvsM1 0.050 双显著）；**但多 seed 极不稳（±2.76）→ 列为「上限存在但不稳」的进阶结果，不作主模型**（主模型仍为 gated）。
- **子期**：xattn 早 / 晚期均稳定 +0.12%；gated 早期 −2.35% / 晚期（2023–25）转正 +0.49%。DM(xattn vs gated) 0.16（xattn 略优、未显著）。

> **一句话**：RQ1 增量弱（遥感尤甚，全模型 CWvsM0 均不显著、仍难破 M0）；**RQ2 部分正向**——最硬的证据是「金融表示上加航运表示」嵌套 CW **0.00057** 显著、且门控>朴素拼接，但用严格 DM(non-nested) 对照扁平 M1 **未达显著**（方向一致、多 seed fusion 1/3），较此前偏乐观口径**明确下调**；**RQ3 门控与注意力可解释**（金融主导、聚焦霍尔木兹与出口终端，两融合机制对模态倚重相反）。Cross-Attention 单 seed 可最佳但多 seed 不稳，列进阶。
